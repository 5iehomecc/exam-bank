在平面直角坐标系 xOy 中，对于任意不重两点 M，N 给出如下定义：点 M，N 的横坐标之差的绝对值与纵坐标之差的绝对值的和叫做这两点之间的“直角距离”，记作；$d_{MN}$，即点 $M(x_{1}, y_{1})$ 与点 $N(x_{2}, y_{2})$ 之间的“直角距离”为 $d_{MN} = |x_{1} - x_{2}| + |y_{1} - y_{2}|$。已知点 $A(-2,1)$，点 $B(4,-3)$。

(1) A 与 B 两点之间的 “直角距离” $d_{AB}=$ ___ ；

(2) 点 $C(t,0)$ 为 $x$ 轴上的一个动点，当 $t$ 的取值范围是 ___ 时，$d_{AC} + d_{BC}$ 的值最小为 ___ :

(3) 若动点 $P(x, k)$ 位于直线 $y = k$（其中 $-3 < k < 1$）上，且 $d_{AP} + d_{BP} \geqslant 14$，求 $x$ 的取值范围.

> [!question]- 点击查看答案与解析
> 【考点】新定义（直角距离），一次函数的最值，不等式求解 → [[【初中数学知识点体系-人教版】#9-1 用坐标描述平面内点的位置]]
> 
> 【解析】
> (1) $d_{AB} = |-2 - 4| + |1 - (-3)| = 6 + 4 = 10$；
> 
> (2) $d_{AC} + d_{BC} = |t + 2| + |0 - 1| + |t - 4| + |0 + 3| = |t + 2| + |t - 4| + 4$，
>   求$|t + 2| + |t - 4|$的最小值：
>   当$-2 \leq t \leq 4$时，最小值为$6$，
>   所以$d_{AC} + d_{BC}$最小值为$6 + 4 = 10$，$t$的范围：$-2 \leq t \leq 4$；
> 
> (3) $d_{AP} + d_{BP} = |x + 2| + |k - 1| + |x - 4| + |k + 3|$，
>   因为$-3 < k < 1$，所以$|k - 1| = 1 - k$，$|k + 3| = k + 3$，
>   则$d_{AP} + d_{BP} = |x + 2| + |x - 4| + (1 - k) + (k + 3) = |x + 2| + |x - 4| + 4$，
>   由$d_{AP} + d_{BP} \geq 14$，得$|x + 2| + |x - 4| \geq 10$，
>   解不等式：
>   - 当$x \geq 4$：$x + 2 + x - 4 \geq 10$，$2x - 2 \geq 10$，$x \geq 6$；
>   - 当$-2 < x < 4$：$x + 2 + 4 - x = 6 < 10$，无解；
>   - 当$x \leq -2$：$-x - 2 + 4 - x \geq 10$，$-2x + 2 \geq 10$，$x \leq -4$；
>   综上，$x \geq 6$或$x \leq -4$。
> 
> 【易错点】直角距离的定义应用错误，绝对值不等式的分段讨论错误。
