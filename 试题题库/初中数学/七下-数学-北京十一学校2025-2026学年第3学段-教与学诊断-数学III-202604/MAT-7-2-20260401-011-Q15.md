关于 $x$ 的不等式组 $\begin{cases} 4x + 1 > 3a \\ a - x > 1 \end{cases}$ 有解，并且它的每一个解都是关于 $x$ 的不等式 $x + 2 > a$ 的解，$①$ 则 $a$ 的取值范围是 ___ ；$②$ 若 $S = a - 3b - 2c$ 且满足 $a + b + c = -2$ 和 $3a - 2b - c = 3$，则 $S$ 的取值范围为___ 。

> [!question]- 点击查看答案与解析
> 【答案】$①$ $3 < a \leq 7$；$②$ $-2 \leq S < 2$
> 
> 【考点】不等式组的解集关系，三元一次方程组的解法 → [[【初中数学知识点体系-人教版】#11-3 一元一次不等式组]]
> 
> 【解析】
> - $①$ 解不等式组$\begin{cases} 4x + 1 > 3a \\ a - x > 1 \end{cases}$：
>   $x > \frac{3a - 1}{4}$，$x < a - 1$，有解则$\frac{3a - 1}{4} < a - 1$，解得$3a - 1 < 4a - 4$，$a > 3$；
>   不等式$x + 2 > a$的解集为$x > a - 2$，
>   不等式组的解都是$x > a - 2$的解，所以$\frac{3a - 1}{4} \geq a - 2$，且$\frac{3a - 1}{4} < a - 1$，
>   解得$3a - 1 \geq 4a - 8$，$a \leq 7$，且$a > 3$，最终$3 < a \leq 7$；
> - $②$ 解方程组$\begin{cases}a + b + c = -2 \\ 3a - 2b - c = 3\end{cases}$，相加得$4a - b = 1$，$b = 4a - 1$，
>   $c = -2 - a - b = -2 - a - (4a - 1) = -5a - 1$，
>   $S = a - 3b - 2c = a - 3(4a - 1) - 2(-5a - 1) = a - 12a + 3 + 10a + 2 = -a + 5$，
>   由$3 < a \leq 7$，得$-7 \leq -a < -3$，$-2 \leq S < 2$。
> 
> 【易错点】不等式组有解的条件判断错误，三元一次方程组消元错误。
