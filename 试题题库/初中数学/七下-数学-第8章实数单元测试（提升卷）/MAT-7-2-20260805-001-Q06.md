6. （24-25 八年级上·山西临汾·阶段练习）已知 $x=\sqrt{2}$，如果 $a$ 是 $x^2+223$ 的算术平方根，$2b-1$ 是 $x^2+25$ 的立方根，则 $|x-a-b|+x$ 的值为（ ）

A. $-17$

B. $17$

C. $-19$

D. $19$

> [!question]- 点击查看答案与解析
> 【答案】B
> 
> 【考点】算术平方根、立方根的计算 → [[【初中数学知识点体系-人教版】#8-1 平方根]]、[[【初中数学知识点体系-人教版】#8-2 立方根]]
> 
> 【解析】
> 由 $x=\sqrt{2}$，得 $x^2 = (\sqrt{2})^2 = 2$。
> 
> $x^2+223 = 2+223 = 225$，$a = \sqrt{225} = 15$。
> 
> $x^2+25 = 2+25 = 27$，$2b-1 = \sqrt[3]{27} = 3$，解得 $b = 2$。
> 
> $|x-a-b|+x = |\sqrt{2}-15-2|+\sqrt{2} = |\sqrt{2}-17|+\sqrt{2}$
> 
> 因为 $\sqrt{2} < 17$，所以 $|\sqrt{2}-17| = 17-\sqrt{2}$。
> 
> 原式 $= 17-\sqrt{2}+\sqrt{2} = 17$。
> 
> 【易错点】混淆算术平方根和平方根的概念；绝对值运算时未先判断内部正负。
