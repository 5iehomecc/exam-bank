<div style="text-align: center;">第1题</div>

A. $\angle 1 = \angle 2$

B. $\angle 2 = \angle 3$

C. $\angle 1 = \angle 5$

D. $\angle 3 + \angle 4 = 180^{\circ}$

> [!question]- 点击查看答案与解析
> 【答案】C
> 
> 【考点】平行线的判定 → [[【初中数学知识点体系-人教版】#7-2 平行线]]
> 
> 【解析】
> - 选项A：$\angle 1=\angle 2$，是同位角相等，能判定 $a\parallel b$，正确；
> - 选项B：$\angle 2=\angle 3$，是内错角相等，能判定 $a\parallel b$，正确；
> - 选项C：$\angle 1=\angle 5$，$\angle 1$ 与 $\angle 5$ 不是同位角、内错角或同旁内角关系，不能判定平行，错误；
> - 选项D：$\angle 3+\angle 4=180^{\circ}$，是同旁内角互补，能判定 $a\parallel b$，正确。
> 
> 故选C。
> 
> 【易错点】准确识别角的位置关系（同位角、内错角、同旁内角）。

A. 若 $\angle 1 = \angle 2$，则 $AB // CD$

B. 若 $\angle 3 = \angle 4$，则 $AD // BC$

C. 若 $\angle A + \angle ABC = 180^\circ$，则 $AB // CD$

D. 若 $\angle C + \angle ABC = 180^\circ$，则 $AB // CD$

> [!question]- 点击查看答案与解析
> 【答案】D
> 
> 【考点】平行线的判定 → [[【初中数学知识点体系-人教版】#7-2 平行线]]
> 
> 【解析】
> - 选项A：若 $\angle 1=\angle 2$，则 $AD\parallel BC$（内错角相等），不是 $AB\parallel CD$，错误；
> - 选项B：若 $\angle 3=\angle 4$，则 $AB\parallel CD$（内错角相等），不是 $AD\parallel BC$，错误；
> - 选项C：若 $\angle A+\angle ABC=180^{\circ}$，则 $AD\parallel BC$（同旁内角互补），不是 $AB\parallel CD$，错误；
> - 选项D：若 $\angle C+\angle ABC=180^{\circ}$，则 $AB\parallel CD$（同旁内角互补），正确。
> 
> 故选D。
> 
> 【易错点】根据角的位置关系判断哪两条直线被哪条直线所截。

> [!question]- 点击查看答案与解析
> 【答案】$50$
> 
> 【考点】平行线的判定 → [[【初中数学知识点体系-人教版】#7-2 平行线]]
> 
> 【解析】
> 三角板的直角顶点在直线 $b$ 上，$\angle 1=40^{\circ}$。
> 因为三角板是直角三角板，所以 $\angle 1+\angle 2+90^{\circ}=180^{\circ}$（平角）。
> $\angle 2=180^{\circ}-90^{\circ}-40^{\circ}=50^{\circ}$。
> 当 $\angle 2=50^{\circ}$ 时，$\angle 1$ 与 $\angle 2$ 的对顶角是同位角关系，且 $\angle 1=40^{\circ}$，$\angle 2=50^{\circ}$，此时同位角相等，所以 $a\parallel b$。
> 
> 或者：$\angle 1=40^{\circ}$，要使 $a\parallel b$，需要 $\angle 2$ 与 $\angle 1$ 的余角相等（内错角）。
> $\angle 2=90^{\circ}-40^{\circ}=50^{\circ}$。
> 
> 【易错点】利用三角板的直角性质和平行线的判定条件。

<div style="text-align: center;">第 11 题</div>

(1) 问题的结论：$a \_\_\_\_\_ c$.

(2) 思路分析：欲说明 $a \_\_\_\_\_ c$.

只要说明 $\_\_\_\_\_ // \_\_\_\_\_$ 且 $\_\_\_\_\_ // \_\_\_\_\_$ 即可.

(3) 理由如下:

$\because \angle 1 = \angle 2$ ($\_\_\_\_\_$)

$\therefore a // \_\_\_\_\_\_$ ($\_\_\_\_\_$)  ①

$\because \angle 3 + \angle 4 = 180^\circ$ ($\_\_\_\_\_$)

$\therefore c //\_\_\_\_\_\_$ ($\_\_\_\_\_$)  ②

由①②得，$a // \_\_\_$，$c // \_\_\_$

$\therefore a \underline{\qquad} c.$ ($\_\_\_\_\_$)

> [!question]- 点击查看答案与解析
> 【答案】(1) $a\parallel c$；(2) $a\parallel c$；$a$；$b$；$b$；$c$；(3) 已知；$b$；同位角相等，两直线平行；已知；$b$；同旁内角互补，两直线平行；$b$；$b$；$\parallel$；平行于同一条直线的两条直线平行
> 
> 【考点】平行线的判定与平行公理推论 → [[【初中数学知识点体系-人教版】#7-2 平行线]]
> 
> 【解析】
> 
> (1) 问题的结论：$a\parallel c$。
> 
> (2) 思路分析：欲说明 $a\parallel c$。
> 只要说明 $a\parallel b$ 且 $c\parallel b$ 即可。
> 
> (3) 理由如下：
> $\because \angle 1=\angle 2$（已知）
> $\therefore a\parallel b$（同位角相等，两直线平行）  ①
> 
> $\because \angle 3+\angle 4=180^{\circ}$（已知）
> $\therefore c\parallel b$（同旁内角互补，两直线平行）  ②
> 
> 由①②得，$a\parallel b$，$c\parallel b$。
> $\therefore a\parallel c$（平行于同一条直线的两条直线平行）。
> 
> 【易错点】利用"平行于同一条直线的两条直线平行"这一推论。
