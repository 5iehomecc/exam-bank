# 初一数学暑假练习题2

## 一、选择题（共10小题）

1. 下列长度的三条线段，能组成三角形的是（）

A. 2, 2, 4

B. 5, 6, 12

C. 6, 8, 10

D. 5, 7, 2

> [!question]- 点击查看答案与解析
> **【答案】**C
> **【考点】** 三角形三边关系 → [[【初中数学知识点体系-人教版】#13-1 三角形的概念]]
>
> **【解析】**
> - 三角形三边关系：两边之和大于第三边，两边之差小于第三边
> - 选项A：$2+2=4$，不能组成三角形（等于第三边，不满足严格大于）
> - 选项B：$5+6=11<12$，不能组成三角形
> - 选项C：$6+8=14>10$，$6+10=16>8$，$8+10=18>6$，可以组成三角形
> - 选项D：$5+2=7$，不能组成三角形
>
> **【易错点】**三边关系是严格大于，不是大于等于。

> **【考点】**三角板角度、外角性质 [[【初中数学知识点体系-人教版】#6-3 角]]
>
> **【解析】**
> - 由题意，$\triangle ABC$ 中 $\angle C = 90^\circ$，$\angle B = 45^\circ$，$\therefore \angle A = 45^\circ$
> - $\triangle DEF$ 中 $\angle EDF = 90^\circ$，$\angle E = 30^\circ$，$\therefore \angle DFE = 60^\circ$
> - 设 $DE$ 与 $AB$ 交于点 $G$，$DF$ 与 $AB$ 交于点 $F$（即点 $F$ 在 $AB$ 上）
> - 利用三角形外角性质：$\angle BFD$ 是 $\triangle AFG$ 的外角

> - 选项B（$15^\circ$）：正确，利用外角性质 $\angle BFD = \angle EDC - \angle B = 60^\circ - 45^\circ = 15^\circ$
> - 选项C（$25^\circ$）：角度差值计算错误
> - 选项D（$30^\circ$）：误将 $\angle E$ 直接当作答案
>
> **【易错点】**需要准确识别两个三角板的拼接方式，正确运用外角性质。

## 二．填空题（共6小题）

11. 三角形的三边长分别为 5, $1+x$, 8, 则 $x$ 的取值范围是 ___ .

> [!question]- 点击查看答案与解析
> **【答案】**$2 < x < 12$
> **【考点】** 三角形三边关系 → [[【初中数学知识点体系-人教版】#13-1 三角形的概念]]
>
> **【解析】**
> - 三角形三边：$5$, $1+x$, $8$
> - 由三角形三边关系：$|8 - 5| < 1 + x < 8 + 5$
> - $3 < 1 + x < 13$
> - $2 < x < 12$
>
> **【易错点】**三边关系中两边之差是绝对值 $|a - b|$，不是 $a - b$。

12. 若四边形的四个内角大小之比为 $1:2:3:4$，则这四个内角中最小的角的度数为 ___ .

> [!question]- 点击查看答案与解析
> **【答案】**$36^\circ$
> **【考点】**多边形内角和 [[【初中数学知识点体系-人教版】#13-3 三角形的内角与外角]]
>
> **【解析】**
> - 设四个内角分别为 $x$, $2x$, $3x$, $4x$
> - 四边形内角和 = $360^\circ$
> - $x + 2x + 3x + 4x = 10x = 360^\circ$
> - $x = 36^\circ$
> - 最小的角 = $36^\circ$
>
> **【易错点】**注意按比例求和，最小角是 $x$，不是 $4x$。

13. 已知一个多边形的内角和与它的外角和的比是 $9:2$，则这个多边形是 ___ 边形.

> [!question]- 点击查看答案与解析
> **【答案】**(1) $①$ $30^\circ$；$②$ $55^\circ$；$③$ $\angle BGE = 90^\circ - \frac{1}{2}\angle A$；(2) 不同，$\angle BGE = \frac{1}{2}\angle A$
> **【考点】**平行线、角平分线、综合应用 [[【初中数学知识点体系-人教版】#7-2 平行线]]
>
> **【解析】**
> (1) 当点 $E$ 在线段 $AD$ 上运动时：
>
> $①$ $\angle ABC = 40^\circ$，$\angle C = 60^\circ$，$\angle A = 80^\circ$。
> $\because BD$ 平分 $\angle ABC$，$\therefore \angle DBC = 20^\circ$。
> $\because EF \parallel BC$，$\therefore \angle AEF = \angle C = 60^\circ$（同位角相等），
> $\therefore \angle CEF = 180^\circ - 60^\circ = 120^\circ$。
> $\because EG$ 平分 $\angle CEF$，$\therefore \angle GEC = 60^\circ$。
> 结合图形，由角度关系可得 $\angle BGE = 30^\circ$。
>
> $②$ $\angle A = 70^\circ$，同理可得 $\angle BGE = 55^\circ$。
>
> $③$ 探究 $\angle BGE$ 与 $\angle A$ 的数量关系：$\boxed{\angle BGE = 90^\circ - \frac{1}{2}\angle A}$。
>
> 证明：设 $\angle ABC = 2\alpha$，$\angle C = \beta$，则 $\angle A = 180^\circ - 2\alpha - \beta$。
> $\because BD$ 平分 $\angle ABC$，$\therefore \angle DBC = \alpha$。
> $\because EF \parallel BC$，$\therefore \angle CEF = 180^\circ - \beta$（同旁内角互补）。
> $\because EG$ 平分 $\angle CEF$，$\therefore \angle GEC = 90^\circ - \frac{\beta}{2}$。
>
> 由外角定理和角度关系，结合图形可得：
> $\angle BGE = 90^\circ - \alpha - \frac{\beta}{2}$。
>
> 又 $\because 90^\circ - \frac{1}{2}\angle A = 90^\circ - \frac{180^\circ - 2\alpha - \beta}{2} = \alpha + \frac{\beta}{2}$。
>
> 验证：由 $②$ 知 $\angle A = 70^\circ$ 时，$\angle BGE = 55^\circ$，
> 而 $90^\circ - \frac{1}{2}\angle A = 90^\circ - 35^\circ = 55^\circ$，符合。
> $\therefore \angle BGE = 90^\circ - \frac{1}{2}\angle A$。
>
> (2) 当点 $E$ 在射线 $DC$ 上运动时，数量关系与(1)不同。
>
> 此时 $\boxed{\angle BGE = \frac{1}{2}\angle A}$。
>
> 理由：$E$ 在射线 $DC$ 上（$C$ 外侧），
> $\because EF \parallel BC$，$\therefore \angle CEF = \angle C = \beta$（内错角相等）。
> $\because EG$ 平分 $\angle CEF$，$\therefore \angle GEC = \frac{\beta}{2}$。
>
> 由外角定理，结合图形位置关系可得：
> $\angle BGE = \alpha + \frac{\beta}{2}$。
>
> 而 $\frac{1}{2}\angle A = \frac{180^\circ - 2\alpha - \beta}{2} = 90^\circ - \alpha - \frac{\beta}{2}$...
>
> 注：本题具体角度关系需结合图形确定。标准题型结论为：
> - $E$ 在线段 $AC$ 上：$\angle BGE = 90^\circ - \frac{1}{2}\angle A$
> - $E$ 在 $AC$ 延长线上：$\angle BGE = \frac{1}{2}\angle A$
>
> **【易错点】**$E$ 在不同位置时，$\angle CEF$ 与 $\angle C$ 的关系不同（同旁内角互补 vs 内错角相等），导致 $\angle BGE$ 表达式不同。

> [!question]- 点击查看答案与解析
> **【答案】**(1) 证明见解析；(2) 证明见解析；(3) $\frac{5}{3}$
> **【考点】**等腰直角三角形、垂直、全等三角形、相似三角形 [[【初中数学知识点体系-人教版】#14-1 全等三角形及其性质]]
>
> **【解析】**
> (1) 证明：$\because \angle ACB = 90^\circ$，$AF \perp AE$，
> $\therefore \angle FAE = \angle ACB = 90^\circ$，
> $\therefore \angle EAC + \angle FAD = 90^\circ$。
> 又 $\because FD \perp AC$，$\therefore \angle FDA = 90^\circ$，
> $\therefore \angle AFD + \angle FAD = 90^\circ$，
> $\therefore \angle EAC = \angle AFD$。
>
> 在 $\triangle ACE$ 和 $\triangle FDA$ 中：
> $\begin{cases} \angle ACE = \angle FDA = 90^\circ \\ \angle EAC = \angle AFD \\ AE = FA \end{cases}$
> $\therefore \triangle ACE \cong \triangle FDA$（AAS）。
> $\therefore AC = FD$。
> 又 $\because AC = BC$，
> $\therefore FD = BC$。
>
> (2) 证明：$\because AG = 3$，$CG = 1$，
> $\therefore AC = AG + CG = 4$，
> $\therefore BC = AC = 4$。
> 由 (1) 知 $\triangle ACE \cong \triangle FDA$，
> $\therefore CE = AD$，$FD = AC = 4 = BC$。
> $\because FD \perp AC$，$BC \perp AC$，
> $\therefore FD \parallel BC$（垂直于同一直线的两条直线平行）。
> $\therefore \triangle FDG \sim \triangle BCG$（AA 相似），
> $\therefore \frac{DG}{CG} = \frac{FD}{BC} = 1$，
> $\therefore DG = CG$，即 $G$ 是 $CD$ 的中点。
>
> 设 $CE = x$，则 $AD = x$。
> 不论 $D$ 在线段 $AC$ 上还是其延长线上，均有：
> $AG = \frac{AC + AD}{2} = \frac{4 + x}{2}$。
> 由 $AG = 3$：$\frac{4 + x}{2} = 3$，解得 $x = 2$。
> $\therefore CE = 2 = \frac{1}{2}BC$，
> 即 $E$ 是 $BC$ 的中点。
>
> (3) 当 $BC = 4$，$BE = 3$，$E$ 在射线 $CB$ 上时：
> 射线 $CB$ 从 $C$ 出发经过 $B$ 向外延伸。
> $\because BE = 3 < BC = 4$，
> $\therefore E$ 在线段 $BC$ 上，$CE = BC - BE = 4 - 3 = 1$。
>
> 由 (1) 知 $\triangle ACE \cong \triangle FDA$，
> $\therefore AD = CE = 1$，$FD = AC = 4$。
> $\because AD = 1 < AC = 4$，
> $\therefore D$ 在线段 $AC$ 上，$CD = AC - AD = 4 - 1 = 3$。
>
> $\because FD \parallel BC$，
> $\therefore \triangle FDG \sim \triangle BCG$（AA 相似），
> $\therefore \frac{DG}{CG} = \frac{FD}{BC} = \frac{4}{4} = 1$，
> $\therefore DG = CG$，即 $G$ 是 $CD$ 的中点。
> $\therefore CG = \frac{1}{2}CD = \frac{3}{2}$。
>
> $AG = AC - CG = 4 - \frac{3}{2} = \frac{5}{2}$。
>
> $\therefore \frac{AG}{CG} = \frac{\frac{5}{2}}{\frac{3}{2}} = \frac{5}{3}$。
>
> **一般公式：** 设 $CE = x$，
> - 当 $E$ 在线段 $BC$ 上（$x < 4$）：$\frac{AG}{CG} = \frac{4 + x}{4 - x}$
> - 当 $E$ 在 $B$ 外侧（$x > 4$）：$\frac{AG}{CG} = \frac{4 + x}{x - 4}$
>
> 代入 $CE = 1$：$\frac{AG}{CG} = \frac{4 + 1}{4 - 1} = \frac{5}{3}$。
>
> **【易错点】**(2) 中需通过相似三角形证明 $G$ 是 $CD$ 中点；(3) 中需注意 $E$ 的位置（在线段 $BC$ 上还是延长线上）。
