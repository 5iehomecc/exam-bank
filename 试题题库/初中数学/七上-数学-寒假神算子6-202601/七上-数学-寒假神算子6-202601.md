A. $-\frac{1}{4}$

B. $\frac{1}{4}$

C. 4

D. -4

> [!question]- 点击查看答案与解析
> 【答案】C
> 
> 【考点】绝对值的定义 → [[【初中数学知识点体系-人教版】#1-2 有理数及其大小比较]]

4. 把 $2.36^{\circ}$ 用度、分、秒表示，正确的是（）

A. $2^{\circ}21'36''$

B. $2^{\circ}18'36''$

C. $2^{\circ}30'60''$

D. $2^{\circ}3'6''$

> [!question]- 点击查看答案与解析
> 【答案】A
> 
> 【考点】度分秒的换算 → [[【初中数学知识点体系-人教版】#6-3 角]]
> 
> 【解析】
> - $1^{\circ} = 60'$，$1' = 60''$。

> - 选项A正确。
> 
> 【易错点】度分秒是六十进制，不是十进制；换算时逐位进行。

6. 将方程 $3x + 6 = 2x - 8$ 移项后，正确的是（）

A. $3x + 2x = 6 - 8$

B. $3x - 2x = -8 + 6$

C. $3x - 2x = 8 - 6$

D. $3x - 2x = -6 - 8$

> [!question]- 点击查看答案与解析
> 【答案】D
> 
> 【考点】一元一次方程的移项法则 → [[【初中数学知识点体系-人教版】#5-2 解一元一次方程]]
> 
> 【解析】
> - 原方程：$3x + 6 = 2x - 8$。
> - 移项（含未知数的项移到一边，常数项移到另一边，移项要变号）：
>   $3x - 2x = -8 - 6$
>   $3x - 2x = -6 - 8$
> - 选项D正确。
> 
> 【易错点】移项时每一项都要变号；不要混淆移项与等式两边同时加减。

A. 0 < -a < b

D. b < -a < 0

> [!question]- 点击查看答案与解析
> 【答案】C
> 
> 【考点】数轴、相反数、有理数大小比较 → [[【初中数学知识点体系-人教版】#1-2 有理数及其大小比较]]
>

> - 由数轴可知：$a < 0 < b$。

> 
> 【易错点】$a < 0$ 时，$-a$ 是正数；比较大小要借助数轴，右边的数总比左边的数大。

13. 阅读下面解方程 $\frac{3x+1}{2}=\frac{x-2}{3}$ 的步骤，在后面的横线上填写此步骤的依据：
    解：去分母，得 $3(3x+1)=2(x-2)$. ①依据：\_\_\_
去括号，得 $9x+3=2x-4$.
移项，得 $9x - 2x = -4 - 3.$ ②依据：\_\_\_
合并同类项，得 7x = -7.
系数化为 1，得 x = -1.
$\therefore x = -1$ 是原方程的解.

> [!question]- 点击查看答案与解析
> 【答案】① 等式的基本性质2（等式两边同时乘以同一个不为0的数，等式仍成立）；② 等式的基本性质1（等式两边同时加上或减去同一个数，等式仍成立）
> 
> 【考点】解一元一次方程的依据 → [[【初中数学知识点体系-人教版】#5-2 解一元一次方程]]
> 
> 【解析】
> - 步骤①去分母：等式两边同时乘以6（2和3的最小公倍数），依据是等式的基本性质2。

> 
> 【易错点】解方程的每一步都要有等式性质作为依据，不能仅凭"移项变号"等口诀。

14. 中国古代数学著作《算法统宗》中有这样一段记载："三百七十八里关，初日健步不为难，次日脚痛减一半，六朝才得到其关。"其大意是：有人要去某关口，路程为 378 里，第一天健步行走，从第二天起，由于脚痛，每天走的路程都为前一天的一半，一共走了六天才到达目的地。若求此人第六天走的路程为多少里．设此人第六天走的路程为 x 里，依题意，可列方程为\_\_\_.

> [!question]- 点击查看答案与解析
> 【答案】$x + 2x + 4x + 8x + 16x + 32x = 378$
> 
> 【考点】一元一次方程的应用、逆向思维 → [[【初中数学知识点体系-人教版】#5-3 实际问题与一元一次方程]]
> 
> 【解析】
> - 设第六天走的路程为 $x$ 里。
> - 第五天走的路程是第六天的2倍：$2x$ 里。
> - 第四天：$4x$ 里，第三天：$8x$ 里，第二天：$16x$ 里，第一天：$32x$ 里。
> - 六天总路程为 $378$ 里，所以 $x + 2x + 4x + 8x + 16x + 32x = 378$。
> 
> 【易错点】从后往前推算，每天是后一天的2倍；也可以用等比数列求和理解。

15. 如图，OB 平分 ∠AOC，OD 平分 ∠COE，∠AOD = 120°，∠BOD = 70°，则 ∠COE 的度数为\_\_\_。

<div style="text-align: center;"><img src="https://pplines-online.bj.bcebos.com/deploy/official/paddleocr/pp-ocr-vl-15//0db045c4-a741-42ce-9314-aef45e28906c/markdown_1/imgs/img_in_image_box_895_351_1091_623.jpg?authorization=bce-auth-v1%2FALTAKzReLNvew3ySINYJ0fuAMN%2F2026-03-03T13%3A41%3A37Z%2F-1%2F%2F4719aae5eaf17a896c9a5969ad8df55da54ad80d2808071ec0adf35cbb62a129" alt="Image" width="16%" /></div>
<div style="text-align: center;">E</div>

> [!question]- 点击查看答案与解析
> 【答案】$40^{\circ}$
> 
> 【考点】角平分线的定义、角的计算 → [[【初中数学知识点体系-人教版】#6-3 角]]
> 
> 【解析】
> - 设 $\angle AOB = \angle BOC = x$（$OB$ 平分 $\angle AOC$）。
> - 设 $\angle COD = \angle DOE = y$（$OD$ 平分 $\angle COE$）。

24. 在数轴上，对于不重合的三点 A, B, C，给出如下定义：

若点 C 到点 A 的距离是点 C 到点 B 的距离的 2 倍，我们就把点 C 叫做【A, B】的和谐点.

例如：图1中，点A表示的数为-1，点B表示的数为2。表示数1的点C到点A的距离是2，到点B的距离是1。那么点C是【A，B】的和谐点；又如，表示数0的点D到点A的距离是1，到点B的距离是2，那么点D就不是【A，B】的和谐点，但点D是【B，A】的和谐点。

(1) 当点 A 表示的数为 -4，点 B 表示的数为 8 时，

① 若点 C 表示的数为 4，则点 C \_\_\_（填"是"或"不是"）【A，B】的和谐点；

② 若点 D 是 $【B, A】$ 的和谐点，则点 D 表示的数是 \_\_\_；

(2) 若 A，B 在数轴上表示的数分别为 -2 和 4，现有一点 C 从点 B 出发，以每秒 1 个单位长度的速度向数轴负半轴方向运动，当点 C 到达点 A 时停止，问点 C 运动多少秒时，C，A，B 中恰有一个点为其余两点的和谐点？

> [!question]- 点击查看答案与解析
> 【答案】（1）① 是；② $0$ 或 $-16$；（2）$2$ 秒或 $3$ 秒或 $4$ 秒
> 
> 【考点】新定义理解、数轴上点的距离、分类讨论、一元一次方程 → [[【初中数学知识点体系-人教版】#1-2 有理数及其大小比较]]
> 
> 【解析】
> （1）① $A = -4$，$B = 8$，$C = 4$。
> $C$ 到 $A$ 的距离：$|4 - (-4)| = 8$。
> $C$ 到 $B$ 的距离：$|4 - 8| = 4$。
> $8 = 2 \times 4$，所以点 $C$ 是【$A$，$B$】的和谐点。填"是"。
> 
> ② $D$ 是【$B$，$A$】的和谐点，即 $D$ 到 $B$ 的距离是 $D$ 到 $A$ 的距离的 $2$ 倍。
> 设 $D$ 表示的数为 $d$。
> $|d - 8| = 2|d + 4|$。
> 
> 两边平方：$(d-8)^2 = 4(d+4)^2$
> $d^2 - 16d + 64 = 4d^2 + 32d + 64$
> $0 = 3d^2 + 48d$
> $0 = 3d(d + 16)$
> $d = 0$ 或 $d = -16$。
> 
> 检验：$d = 0$ 时，$|0-8| = 8$，$|0+4| = 4$，$8 = 2 \times 4$ ✓；$d = -16$ 时，$|-16-8| = 24$，$|-16+4| = 12$，$24 = 2 \times 12$ ✓。
> 
> 所以 $D$ 表示的数为 $0$ 或 $-16$。
> 
> （2）$A = -2$，$B = 4$。
> 点 $C$ 从 $B$（$= 4$）出发，以每秒 $1$ 个单位的速度向负方向运动。
> $t$ 秒后，$C$ 表示的数为 $4 - t$，其中 $0 \leq t \leq 6$（到达 $A = -2$ 时停止）。
> 
> 需要讨论三种情况：
> 
> **情况一**：$C$ 是【$A$，$B$】的和谐点。
> $|C - A| = 2|C - B|$
> $|(4-t) - (-2)| = 2|(4-t) - 4|$
> $|6 - t| = 2|-t| = 2t$（因为 $t \geq 0$）
> 
> 当 $0 \leq t \leq 6$ 时，$6 - t \geq 0$，所以 $6 - t = 2t$，$t = 2$。
> 
> 检验：$t = 2$，$C = 2$。$C$ 到 $A$：$|2-(-2)| = 4$，$C$ 到 $B$：$|2-4| = 2$。$4 = 2 \times 2$ ✓。
> 
> **情况二**：$C$ 是【$B$，$A$】的和谐点。
> $|C - B| = 2|C - A|$
> $|(4-t) - 4| = 2|(4-t) - (-2)|$
> $t = 2|6 - t|$
> 
> 当 $0 \leq t \leq 6$ 时，$t = 2(6 - t)$，$t = 12 - 2t$，$3t = 12$，$t = 4$。
> 
> 检验：$t = 4$，$C = 0$。$C$ 到 $B$：$|0-4| = 4$，$C$ 到 $A$：$|0-(-2)| = 2$。$4 = 2 \times 2$ ✓。
> 
> **情况三**：$A$ 是【$C$，$B$】的和谐点。
> $|A - C| = 2|A - B|$
> $|(-2) - (4-t)| = 2|(-2) - 4|$
> $|t - 6| = 12$
> 
> $t - 6 = 12$ 或 $t - 6 = -12$
> $t = 18$（超出范围，舍去）或 $t = -6$（超出范围，舍去）。
> 
> **情况四**：$A$ 是【$B$，$C$】的和谐点。
> $|A - B| = 2|A - C|$
> $6 = 2|t - 6|$
> $|t - 6| = 3$
> 
> $t - 6 = 3$ 或 $t - 6 = -3$
> $t = 9$（超出范围，舍去）或 $t = 3$。
> 
> 检验：$t = 3$，$C = 1$。$A$ 到 $B$：$6$，$A$ 到 $C$：$|(-2)-1| = 3$。$6 = 2 \times 3$ ✓。
> 
> **情况五**：$B$ 是【$A$，$C$】的和谐点。
> $|B - A| = 2|B - C|$
> $6 = 2t$
> $t = 3$。
> 
> 检验：$t = 3$，$C = 1$。$B$ 到 $A$：$6$，$B$ 到 $C$：$|4-1| = 3$。$6 = 2 \times 3$ ✓。
> 
> **情况六**：$B$ 是【$C$，$A$】的和谐点。
> $|B - C| = 2|B - A|$
> $t = 12$（超出范围，舍去）。
> 
> 综上，满足条件的 $t$ 值为：$2$，$3$，$4$。
> 
> 点 $C$ 运动 $2$ 秒、$3$ 秒或 $4$ 秒时，$C$，$A$，$B$ 中恰有一个点为其余两点的和谐点。
> 
> 【易错点】和谐点的定义要注意顺序；三种点都可以是和谐点，需要全面分类讨论；注意运动时间的取值范围。
