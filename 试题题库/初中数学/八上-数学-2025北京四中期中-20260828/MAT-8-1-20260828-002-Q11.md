（2分）已知三角形的两边长分别是 $2$ 和 $5$，则第三边长 $c$ 的取值范围是 ___ 。

> [!question]- 点击查看答案与解析
> 【答案】$3 < c < 7$
> 
> 【考点】三角形三边关系（两边之差 < 第三边 < 两边之和） → [[【初中数学知识点体系-人教版】#13-2 与三角形有关的线段]]
> 
> 【解析】
> 由三角形三边关系，$|5-2| < c < 5+2$，即 $3 < c < 7$。
> 
> 【易错点】三角形三边关系需同时满足"两边之和大于第三边"和"两边之差小于第三边"。
