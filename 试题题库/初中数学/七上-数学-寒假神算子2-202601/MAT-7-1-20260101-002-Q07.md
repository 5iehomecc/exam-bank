已知 $a - b = 3$, $c + d = 2$, 则 $(a + c) - (b - d)$ 的值为（）

A. 1

B. -1

C. 5

D. -5

> [!question]- 点击查看答案与解析
> 【答案】C
>
> 【考点】整式的化简求值 → [[【初中数学知识点体系-人教版】#4-2 整式的加法与减法]]
>
> 【解析】
> $(a + c) - (b - d) = a + c - b + d = (a - b) + (c + d) = 3 + 2 = 5$。
> 故选 C。
>
> 【易错点】去括号时符号变化错误
