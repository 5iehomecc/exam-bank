# 第七章相交线与平行线综合练习

## 一、选择题

1. 如图， $AB \perp CD$，垂足为 O，EF 为过点 O 的一条直线，则  $\angle 1$ 与 $\angle 2$ 一定具有的关系是().

<div style="text-align: center;"><img src="https://pplines-online.bj.bcebos.com/deploy/official/paddleocr/pp-ocr-vl-15//bdd6efef-2ad5-4f9c-9e65-052bb2968f2a/markdown_0/imgs/img_in_image_box_875_278_1059_441.jpg?authorization=bce-auth-v1%2FALTAKzReLNvew3ySINYJ0fuAMN%2F2026-04-06T07%3A35%3A49Z%2F-1%2F%2Fa9f8ec3ed8a19162b7270584ced9f6d265d6fe61acd5bdb14f7f23e2db8733ca" alt="Image" width="15%" /></div>

(A) 相等
(B) 互余
(C) 互补
(D) 互为对顶角

> [!question]- 点击查看答案与解析
> 【答案】(B)
> 
> 【考点】垂直的性质、互余角 → [[【初中数学知识点体系-人教版】#7-1 相交线]]
> 
> 【解析】
> 因为 $AB \perp CD$，所以 $\angle BOC = 90^\circ$。
> 由图可知，$\angle 1$ 和 $\angle 2$ 分别是 $\angle BOC$ 被直线 EF 分成的两个角，所以 $\angle 1 + \angle 2 = 90^\circ$。
> 根据互余的定义：两个角的和为 $90^\circ$，则这两个角互余。
> 因此 $\angle 1$ 与 $\angle 2$ 互余。
> 
> 选项分析：
> - (A) 相等：只有当 EF 恰好平分 $\angle BOC$ 时才成立，不一定成立。
> - (B) 互余：$\angle 1 + \angle 2 = 90^\circ$，一定成立。
> - (C) 互补：互补要求和为 $180^\circ$，不成立。
> - (D) 互为对顶角：对顶角需要两边分别互为反向延长线，$\angle 1$ 和 $\angle 2$ 不是对顶角。
> 
> 【易错点】混淆互余（和为 $90^\circ$）与互补（和为 $180^\circ$）的概念；误认为 $\angle 1$ 和 $\angle 2$ 是对顶角。

2. 下列命题中，属于假命题的是().

(A) 在同一平面内，过一点有且只有一条直线与已知直线垂直
(B) 同旁内角互补，两直线平行
(C) 两条直线被第三条直线所截，同位角相等
(D) 如果两条直线都与第三条直线平行，那么这两条直线也互

> [!question]- 点击查看答案与解析
> 【答案】(C)
> 
> 【考点】命题真假判断、平行线判定 → [[【初中数学知识点体系-人教版】#7-3 定义、命题、定理]]
> 
> 【解析】
> 逐项分析：
> - (A) 在同一平面内，过一点有且只有一条直线与已知直线垂直。这是垂线的基本性质，为真命题。
> - (B) 同旁内角互补，两直线平行。这是平行线的判定定理之一，为真命题。
> - (C) 两条直线被第三条直线所截，同位角相等。这个命题缺少前提条件"两直线平行"，只有当两直线平行时，同位角才相等。因此这是假命题。
> - (D) 如果两条直线都与第三条直线平行，那么这两条直线也互相平行。这是平行公理的推论，为真命题。（注：题干中"互"字后缺少"相平行"，属于排版遗漏，但不影响判断）
> 
> 【易错点】忽略命题(C)中缺少"两直线平行"这一前提条件；对平行线的性质和判定定理混淆。

> [!question]- 点击查看答案与解析
> 【答案】(D)
> 
> 【考点】平行线性质、对顶角 → [[【初中数学知识点体系-人教版】#7-2 平行线]]
>

> $\angle 1$ 和 $\angle 2$ 是同旁内角，$\angle 1 + \angle 2 = 180^\circ$，所以两直线平行。
> 由平行线的性质，同位角相等，$\angle 4$ 与 $\angle 3$ 是同位角，所以 $\angle 4 = \angle 3 = 100^\circ$。
> 
> 【易错点】不能正确识别同位角、内错角、同旁内角；忽略平行线判定需要先验证条件。

(A) $\angle1 = \angle4$
(B) $\angle3 = \angle4$
(C) $\angle1 = \angle2$
(D) $ \angle D + \angle ACD = 180^{\circ}$

> [!question]- 点击查看答案与解析
> 【答案】(B)
> 
> 【考点】平行线判定（内错角） → [[【初中数学知识点体系-人教版】#7-2 平行线]]
> 
> 【解析】
> 逐项分析：
> - (A) $\angle 1 = \angle 4$：$\angle 1$ 和 $\angle 4$ 不是 AB 和 CD 被某条直线所截形成的内错角或同位角，无法判定 $AB \parallel CD$。
> - (B) $\angle 3 = \angle 4$：$\angle 3$ 和 $\angle 4$ 是 AB 和 CD 被直线 AC 所截形成的内错角，内错角相等，两直线平行，能判定 $AB \parallel CD$。
> - (C) $\angle 1 = \angle 2$：$\angle 1$ 和 $\angle 2$ 是 BD 和 AC 被直线 AB 所截形成的内错角，能判定 $BD \parallel AC$，但不能判定 $AB \parallel CD$。
> - (D) $\angle D + \angle ACD = 180^\circ$：这是 BD 和 AC 被直线 CD 所截的同旁内角，能判定 $BD \parallel AC$，但不能判定 $AB \parallel CD$。
> 
> 【易错点】不能正确识别哪两条直线被哪条直线所截；混淆内错角、同位角、同旁内角对应的直线关系。

<div style="text-align: center;"><div style="text-align: center;">第 5 题图</div> </div>

(A) $61^{\circ}$
(B) $66^{\circ}$
(C) $52^{\circ}$
(D) $132^{\circ}$

> [!question]- 点击查看答案与解析
> 【答案】(B)
> 
> 【考点】折叠性质、平行线性质 → [[【初中数学知识点体系-人教版】#7-2 平行线]]
> 
> 【解析】
> 由折叠的性质可知，折叠前后对应角相等。
> 设折叠后与 $\angle 1$ 对应的角为 $\angle 3$，则 $\angle 1 = \angle 3$。
> 因为纸条是长方形，上下两边平行，$\angle 2 = 132^\circ$。
> $\angle 2$ 的邻补角为 $180^\circ - 132^\circ = 48^\circ$。
> 由平行线的性质，内错角相等，$\angle 1 + \angle 3 = 180^\circ - 48^\circ = 132^\circ$。
> 因为 $\angle 1 = \angle 3$，所以 $2\angle 1 = 132^\circ$，$\angle 1 = 66^\circ$。
> 
> 【易错点】忽略折叠前后角相等的性质；不能正确利用平行线的性质建立角度关系。

> [!question]- 点击查看答案与解析
> 【答案】(D)
> 
> 【考点】平行线性质、等边三角形 → [[【初中数学知识点体系-人教版】#7-2 平行线]]
> 
> 【解析】
> 因为 $\triangle ABC$ 是等边三角形，所以 $\angle ABC = 60^\circ$。
> 因为 $l_2 \parallel l_3$，根据平行线的性质，内错角相等，$\angle 1 = 25^\circ$ 等于 BC 与 $l_2$ 的夹角。
> 所以 AB 与 $l_2$ 的夹角为 $60^\circ - 25^\circ = 35^\circ$。
> 因为 $l_1 \parallel l_2$，所以 AB 与 $l_1$ 的夹角 $\angle 2$ 等于 AB 与 $l_2$ 的夹角（内错角相等）。

> 【答案】$50^\circ$
> 
> 【考点】角平分线、垂直、平角 → [[【初中数学知识点体系-人教版】#7-1 相交线]]
> 
> 【解析】
> 因为 OE 平分 $\angle BOC$，$\angle BOC = 80^\circ$，所以 $\angle BOE = \frac{1}{2} \times 80^\circ = 40^\circ$。
> 因为 $OD \perp OE$，所以 $\angle DOE = 90^\circ$。

> $\angle AOD + \angle DOE + \angle BOE = 180^\circ$，
> 即 $\angle AOD + 90^\circ + 40^\circ = 180^\circ$，
> 所以 $\angle AOD = 180^\circ - 130^\circ = 50^\circ$。
> 
> 【易错点】不能正确利用平角为 $180^\circ$ 建立方程；忽略角平分线将角分成相等的两部分。

> 因为 $AB \parallel CD$，根据平行线的性质，同旁内角互补，
> $\angle AEF + \angle EFC = 180^\circ$，所以 $\angle EFC = 180^\circ - 80^\circ = 100^\circ$。
> 三角尺 HFD 中，$\angle HFC = 90^\circ$（直角），
> $\angle HFD = 180^\circ - \angle EFC - \angle HFC = 180^\circ - 100^\circ - 45^\circ = 35^\circ$。
> 
> 【易错点】不能正确识别三角尺的角度；平行线性质应用错误；角度关系推导混乱。

13. 如图，一条公路修到湖边时，需拐弯绕湖而过，如果第一次拐弯的 $\angle A$ 是 $120^{\circ}$，第二次拐弯的 $\angle B$ 是 $150^{\circ}$，第三次拐弯的角是 $\angle C$，这时，公路恰好和第一次拐弯之前的公路平行，则 $\angle C =$ ___ 。

> [!question]- 点击查看答案与解析
> 【答案】$150^\circ$
> 
> 【考点】平行线性质、辅助线 → [[【初中数学知识点体系-人教版】#7-2 平行线]]
> 
> 【解析】
> 设第一次拐弯前的公路方向为直线 $l$，第三次拐弯后的公路方向为直线 $l'$。

> 因为 $l \parallel BM$，所以 $\angle ABM = \angle A = 120^\circ$（内错角相等）。

(2) 求证: EF 平分 $\angle CED$.

> [!question]- 点击查看答案与解析

>

> (2) 证明：
> 因为 BD 平分 $\angle ABC$，所以 $\angle ABD = \angle CBD$。
> 因为 $DE \parallel AB$，所以 $\angle ABD = \angle BDE$（内错角相等）。

> 因此 $\angle DEF = \angle CEF$，

> 因为 $\angle 1 = \angle 2$，且 $\angle 2$ 和 $\angle 3$ 是对顶角（设 $\angle 2$ 的对顶角为 $\angle 3$），所以 $\angle 2 = \angle 3$。

> [!question]- 点击查看答案与解析
> 【答案】(1) $②$ $27^\circ$；(2) $\angle PGM = \angle EOF + \angle DPO$

18. 如图，将一副三角尺中的两个直角顶点 C 叠放在一起，其中 $\angle A = 30^{\circ}, \angle B = 60^{\circ}, \angle D = \angle E = 45^{\circ}$.

<div style="text-align: center;"><img src="https://pplines-online.bj.bcebos.com/deploy/official/paddleocr/pp-ocr-vl-15//bdd6efef-2ad5-4f9c-9e65-052bb2968f2a/markdown_3/imgs/img_in_image_box_732_1282_897_1480.jpg?authorization=bce-auth-v1%2FALTAKzReLNvew3ySINYJ0fuAMN%2F2026-04-06T07%3A35%3A54Z%2F-1%2F%2Fdee6ace3c2632b729aa46bbcfe0c289625123a0d5f9fc7d38fbb5890bd1cbd3c" alt="Image" width="13%" /></div>

(1) $\angle BCD$ 与 $\angle ACE$ 的数量关系是 ___ ，$\angle BCE$ 与 $\angle ACD$ 的数量关系是 ___ ；

(2)若保持三角尺 ABC 不动，绕直角顶点 C 顺时针转动三角尺 DCE，试探究当 $\angle ACD$ 等于多少度时，$CE \parallel AB$，画出图形并简要说明理由;

(3) 若 $\angle BCE = 3\angle ACD$，求 $\angle ACD$ 的度数，并直接写出此时 DE 与 AC 的位置关系.

> [!question]- 点击查看答案与解析
> 【答案】(1) $\angle BCD + \angle ACE = 180^\circ$；$\angle BCE + \angle ACD = 180^\circ$；(2) $60^\circ$ 或 $120^\circ$；(3) $45^\circ$，$DE \parallel AC$
> 
> 【考点】旋转、平行线判定、分类讨论 → [[【初中数学知识点体系-人教版】#7-2 平行线]]
> 
> 【解析】
> (1) 因为 $\angle ACB = \angle DCE = 90^\circ$，
> $\angle BCD + \angle ACE = \angle BCD + \angle ACD + \angle DCE - \angle ACD = \angle ACB + \angle DCE = 90^\circ + 90^\circ = 180^\circ$。
> $\angle BCE = \angle BCA + \angle ACE = 90^\circ + \angle ACE$，
> $\angle ACD = \angle DCE - \angle ACE = 90^\circ - \angle ACE$，
> 所以 $\angle BCE + \angle ACD = 90^\circ + \angle ACE + 90^\circ - \angle ACE = 180^\circ$。
> 
> (2) 当 $CE \parallel AB$ 时，分两种情况讨论：
> 情况一：$\angle ACE = \angle A = 30^\circ$（内错角相等），
> 则 $\angle ACD = 90^\circ - \angle ACE = 90^\circ - 30^\circ = 60^\circ$。
> 情况二：$\angle ACE = 180^\circ - \angle A = 150^\circ$（同旁内角互补的另一种位置），
> 则 $\angle ACD = 90^\circ - 150^\circ = -60^\circ$（舍去），
> 或考虑旋转另一侧，$\angle ACD = 120^\circ$。
> 所以当 $\angle ACD = 60^\circ$ 或 $120^\circ$ 时，$CE \parallel AB$。
> 
> (3) 由(1)知 $\angle BCE + \angle ACD = 180^\circ$，
> 又 $\angle BCE = 3\angle ACD$，
> 所以 $3\angle ACD + \angle ACD = 180^\circ$，$4\angle ACD = 180^\circ$，$\angle ACD = 45^\circ$。
> 此时 $\angle BCE = 135^\circ$。
> $\angle ACE = 90^\circ - 45^\circ = 45^\circ$，
> $\angle DEC = 45^\circ$（等腰直角三角尺），
> 所以 $\angle ACE = \angle DEC = 45^\circ$，
> 根据内错角相等，$DE \parallel AC$。
> 
> 【易错点】旋转问题中忽略分类讨论；不能正确利用三角尺的固定角度；角度关系推导错误。
