若关于 x 的一元一次不等式组 $\begin{cases} 2x - 1 < 3, \\ x - a < 0 \end{cases}$ 的解集为 $x < 2$，则 a 的取值范围是 ___ .

> [!question]- 点击查看答案与解析
> **【答案】** $a \geqslant 2$
> 
> **【考点】** 一元一次不等式组解集与参数 [[【初中数学知识点体系-人教版】#11-3 一元一次不等式组]]
> 
> **【解析】**
> 解第一个不等式：$2x - 1 < 3$，$2x < 4$，$x < 2$。解第二个不等式：$x - a < 0$，$x < a$。不等式组的解集为 $x < 2$ 和 $x < a$ 的交集，即 $x < \min(2, a)$。要使得解集恰好为 $x < 2$，需要 $\min(2, a) = 2$，即 $a \geqslant 2$。当 $a < 2$ 时，解集为 $x < a$，与题目要求的 $x < 2$ 不一致。
> 
> **【易错点】** 忽略 $a = 2$ 的情况（此时 $x < 2$ 与 $x < 2$ 的交集仍是 $x < 2$）；误以为 $a > 2$ 时解集会缩小。
