规定 $[x]$ 为不大于x的最大整数，如 $[0.7]=0，[-2.3]=-3$. 若 $[x+0.5]=2$，且 $[1-x]=-2$，则 x 的取值范围为 ___ .

> [!question]- 点击查看答案与解析
> **【答案】** $2 < x < 2.5$
> 
> **【考点】** 取整函数与不等式组 [[【初中数学知识点体系-人教版】#11-1 不等式]]
> 
> **【解析】**
> $[x]$ 表示不大于 $x$ 的最大整数。由 $[x+0.5] = 2$，得 $2 \leqslant x+0.5 < 3$，解得 $1.5 \leqslant x < 2.5$。
> 由 $[1-x] = -2$，得 $-2 \leqslant 1-x < -1$，两边乘以 $-1$（不等号方向改变）：$2 \geqslant x-1 > 1$，即 $1 < x-1 \leqslant 2$，解得 $2 < x \leqslant 3$。
> 取两个解集的交集：$(1.5 \leqslant x < 2.5) \cap (2 < x \leqslant 3) = 2 < x < 2.5$。
> 
> **【易错点】** 取整函数定义理解错误（$[x] = n$ 表示 $n \leqslant x < n+1$）；在转化 $[1-x] = -2$ 时忽略乘以负数导致的不等号方向反转；取交集时端点取舍出错（$x = 2$ 不满足 $2 < x$，$x = 2.5$ 不满足 $x < 2.5$）。
