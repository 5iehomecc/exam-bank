根据以下学习素材，完成下列两个任务:

| 学习素材 |                                                                                                                   |              |
| ---- | ----------------------------------------------------------------------------------------------------------------- | ------------ |
| 素材一  | 某校组织学生去农场进行学农实践，体验草莓采摘、包装和销售。同学们了解到该农场在包装草莓时，通常会采用精包装和简包装两种包装方式。                                                  |              |
| 素材二  | 精包装                                                                                                               | 简包装          |
|      | 每盒2斤，每盒售价25元                                                                                                      | 每盒3斤，每盒售价35元 |
| 问题解决 |                                                                                                                   |              |
| 任务一  | 在活动中，学生共卖出了700斤草莓，销售总收入为8500元，请问精包装和简包装各销售了多少盒？                                                                   |              |
| 任务二  | 现在需要对75斤草莓进行分装，既有精包装也有简包装，且恰好将这75斤草莓整盒分装完。每个精包装盒的成本为1元，每个简包装盒的成本为0.5元。若要将购买包装盒的成本控制在18元以内，请你设计出一种符合要求的分装方案，并说明理由。 |              |

> [!question]- 点击查看答案与解析
> **【答案】** 任务一：精包装200盒，简包装100盒；任务二：精包装3盒，简包装23盒（答案不唯一）
> 
> **【考点】** 二元一次方程组的应用 [[【初中数学知识点体系-人教版】#10-3 实际问题与二元一次方程组]]
> 
> **【解析】**
> **任务一：**
> 设精包装 $x$ 盒，简包装 $y$ 盒。
> 根据题意列方程组：
> $\begin{cases}2x+3y=700\\25x+35y=8500\end{cases}$
> 
> 化简第二个方程：$5x+7y=1700$
> 由第一个方程得：$x=\frac{700-3y}{2}$
> 代入化简后的第二个方程：$5\times\frac{700-3y}{2}+7y=1700$
> $1750-7.5y+7y=1700$
> $-0.5y=-50$
> $y=100$
> 
> 将 $y=100$ 代入第一个方程：$2x+300=700$
> $2x=400$
> $x=200$
> 
> 所以精包装200盒，简包装100盒。
> 
> **任务二：**
> 设精包装 $a$ 盒，简包装 $b$ 盒。
> 根据题意：$2a+3b=75$（总重量为75斤）
> 成本：$a+0.5b\leqslant 18$（成本控制在18元以内）
> 
> 由 $2a+3b=75$ 得：$b=\frac{75-2a}{3}$
> 由于 $b$ 为正整数，$75-2a$ 必须是3的倍数，且 $a,b>0$。
> 
> 代入成本不等式：$a+0.5\times\frac{75-2a}{3}\leqslant 18$
> $a+\frac{75-2a}{6}\leqslant 18$
> $6a+75-2a\leqslant 108$
> $4a\leqslant 33$
> $a\leqslant 8.25$
> 
> 枚举满足条件的正整数解：
> - $a=3$，$b=23$，成本 $=3+0.5\times 23=14.5\leqslant 18$ ✓
> - $a=6$，$b=21$，成本 $=6+0.5\times 21=16.5\leqslant 18$ ✓
> 
> 所以精包装3盒，简包装23盒（答案不唯一）。
> 
> **【易错点】** 列方程组时对"每盒2斤""每盒3斤"与总重量的关系理解错误；解方程组时计算错误；成本不等式列错或枚举时遗漏解。
