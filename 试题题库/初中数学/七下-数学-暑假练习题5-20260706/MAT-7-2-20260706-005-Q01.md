$\pi$ 的相反数是 ( )

A. $\frac{1}{\pi}$

B. $-\frac{1}{\pi}$

C. $-\pi$

D. $\pi$

> [!question]- 点击查看答案与解析
> **【答案】** C
> 
> **【考点】** 相反数的概念 → [[【初中数学知识点体系-人教版】#1-2 有理数及其大小比较]]
> 
> **【解析】**
> 相反数是指绝对值相等、符号相反的两个数。$\pi$ 的相反数是 $-\pi$。
> A 选项 $\frac{1}{\pi}$ 是 $\pi$ 的倒数，不是相反数，错误；
> B 选项 $-\frac{1}{\pi}$ 是 $-\pi$ 的倒数，不是 $\pi$ 的相反数，错误；
> C 选项 $-\pi$ 是 $\pi$ 的相反数，正确；
> D 选项 $\pi$ 是原数本身，不是相反数，错误。
> 
> **【易错点】** 混淆相反数与倒数的概念，倒数是乘积为 1 的两个数，相反数是和为 0 的两个数
