已知：关于x的不等式组 $\left\{\begin{array}{l}x-a\geqslant0,\\2x<4\end{array}\right.$ 只有三个整数解，则 $a$ 的取值范围是

A. $-2\leqslant a\leqslant-1$

B. $-2\leqslant a<-1$

C. $-2<a\leqslant-1$

D. $-2<a<-1$

> [!question]- 点击查看答案与解析
> 【答案】A
> 
> 【解析】解不等式组：
> $\begin{cases} x \geq a \\ x < 2 \end{cases}$
> 不等式组有解，则 $a \leq x < 2$。
> 整数解只有三个，应为 $-1, 0, 1$。
> 所以 $a$ 的取值范围是 $-2 \leq a \leq -1$。
> 当 $a = -2$ 时，解集为 $-2 \leq x < 2$，整数解为 $-2, -1, 0, 1$（四个），不符合题意；
> 当 $a = -1$ 时，解集为 $-1 \leq x < 2$，整数解为 $-1, 0, 1$（三个），符合题意。
> $\therefore -2 < a \leq -1$，选C。
>
