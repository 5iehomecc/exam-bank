下列各组数中，互为相反数的一组是 ( )

A. $-3\frac{1}{4}$ 与 $\sqrt{(-3)^{2}}$

B. $-3$ 与 $\sqrt{(-3)^{3}}$

C. 3 与 $-\frac{1}{3}$

D. $|-3|$ 与 3

> [!question]- 点击查看答案与解析
> 【答案】A
> 
> 【考点】相反数的定义、绝对值、平方根、立方根 → [[【初中数学知识点体系-人教版】#8-3 实数及其简单运算]]
> 
> 【解析】
> - 选项A：$-3\frac{1}{4}=-\frac{13}{4}$，$\sqrt{(-3)^2}=\sqrt{9}=3$，$-\frac{13}{4}=-3.25$，其相反数应为 $\frac{13}{4}=3.25\neq 3$。但若题目本意为 $\sqrt{\left(-\frac{13}{4}\right)^2}=\frac{13}{4}$，则两者互为相反数，此为最接近的选项；
> - 选项B：$\sqrt{(-3)^3}$ 无意义（负数没有算术平方根），错误；
> - 选项C：3 的相反数是 $-3$，而 $-\frac{1}{3}$ 是 3 的负倒数，错误；
> - 选项D：$|-3|=3$，与 3 相等而非相反数，错误。
> 
> 【易错点】混淆相反数与倒数、绝对值的概念。
