为了传承中华文化，激发学生的爱国情怀，提高学生的文学素养，七年级举办了"古诗词"大赛，现有小刚、小强、小敏三位同学进入了最后冠军的角逐，规定：每轮分别决出第1，2，3名（没有并列），对应名次的得分都分别为 a，b，$c(a > b > c)$ 且 a，b，c 均为正整数），选手最后得分为各轮得分之和，得分最高者为冠军，如下表是三位选手在每轮比赛中的部分得分情况，小敏同学第三轮的得分为 ___ 分。

|  | 第一轮 | 第二轮 | 第三轮 | 第四轮 | 第五轮 | 第六轮 | 最后得分 |
|---|---|---|---|---|---|---|---|
| 小刚 | a |  |  | a |  |  | 24 |
| 小强 |  | a |  |  | b | c | 13 |
| 小敏 |  | c |  | b |  |  | 11 |

> [!question]- 点击查看答案与解析
> **【答案】** 1
> **【考点】** 推理与论证 → [[【初中数学知识点体系-人教版】#10-3 实际问题与二元一次方程组]]、方程与不等式的综合应用 → [[【初中数学知识点体系-人教版】#11-2 一元一次不等式]]
> **【解析】** 由题意，每轮三人得分分别为 $a$、$b$、$c$，且 $a>b>c$，$a$、$b$、$c$ 均为正整数。三人最后得分之和为 $24+13+11=48$，六轮总得分为 $6(a+b+c)=48$，所以 $a+b+c=8$。因为 $a>b>c\geq1$ 且均为正整数，可能的组合有 $(5,2,1)$ 或 $(4,3,1)$。对于 $(4,3,1)$：小刚第一轮、第四轮各得 4，总分 24，设得 4 的次数为 $n_4$，则 $4n_4+3n_3+n_1=24$，$n_4+n_3+n_1=6$。逐一验证 $n_4=2,3,4$ 均无整数解，排除。对于 $(5,2,1)$：小刚第一轮、第四轮各得 5，总分 24，设得 5 的次数为 $n_5$，则 $5n_5+2n_2+n_1=24$，$n_5+n_2+n_1=6$。若 $n_5=4$：$2n_2+n_1=4$，$n_2+n_1=2$，解得 $n_2=2$，$n_1=0$。所以小刚六轮得分为四个 5 和两个 2。确定各轮得分后，小敏第三轮得分为 1 分。验证：小刚 $5+2+5+5+5+2=24$ ✓，小强 $2+5+2+1+2+1=13$ ✓，小敏 $1+1+1+2+1+5=11$ ✓。
> **【易错点】** 不能正确利用总分关系求出 $a+b+c$ 的值，或在推理过程中遗漏某些约束条件。
