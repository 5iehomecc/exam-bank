判断一个正整数能被 3 整除的方法是：把这个正整数各个数位上的数字相加，如果所得的和能够被 3 整除，则这个正整数就能被 3 整除．请证明对于任意两位正整数，这个判断方法都是正确的．

> [!question]- 点击查看答案与解析
> 【答案】证明见解析
> 
> 【考点】代数式表示、整除性质、证明 → [[【初中数学知识点体系-人教版】#3-1 列代数式表示数量关系]]
> 
> 【解析】
> 设任意两位正整数为 $\overline{ab}$，其中 $a$ 为十位数字，$b$ 为个位数字。
> 则该数可表示为 $10a + b$（$1 \leq a \leq 9$，$0 \leq b \leq 9$，$a$，$b$ 均为整数）。
> 各位数字之和为 $a + b$。
>
> 假设 $a + b$ 能被 $3$ 整除，即 $a + b = 3k$（$k$ 为整数）。
>
> 因为 $10a + b = 9a + a + b = 9a + 3k$，
> 其中 $9a = 9 \times a$ 能被 $3$ 整除，$a + b = 3k$ 也能被 $3$ 整除，
> 所以 $10a + b = 9a + 3k = 3(3a + k)$ 能被 $3$ 整除。
>
> 因此，对于任意两位正整数，若各位数字之和能被 $3$ 整除，则该数能被 $3$ 整除，判断方法正确。
> 
> 【易错点】用代数式正确表示两位数 $\overline{ab} = 10a + b$，而不是 $ab$；利用拆分 $10a = 9a + a$ 是关键。
