阅读材料：

数学活动课上，小智同学提出一个猜想；把一个三位正整数的百位上的与个位上的数交换位置，十位上的数不变，原数与所得数的差等于 99 乘原数的百位上的数与个位上的数的差例如： $782-287=99\times(7-2)$.

回答问题：

(1) 小智的猜想是否正确？若正确，对任意情况进行说明；若不正确，说明理由。

(2) 已知一个五位正整数的万位上的数为 m，个位上的数为 n，把万位上的数与个位上的数交换位置，其余数位上的数不变，原数与所得数的差等于 \_\_\_。(用含 m，n 的式子表示)

> [!question]- 点击查看答案与解析
> 【答案】$(1)$ 正确，说明见解析；$(2)$ $9999(m - n)$
>
> 【考点】数位表示、整式的运算 → [[【初中数学知识点体系-人教版】#4-2 整式的加法与减法]]
>
> 【解析】$(1)$ 正确。设三位数为$100a + 10b + c$（$a$为百位，$b$为十位，$c$为个位），交换百位和个位后得$100c + 10b + a$。两数之差$= (100a + 10b + c) - (100c + 10b + a) = 99a - 99c = 99(a - c)$，即99乘以百位与个位的差，猜想正确。
>
> $(2)$ 设五位数为$\overline{mabcd}$（即$10000m + 1000a + 100b + 10c + d$），交换万位和个位后得$\overline{nabcd}$（即$10000n + 1000a + 100b + 10c + m$）。两数之差$= (10000m + d) - (10000n + m) = 9999m - 9999n = 9999(m - n)$。
>
> 【易错点】未掌握用代数式表示多位数的方法，位值原理理解不清。
