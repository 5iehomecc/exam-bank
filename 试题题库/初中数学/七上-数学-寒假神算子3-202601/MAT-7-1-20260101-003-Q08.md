设 a, h, c 为非零有理数, a > b > c, 则下列大小关系一定成立的是()

A. a - b > b - c

B. $\frac{1}{a} < \frac{1}{b} < \frac{1}{c}$

C. $a^{2} > b^{2} > c^{2}$

D. a - c > b - c

> [!question]- 点击查看答案与解析
> 【答案】D
>
> 【考点】有理数大小比较 → [[【初中数学知识点体系-人教版】#1-2 有理数及其大小比较]]
>
> 【解析】已知$a > b > c$，且$a$、$b$、$c$为非零有理数。
> A选项：$a - b$与$b - c$的大小无法确定，因为不知道具体数值关系，故A错误；
> B选项：当$a$、$b$同号时，$\frac{1}{a} < \frac{1}{b}$成立；但当$a > 0 > c$时，$\frac{1}{a} > 0$，$\frac{1}{c} < 0$，此时$\frac{1}{a} > \frac{1}{c}$，故B错误；
> C选项：当$a = 1$，$b = -1$，$c = -2$时，$a^2 = 1$，$b^2 = 1$，$c^2 = 4$，此时$a^2 < c^2$，故C错误；
> D选项：因为$a > b$，两边同时减去$c$，得$a - c > b - c$，故D正确。
>
> 【易错点】有理数大小比较中，忽略正负号的影响，或在不等式变形时出错。
