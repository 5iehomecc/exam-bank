小韩和同学们在一家快餐店吃饭，下表为快餐店的菜单：

| 种类 | 配餐 | 价格(元) | 优惠活动 |
|---|---|---|---|
| A餐 | 1份盖饭 | 20 | 消费满150元，减24元 |
| B餐 | 1份盖饭+1杯饮料 | 28 | 消费满300元，减48元 |
| C餐 | 1份盖饭+1杯饮料+1份小菜 | 32 | ... |

小韩记录大家的点餐种类，并根据菜单一次点好，已知他们所点的餐共有 11 份盖饭，x 杯饮料和 5 份小菜，

(1) 他们共点了 \_\_\_ 份 B 餐；(用含 x 的式子表示)

(2) 若他们至少需要6杯饮料，要使所花费的钱数最少，则应该点 \_\_\_ 份B餐

> [!question]- 点击查看答案与解析
> 【答案】$(1)$ $x - 5$；$(2)$ 3
>
> 【考点】一元一次方程的应用 → [[【初中数学知识点体系-人教版】#5-3 实际问题与一元一次方程]]
>
> 【解析】$(1)$设点A餐$a$份、B餐$b$份、C餐$c$份。由题意：$a + b + c = 11$，$b + c = x$，$c = 5$。所以$b = x - 5$，即B餐为$(x - 5)$份。
> $(2)$总花费$= 20a + 28b + 32c = 20(11 - x) + 28(x - 5) + 160 = 240 + 8x$（元）。当$x \geq 6$时，逐一代入计算：$x = 6$时花费$264$元；$x = 7$时花费$272$元；$x = 8$时花费$256$元（满300减48）；$x = 9$时花费$264$元。最小值在$x = 8$时取得，此时B餐$= 8 - 5 = 3$份。
>
> 【易错点】忘记考虑满减优惠活动的影响，需分类讨论计算实际花费。
