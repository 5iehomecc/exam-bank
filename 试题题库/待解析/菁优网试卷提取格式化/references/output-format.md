# 产物格式、规则对接与校验清单

> 本技能只完成「网页识别 → 结构化提取 → 按规则格式化落盘」，属于试卷工作流的**格式化阶段**；拆题、本地化配图、写解析 callout 属于后续 `/试卷解析` 阶段，本技能不执行。

## 1. 落盘位置与命名

- 默认 vault 解析根目录：`D:\【Knowledge Notes】\12-试卷解析`；用户指定其它路径时以用户为准。
- 格式化阶段产物放 `待解析/` 根目录（拆题前不建试卷文件夹）。
- 文件名：`{年级}-{学科}-{试卷名}-{发布日期YYYYMMDD}.md`
  - 示例：`八上-数学-几何辅助线之三线合一5大必刷通关模型-20261109.md`
  - 发布日期取自页面「发布时间：2026年11月9日」；只有年月时按规则补 `01` 日。
- 学科代码与年级编码对照见 Rules 文件「科目代码表」「年级编码对照表」。

## 2. Frontmatter

```yaml
---
创建时间: 2026-11-18
来源: 菁优网（作者：XXX），https://www.jyeoo.com/math/paper/share/<uuid>
类型:
  - 几何综合
tags:
  - 八上数学
---
```

- `创建时间`：本次处理日期；`来源`：站点 + 作者 + 分享 URL。
- `tags`：统一「年级+学科」（如 `八上数学`、`八上物理`、`九下数学`）。
- 不在源试卷 MD 里写 `knowledge`、`source`、题目 ID——这些是拆题阶段 Q 文件的 frontmatter 字段。

## 3. 正文结构

```markdown
## {文件名去后缀}

> 共 N 题（填空 X、解答/证明 Y）。配图为站点原图（含水印），拆题阶段再本地化；本文件为格式化后的源试卷，不含答案与解析。

### 一、{分节标题}

1. （出处标签）题干……

（1）……
（2）……

![Image](https://img.jyeoo.net/...)

2. ……
```

- 题号 `N. ` 全局连续编号；出处标签紧跟题号后括号内（无标签则省略）。
- 分节标题由页面 `H4` 转换：「一．」→「一、」，去掉全角句点。
- 配图用 Markdown `![Image](url)`；源试卷阶段**保留网络链接**，不下载、不换本地路径。
- 选择题选项按规则 2.5 每项独占一行、空行隔开；本卷题型以解答/证明与填空为主。

## 4. 规则对接（不复制规则全文）

数学格式规范以本地规则文件为准，落盘前逐条对照：

- 规则全文：`D:\【Knowledge Notes】\12-试卷解析\待解析\【Rules-数理化试卷】.md`
  - 第一章：公式 `$` 包裹、圈数、标点前空格、独立数字空格、独立字母/连续表达式整体包裹。
  - 第二章：题号、公式、圈数、选项分行、填空线、独立数字/字母六项格式化任务。
- 耦合技能：
  - `C:\Users\LSSTUDIO\.agents\skills\数学试卷格式化\SKILL.md`
  - `C:\Users\LSSTUDIO\.agents\skills\试卷解析\SKILL.md`

转换器脚本只做结构级清洗；**规则 1.6/1.7 的独立数字空格与独立字母 `$` 包裹必须在落盘前人工逐题复核补全**，不得把脚本输出直接当成最终 MD。

## 5. 强制校验清单（落盘后逐项跑）

1. 题数 = 配图数（与页面题号逐一对应，不少题不多题）。
2. 题号全部为 `数字. ` 格式，无残留 `、`。
3. 圈数 `①②③…` 全部 `$` 包裹；圈数与相邻公式之间留一个空格。
4. 填空线 `___` 两侧各一空格；Grep `[^ ]___` 与 `___[^ ；;。，,.!！?？)）\n]` 0 命中（行尾除外）。
5. 独立字母/表达式已 `$` 包裹，连续表达式整体包裹、未逐字母拆开；独立数字前后空格（题号、出处年份除外）。
6. 标点前不留多余空格；公式内部运算符两侧无多余空格。
7. 无 HTML 标签残留（`<div>/<img>/<span>/<table>/<center>/<sub>/<sup>/<br>` 等）。
8. 源试卷 MD 中无 `> [!question]-` callout、无本地图片引用；网络图片链接完整。
9. 配图逐张下载目检：与题干构型一致，无缺图、错图、水印占位图；多图组合（图1/2/3、备用图）保持一题一图。

## 6. 交付报告必须说明的事项

- **答案/解析门禁**：若 `.pt2` 为空、`【答案】/【解析】/【考点】` 0 命中，明确告知用户解析不可见，需下载文件或可访问详情后再补；不得在 MD 中编造答案。
- **缺 PDF 源文件**：本卷来源为网页，无 PDF；拆题阶段需用户确认 PDF 如何处理（规则 4.2 不得直接跳过）。
- **年级为推断**：页面未标年级时，报告注明推断依据与结论，请用户确认后再定稿 tag。
- **缺失出处标签**：个别题 `data-label` 为空，在报告中列出题号。
- **后续阶段提示**：格式化经用户审核通过后，再走拆题流程（建试卷文件夹、移动源文件、Q 文件、配图本地化、解析 callout、双向链接）。
