# 数学试卷格式化 (Math Exam Formatter)

对数学试卷 Markdown 文件进行标准化格式化处理。本技能处理已有 Markdown 文件（位于 `12-试卷解析/` 或用户指定的路径），执行六项格式化任务。完整规范以 `12-试卷解析\待解析\【Rules-数理化试卷】.md` 第一章、第二章为准，本文件为其摘要。

## 重要前提

- **本技能处理已有的 Markdown 文件**，不处理 PDF 或图片
- 工作目录为 `D:\【Knowledge Notes】`
- 处理前先读取整个文件内容，了解其结构

## 工作流程

### 步骤 1：识别要处理的文件

1. 检查用户是否在命令中指定了文件路径
2. 如果未指定，列出 `D:\【Knowledge Notes】\12-试卷解析\` 目录下最近修改的 .md 文件让用户选择
3. 向用户展示文件列表（文件名和修改时间），让用户确认

### 步骤 2：读取文件

读取用户指定的 Markdown 文件全部内容，了解整体结构和内容分布。

### 步骤 3：执行六项格式化任务

#### 任务一：题目序号格式修改

将题号后的 "、" 改为 ". "（点号+空格）。

- **查找模式**：数字后跟 "、"，例如 `1、`、`2、`、`10、`
- **替换为**：`1. `、`2. `、`10. `
- **注意不要误改**：非题号场景的 "、"（如中文列举、注释中的顿号）

**示例：**
```
输入：1、 下列计算正确的是（   ）
输出：1. 下列计算正确的是（   ）
```

#### 任务二：数学公式格式修改

修正数学公式的 `$` 包裹格式，这是本技能的核心任务。

核心规则：
1. **公式内容紧贴 `$`**：`$` 与内部数学表达式之间没有空格
2. **`$` 外侧保留空格**：`$` 与其他非数学文本之间要保留一个空格
3. 对于单独成行的公式，也确保使用 `$公式$` 格式

**需要修正的典型错误模式：**

| 错误格式 | 正确格式 |
|---------|---------|
| `$ AB \parallel CD $` | `$AB \parallel CD$` |
| `是  $AB` | `是 $AB` |
| `CD$ 的` | `CD$ 的` |
| `=$ 1$` | `=$1$`（等号前/后处理取决于上下文）|

**处理优先级**：
- 先移除 `$` 与内部公式之间的多余空格
- 再修正 `$` 外侧缺少的空格（与非公式文本之间）

#### 任务三：圆圈数字编号处理

将 ①②③④⑤⑥⑦⑧⑨⑩ 等 Unicode 圆圈数字用 `$` 包裹。

- **单独的圆圈数字**：`①` → `$①$`，`②` → `$②$`
- **连续多个**：`①②③④` → `$①②③④$`
- 检查全文中所有这类字符，确保无一遗漏

**注意**：这是数学排版惯例，将圆圈数字视为数学符号处理。

#### 任务四：选择题选项分行

将同一行的选择题选项拆分为每个选项独立一行，选项之间用空行隔开。

**查找模式**：同一行中出现多个 `X. ` 格式的选项（A/B/C/D 或更多）

**转换示例：**
```
输入：A. 3   B. 4   C. 5   D. 6
输出：
A. 3

B. 4

C. 5

D. 6
```

**注意事项**：
- 每个选项单独一行
- 选项之间留一个空行
- 保持选项文本的原始内容不变

#### 任务五：填空线格式

填空线统一为 `___`（三个下划线），**左右两侧必须各有一个空格**。只允许三种合法形态：

| 形态 | 示例 |
|------|------|
| 后接正文 | `xxx ___ xxx` |
| 行尾结束 | `xxx ___` |
| 后接标点 | `xxx ___ 。`（标点前保留空格） |

必须修复的禁止形态：`x___`、`___x`、`___.`、`___。`、`___，`、`$___`、`___$` 等任一侧缺空格的情况。

**示例：**
```
输入：则 A、B 两点间的距离为___。
输出：则 $A$、$B$ 两点间的距离为 ___ 。
```

**机械化检查**：完成后用 Grep 搜索 `[^ ]___` 与 `___[^ ]`（行尾的 `___` 除外），必须 0 命中。

#### 任务六：独立数字空格与独立字母 $ 包裹

题干中 `$...$` 之外的**独立数字**与**独立字母**处理（对应规则文件 1.6、1.7，历次格式化最易遗漏）：

1. **独立数字**：前后各保留一个空格。如 `已知2个正数` → `已知 2 个正数`
2. **独立字母**（点名、线名、变量名等数学符号）：用 `$` 包裹，且与前后非标点文字各留一个空格。如 `点A在直线l上` → `点 $A$ 在直线 $l$ 上`
3. **连续表达式整体包裹**：`AB=2` → `$AB=2$`，`m=-4` → `$m=-4$`，禁止逐字母拆开包裹
4. **例外（不处理）**：行首题号 `1. ` 与选项标签 `A. `；出处标签/年份（如 `(2023-2024·丰台区期末)`）；`$...$` 内部内容；单位与英文单词（`cm`、`kg`）；数字/字母紧跟标点时标点前不加空格

### 步骤 4：写入文件

将格式化后的内容写回原始文件（覆盖）。

### 步骤 5：验证

重新读取写入的文件，逐项验证六项任务是否执行正确：

1. **序号验证**：抽查 5 个题号，确认格式为 `数字. `
2. **公式验证**：抽查 5 处数学公式，确认 `$公式$` 格式正确（无内侧空格，外侧保留空格）
3. **圆圈数字验证**：确认所有 ①②③ 等已被 `$` 包裹
4. **选项验证**：确认选择题选项已正确分行
5. **填空线验证**：Grep 搜索 `[^ ]___` 与 `___[^ ]`（行尾除外），必须 0 命中
6. **数字空格验证**：抽查 5 处题干独立数字，确认前后各一个空格（题号/年份除外）
7. **字母包裹验证**：抽查 5 处题干独立字母，确认已 `$` 包裹且前后空格正确；连续表达式（如 `$AB=2$`）整体包裹、未逐字母拆分

### 步骤 6：报告

向用户报告：
- 处理了哪个文件
- 六项任务各做了哪些修改（简要说明）
- 验证结果（通过/发现问题）

## 示例

### 格式化前（片段）
```
1、 下列计算正确的是（   ）
A. a^2 + a^3 = a^5   B. a^2 \cdot a^3 = a^5   C. (a^2)^3 = a^5   D. a^6 \div a^3 = a^2

2、 已知  $ AB \parallel CD $ ，则  $\angle 1$  的度数为（   ）
A. 30°   B. 45°   C. 60°   D. 90°

3、 数轴上点A到表示2的点的距离为3，则点A表示的数为___．
```

```
3. 数轴上点 $A$ 到表示 2 的点的距离为 3，则点 $A$ 表示的数为 ___ ．
```
