# 产物格式、规则对接与校验清单

> 本技能只完成「网页识别 → 结构化提取 → 按规则格式化落盘」，属于试卷工作流的**格式化阶段**；拆题、本地化配图、写解析 callout 属于后续 `/试卷解析` 阶段，本技能不执行。

## 1. 落盘位置与命名

- 默认 vault 解析根目录：`D:\【Knowledge Notes】\12-试卷解析`；用户指定其它路径时以用户为准。
- 格式化阶段产物放 `待解析/` 根目录（拆题前不建试卷文件夹）。
- 文件名：`{年级}-{学科}-{试卷名}-{发布日期YYYYMMDD}.md`
  - 示例：`八上-数学-2025北京西城北师大附中八年级上期末-20260122.md`
  - 发布日期取自页面顶部元信息（`2026/01/22` → `20260122`）；只有年月时按规则补 `01` 日。
- 学科代码与年级编码对照见 Rules 文件「科目代码表」「年级编码对照表」。

## 2. Frontmatter

```yaml
---
创建时间: 2026-11-22
来源: 组卷网，https://zujuan.xkw.com/2p3012600.html
类型:
  - 期末试题
tags:
  - 八上数学
---
```

- `创建时间`：本次处理日期；`来源`：站点 + 试卷 URL（页面未标作者时不编造作者名）。
- `tags`：统一「年级+学科」（如 `八上数学`、`八上物理`、`九下数学`）。
- 不在源试卷 MD 里写 `knowledge`、`source`、题目 ID——这些是拆题阶段 Q 文件的 frontmatter 字段。

## 3. 正文结构

```markdown
## {文件名去后缀}

> 共 N 题（单选 X、填空 Y、解答 Z）。配图为站点原图（公式为渲染碎片图），拆题阶段再本地化；本文件为格式化后的源试卷，不含答案与解析。

### 一、单选题

1. （出处标签）题干……

A. 选项

B. 选项

C. 选项

D. 选项

### 二、填空题

9. 题干 ___ 。

### 三、解答题

17. 题干……

(1) ……

(2) ……

![Image](https://img.xkw.com/...)
```

- 题号 `N. ` 全局连续编号；出处标签紧跟题号后括号内（无标签则省略）。
- 分节标题由页面 `H4.sec-title` 转换：剥离尾部「添加题型下试题」按钮文字；「一．」类全角句点改为「一、」。
- 配图用 Markdown `![Image](url)`；源试卷阶段**保留网络链接**，不下载、不换本地路径。
- 选择题选项按规则 2.5 每项独占一行、空行隔开；题号与首个选项之间空一行。

## 4. 规则对接（不复制规则全文）

数学格式规范以本地规则文件为准，落盘前逐条对照：

- 规则全文：`D:\【Knowledge Notes】\12-试卷解析\待解析\【Rules-数理化试卷】.md`
  - 第一章：公式 `$` 包裹、圈数、标点前空格、独立数字空格、独立字母/连续表达式整体包裹。
  - 第二章：题号、公式、圈数、选项分行、填空线、独立数字/字母六项格式化任务。
- 耦合技能：
  - `C:\Users\LSSTUDIO\.agents\skills\数学试卷格式化\SKILL.md`
  - `C:\Users\LSSTUDIO\.agents\skills\试卷解析\SKILL.md`

转换器脚本只做结构级清洗；**规则 1.6/1.7 的独立数字空格与独立字母 `$` 包裹必须在落盘前人工逐题复核补全**，不得把脚本输出直接当成最终 MD。

## 5. 强制校验清单（落盘后逐项跑）

1. 题数 = 配图数（与页面题号逐一对应，不少题不多题）；公式碎片图与题图分别计数无遗漏。
2. 题号全部为 `数字. ` 格式，无残留 `、`。
3. 圈数 `①②③…` 全部 `$` 包裹；圈数与相邻公式之间留一个空格。
4. 填空线 `___` 两侧各一空格；Grep `[^ ]___` 与 `___[^ ；;。，,.!！?？)）\n]` 0 命中（行尾除外）。
5. 独立字母/表达式已 `$` 包裹，连续表达式整体包裹、未逐字母拆开；独立数字前后空格（题号、出处年份除外）。
6. 标点前不留多余空格；公式内部运算符两侧无多余空格。
7. 无 HTML 标签残留（`<div>/<img>/<span>/<table>/<center>/<sub>/<sup>/<br>/<bk>/<i>/<p>` 等）。
8. 源试卷 MD 中无 `> [!question]-` callout、无本地图片引用；网络图片链接完整。
9. 配图逐张下载目检：与题干构型一致，无缺图、错图、水印占位图；多图组合（图1/2/3、备用图）保持一题一图；公式碎片图放大后可辨认。

## 6. 交付报告必须说明的事项

- **答案/解析门禁**：若 `.item.answer` 为空、`【答案】/【解析】/【考点】` 0 命中，明确告知用户解析不可见，需下载文件或可访问详情后再补；不得在 MD 中编造答案。
- **缺 PDF 源文件**：本卷来源为网页，无 PDF；拆题阶段需用户确认 PDF 如何处理（规则 4.2 不得直接跳过）。
- **年级依据**：页面已标年级时注明；未标时说明推断依据与结论，请用户确认后定稿 tag。
- **缺失出处标签**：个别题 `.ques-src` 为空，在报告中列出题号。
- **公式碎片图说明**：本站公式以 PNG 碎片呈现、无 LaTeX 源码；用户要求转 Markdown 时按 `dom-and-gating.md` §5.1 做视觉转写回写 `$...$`，转写须放大复核并结合题干核对；模糊不可辨碎片在报告中标注题号，不臆造等式结果。题图（`img.xkw.com`）始终保留为图片。
- **后续阶段提示**：格式化经用户审核通过后，再走拆题流程（建试卷文件夹、移动源文件、Q 文件、配图本地化、解析 callout、双向链接）。
- **答案版 PDF 的处理**：若用户下载的是含「答案/分析/详解」的答案版 PDF（常为题干与答案解析逐题混排，图片型无文字层），格式化阶段只取题干部分与现有 MD 逐页核对；**答案、分析、详解、考点一律不写入源 MD**，PDF 保留在目录中，供后续 `/试卷解析` 阶段撰写 Q 文件 callout 时参考。源 MD 中不得出现 `【答案】/【解析】/【考点】/【易错点】`、`故选/故答案为` 等答案性文字。
