## 八年级上册（2024版）

### 第1章 物态及其变化

#### 1-1 温度及其测量

【知识点】
- 温度：表示物体冷热程度的物理量
- 温度的单位：摄氏度（℃）
- 摄氏温度的规定：在标准大气压下，冰水混合物的温度规定为0℃，沸水的温度为100℃
- 0℃和100℃之间分成100等份，每一等份代表1℃
- 温度计的原理：液体的热胀冷缩
- 温度计的使用：$①$估：估计被测物体的温度；$②$选：选择合适量程的温度计；$③$看：看清温度计的量程和分度值；$④$放：温度计的玻璃泡要全部浸入被测液体中，不要碰到容器底或容器壁；$⑤$读：待温度计示数稳定后再读数，读数时玻璃泡要继续留在被测液体中，视线要与温度计中液柱的上表面相平；$⑥$记：记录结果要包括数字和单位
- 体温计：测量范围35℃~42℃，分度值0.1℃，可以离开人体读数（有缩口）
- 体温计使用前要用力向下甩，其他温度计不能甩
- 易错点：读数时视线要与液柱上表面相平；体温计可以离开人体读数

【标准考点】
1. 温度的概念和单位（高频）
2. 温度计的正确使用（高频）
3. 体温计的特点（高频）
4. 温度计的读数（中频）

【常见题型】
1. **选择题：温度计使用**
   例：使用温度计测量液体温度时，下列做法正确的是（ ）
   A. 温度计的玻璃泡碰到容器底 B. 读数时温度计离开液体 C. 玻璃泡全部浸入液体中 D. 视线与液柱上表面不相平
   答案：C

2. **填空题：体温计**
   例：体温计的测量范围是 ___ ℃，分度值是 ___ ℃， ___ （选填"能"或"不能"）离开人体读数。
   答案：35~42；0.1；能

3. **选择题：体温计使用**
   例：用体温计测得甲的体温为37.5℃，若没有甩过又去测乙和丙的体温，已知乙和丙的实际体温分别为36.5℃和38.5℃，那么两次读数分别是（ ）
   A. 36.5℃和38.5℃ B. 37.5℃和38.5℃ C. 36.5℃和37.5℃ D. 37.5℃和37.5℃
   答案：B（体温计有缩口，不甩不会下降）

4. **读图题：温度计读数**
   例：如图所示温度计的示数为 ___ ℃。
   答案：根据液柱位置读数，注意零上零下

【解题思路】
1. **温度计使用规则**：玻璃泡全部浸入，不碰容器底壁，待示数稳定再读数，视线与液面相平
2. **体温计特点**：有缩口，可以离开人体读数，使用前要甩
3. **读数方法**：先看液柱在零上还是零下，再看分度值，最后读数
4. **易错警示**：体温计不甩，示数只升不降

#### 1-2 熔化和凝固

【知识点】
- 熔化：物质从固态变成液态的过程
- 凝固：物质从液态变成固态的过程
- 晶体：有固定熔化温度的固体，如冰、海波、各种金属
- 非晶体：没有固定熔化温度的固体，如蜡、松香、玻璃、沥青
- 熔点：晶体熔化时的温度
- 凝固点：晶体凝固时的温度
- 同种晶体的熔点和凝固点相同
- 晶体熔化的条件：$①$达到熔点；$②$继续吸热
- 晶体凝固的条件：$①$达到凝固点；$②$继续放热
- 晶体熔化特点：吸热，温度不变
- 非晶体熔化特点：吸热，温度不断升高
- 晶体凝固特点：放热，温度不变
- 非晶体凝固特点：放热，温度不断降低
- 易错点：晶体熔化时温度不变，但要继续吸热

【标准考点】
1. 晶体和非晶体的区别（高频）
2. 熔化和凝固的概念（高频）
3. 晶体熔化和凝固的条件（高频）
4. 熔化和凝固图像分析（高频）
5. 熔点的应用（中频）

【常见题型】
1. **选择题：晶体非晶体**
   例：下列物质中都是晶体的是（ ）
   A. 冰、海波、铁 B. 蜡、玻璃、松香 C. 冰、蜡、铁 D. 海波、玻璃、沥青
   答案：A

2. **图像题：熔化图像**
   例：如图所示是某物质的熔化图像，该物质是 ___ （选填"晶体"或"非晶体"），熔点是 ___ ℃，熔化过程用了 ___ min。
   答案：晶体；根据图像读取；根据图像读取

3. **填空题：熔化条件**
   例：晶体熔化的条件是：$①$ ___ ；$②$ ___ 。
   答案：达到熔点；继续吸热

4. **选择题：熔化特点**
   例：晶体在熔化过程中（ ）
   A. 吸热，温度升高 B. 吸热，温度不变 C. 放热，温度不变 D. 不吸热不放热，温度不变
   答案：B

5. **简答题：应用**
   例：为什么北方冬天菜窖里要放几桶水？
   答案：水凝固成冰时会放热，使菜窖内温度不至于太低，防止菜冻坏。

【解题思路】
1. **晶体非晶体判断**：看熔化图像是否有平台（温度不变段），有平台是晶体
2. **熔化条件**：达到熔点且继续吸热，缺一不可
3. **图像分析**：横轴时间，纵轴温度，平台段对应熔点
4. **易错警示**：晶体熔化时温度不变，但内能增加（吸热）

#### 1-3 汽化和液化

【知识点】
- 汽化：物质从液态变成气态的过程
- 液化：物质从气态变成液态的过程
- 汽化的两种方式：蒸发和沸腾
- 蒸发：在任何温度下都能发生的汽化现象，只在液体表面进行
- 沸腾：在一定温度下（沸点），在液体表面和内部同时发生的剧烈汽化现象
- 沸点：液体沸腾时的温度
- 液体沸腾的条件：$①$达到沸点；$②$继续吸热
- 液体沸腾特点：吸热，温度不变
- 影响蒸发快慢的因素：$①$液体的温度；$②$液体的表面积；$③$液体表面空气流速
- 蒸发吸热，有致冷作用
- 液化的方法：$①$降低温度；$②$压缩体积
- 液化放热
- 易错点：蒸发和沸腾的区别；"白气"不是水蒸气，是小水珠

【标准考点】
1. 汽化和液化的概念（高频）
2. 蒸发和沸腾的区别（高频）
3. 沸腾的条件和特点（高频）
4. 影响蒸发快慢的因素（高频）
5. 液化的方法（中频）
6. 沸腾图像分析（中频）

【常见题型】
1. **选择题：蒸发和沸腾**
   例：下列关于蒸发和沸腾的说法中，正确的是（ ）
   A. 蒸发和沸腾都只在液体表面进行 B. 蒸发和沸腾都在一定温度下进行 C. 蒸发和沸腾都要吸热 D. 蒸发和沸腾都是剧烈的汽化现象
   答案：C

2. **填空题：沸腾条件**
   例：液体沸腾的条件是：$①$ ___ ；$②$ ___ 。
   答案：达到沸点；继续吸热

3. **简答题：蒸发吸热**
   例：夏天在地上洒水会感到凉快，为什么？
   答案：水蒸发吸热，使周围温度降低。

4. **选择题：液化**
   例：下列现象中属于液化的是（ ）
   A. 冰化成水 B. 湿衣服变干 C. 烧水时壶嘴冒"白气" D. 冰冻衣服变干
   答案：C（"白气"是水蒸气液化形成的小水珠）

5. **实验题：沸腾实验**
   例：在"观察水的沸腾"实验中，水沸腾时的特点是 ___ ，继续加热，水的温度 ___ 。
   答案：吸热，温度不变；不变

【解题思路】
1. **蒸发vs沸腾**：蒸发在任何温度、表面、缓慢；沸腾在沸点、表面和内部、剧烈
2. **沸腾条件**：达到沸点且继续吸热，缺一不可
3. **液化判断**："白气""白雾"都是液化形成的小水珠，不是水蒸气
4. **蒸发快慢**：控制变量法，温度、表面积、空气流速
5. **易错警示**：水蒸气看不见，看见的"白气"是小水珠

#### 1-4 升华和凝华

【知识点】
- 升华：物质从固态直接变成气态的过程
- 凝华：物质从气态直接变成固态的过程
- 升华吸热，凝华放热
- 升华现象：樟脑丸变小、冰冻衣服变干、碘变成碘蒸气
- 凝华现象：霜、雪、雾凇、窗花（冰花）
- 升华的应用：干冰升华吸热，用于人工降雨、制造舞台效果
- 物态变化总结：固→液熔化，液→固凝固，液→气汽化，气→液液化，固→气升华，气→固凝华
- 吸热过程：熔化、汽化、升华
- 放热过程：凝固、液化、凝华
- 易错点：窗花在玻璃内侧；霜不是冰晶，是凝华形成的小冰晶

【标准考点】
1. 升华和凝华的概念（高频）
2. 生活中的升华和凝华现象（高频）
3. 物态变化的判断（高频）
4. 升华吸热的应用（中频）

【常见题型】
1. **选择题：物态变化判断**
   例：下列现象中属于升华的是（ ）
   A. 春天，冰雪消融 B. 夏天，湿衣服晾干 C. 秋天，早晨草叶上的露珠 D. 冬天，冰冻的衣服变干
   答案：D（固态冰直接变成气态水蒸气）

2. **填空题：凝华现象**
   例：冬天，窗户玻璃 ___ （选填"内"或"外"）侧出现冰花，这是 ___ 现象。
   答案：内；凝华（室内水蒸气遇到冷的玻璃凝华）

3. **选择题：物态变化吸放热**
   例：下列物态变化中，需要吸热的是（ ）
   A. 凝固 B. 液化 C. 升华 D. 凝华
   答案：C

4. **简答题：干冰应用**
   例：舞台上喷洒干冰可以制造白雾效果，请解释原因。
   答案：干冰升华吸热，使周围空气温度降低，空气中的水蒸气遇冷液化成小水珠，形成白雾。

5. **填空题：物态变化**
   例：用久了的灯泡壁变黑，是因为钨丝先 ___ 后 ___ 。
   答案：升华；凝华

【解题思路】
1. **升华凝华判断**：固→气是升华，气→固是凝华，没有经过液态
2. **物态变化六步法**：先判断初态和末态，再确定是哪种变化
3. **吸放热规律**：熔化、汽化、升华吸热；凝固、液化、凝华放热
4. **易错警示**：窗花在玻璃内侧（室内水蒸气遇冷凝华）；霜是小冰晶不是冰

### 第2章 机械运动

#### 2-1 长度和时间的测量

【知识点】
- 长度的国际单位是米（m），常用单位还有千米（km）、分米（dm）、厘米（cm）、毫米（mm）、微米（μm）、纳米（nm）
- 单位换算：$1\text{km} = 10^3\text{m}$，$1\text{m} = 10\text{dm} = 10^2\text{cm} = 10^3\text{mm} = 10^6\text{μm} = 10^9\text{nm}$
- 测量长度的基本工具是刻度尺，使用前要观察零刻度线、量程和分度值
- 刻度尺的正确使用方法：$①$选：根据测量要求选择合适量程和分度值的刻度尺；$②$放：刻度尺要放正，有刻度的一边要紧靠被测物体；$③$看：读数时视线要与尺面垂直；$④$读：要估读到分度值的下一位；$⑤$记：记录结果要包括数字和单位
- 时间的国际单位是秒（s），常用单位还有小时（h）、分钟（min）
- 单位换算：$1\text{h} = 60\text{min} = 3600\text{s}$
- 误差：测量值与真实值之间的差异，误差不可避免，但可以减小
- 减小误差的方法：$①$多次测量求平均值；$②$使用更精密的测量工具；$③$改进测量方法
- 错误：由于不遵守测量仪器的使用规则或粗心大意造成的，错误可以避免
- 特殊测量方法：$①$累积法（测多算少）；$②$化曲为直法；$③$配合法（如用三角板和刻度尺测硬币直径）
- 易错点：估读时要读到分度值的下一位；记录结果时必须带单位；误差不是错误

【标准考点】
1. 长度单位的换算（高频）
2. 刻度尺的正确使用和读数（高频）
3. 误差与错误的区别（中频）
4. 特殊测量方法的应用（中频）
5. 时间单位的换算（低频）

【常见题型】
1. **选择题：刻度尺读数**
   例：用分度值为1mm的刻度尺测量物体长度，下列读数正确的是（ ）
   A. 2.3cm B. 2.30cm C. 2.300cm D. 23cm
   答案：B（要估读到分度值的下一位）

2. **填空题：单位换算**
   例：$3.5\text{km}=$ ___ $\text{m}=$ ___ $\text{cm}$
   答案：$3.5 \times 10^3$；$3.5 \times 10^5$

3. **选择题：误差与错误**
   例：关于误差，下列说法正确的是（ ）
   A. 误差就是错误 B. 误差可以避免 C. 多次测量求平均值可以减小误差 D. 误差是由于不遵守测量规则造成的
   答案：C

4. **填空题：特殊测量**
   例：要测量一张纸的厚度，可以先测量100张纸的总厚度，再除以100，这种方法叫做 ___ 。
   答案：累积法（测多算少）

【解题思路】
1. **刻度尺读数三步法**：$①$看分度值；$②$读准确值（对齐刻度）；$③$估读到分度值下一位
2. **单位换算技巧**：数字不变，单位换算是乘以进率，注意科学计数法的使用
3. **误差vs错误**：误差不可避免只能减小，错误可以避免；误差不是错误
4. **特殊测量方法选择**：太薄用累积法，曲线用化曲为直法，直径用配合法
5. **记录结果必须带单位**：没有单位的数字没有物理意义

#### 2-2 运动的描述

【知识点】
- 机械运动：物体位置的变化叫做机械运动
- 参照物：在研究机械运动时，选作标准的物体叫做参照物
- 运动和静止的相对性：同一个物体是运动还是静止，取决于所选的参照物
- 参照物的选择原则：$①$参照物可以任意选择；$②$通常选地面或固定在地面上的物体为参照物；$③$不选研究对象本身为参照物
- 判断物体运动状态的方法：$①$确定研究对象；$②$选定参照物；$③$判断研究对象相对于参照物的位置是否变化
- 宇宙中一切物体都在运动，绝对静止的物体不存在
- 易错点：运动和静止是相对的；参照物一旦选定就假定它是静止的

【标准考点】
1. 参照物的选择和判断（高频）
2. 运动和静止的相对性（高频）
3. 机械运动的概念（中频）
4. 根据参照物判断运动状态（中频）

【常见题型】
1. **选择题：参照物判断**
   例：坐在行驶的火车上的乘客，认为自己是静止的，他选择的参照物是（ ）
   A. 地面 B. 迎面驶来的火车 C. 车厢 D. 路旁的树木
   答案：C（相对于车厢位置不变）

2. **填空题：运动相对性**
   例："小小竹排江中游，巍巍青山两岸走"，前一句是以 ___ 为参照物，后一句是以 ___ 为参照物。
   答案：青山（或岸）；竹排

3. **选择题：运动状态判断**
   例：甲乙两车并排停在路口等候绿灯，绿灯亮后，甲车突然向前运动，乙车中的人看到甲车在后退，则乙车（ ）
   A. 一定向前运动 B. 一定向后运动 C. 可能静止 D. 可能向前运动但比甲车慢
   答案：D

4. **简答题：解释现象**
   例：为什么坐在行驶的汽车里会看到路边的树木向后退？
   答案：以汽车为参照物，树木相对于汽车的位置在不断向后变化，所以看到树木向后退。

【解题思路】
1. **参照物判断三步法**：$①$明确研究对象；$②$分析相对于哪个物体位置变化；$③$该物体就是参照物
2. **运动状态判断法**：$①$选参照物；$②$看研究对象与参照物的距离是否变化；$③$变化则运动，不变则静止
3. **相对运动分析**：若A相对于B运动，则B相对于A也运动，方向相反
4. **多参照物问题**：分别以不同参照物分析，注意结论可能不同
5. **易错警示**：不能选研究对象本身为参照物；运动和静止是相对的

#### 2-3 运动的快慢

【知识点】
- 速度：路程与时间之比叫做速度，公式 $v = \dfrac{s}{t}$
- 速度的国际单位是米每秒（m/s），常用单位是千米每小时（km/h）
- 单位换算：$1\text{m/s} = 3.6\text{km/h}$
- 速度的物理意义：表示物体运动的快慢
- 匀速直线运动的速度：速度保持不变，$v = \dfrac{s}{t}$ 可用于计算任意时间段的速度
- 变速运动的平均速度：$v_{\text{平}} = \dfrac{s_{\text{总}}}{t_{\text{总}}}$，表示某段路程或某段时间内的平均快慢
- 匀速直线运动的路程-时间图像（s-t图像）：是一条过原点的倾斜直线，斜率表示速度
- 匀速直线运动的速度-时间图像（v-t图像）：是一条平行于时间轴的直线
- 比较速度大小的方法：统一单位后比较数值大小
- 易错点：平均速度不是速度的平均值；计算平均速度必须对应同一段路程和时间

【标准考点】
1. 速度公式的应用（高频）
2. 速度单位的换算（高频）
3. 匀速直线运动的图像分析（高频）
4. 平均速度的计算（高频）
5. 比较物体运动快慢（中频）
6. 速度-时间图像与路程-时间图像的转化（中频）

【常见题型】
1. **计算题：速度计算**
   例：一辆汽车在平直公路上行驶，前2s通过的路程是20m，后3s通过的路程是30m，求：
   （1）前2s的平均速度；（2）后3s的平均速度；（3）全程的平均速度。
   答案：（1）$v_1 = \dfrac{20\text{m}}{2\text{s}} = 10\text{m/s}$；（2）$v_2 = \dfrac{30\text{m}}{3\text{s}} = 10\text{m/s}$；（3）$v = \dfrac{20\text{m} + 30\text{m}}{2\text{s} + 3\text{s}} = 10\text{m/s}$

2. **选择题：单位换算**
   例：下列速度最大的是（ ）
   A. 72km/h B. 20m/s C. 1800m/min D. 25m/s
   答案：D（统一单位为m/s：A为20m/s，B为20m/s，C为30m/s，D为25m/s）

3. **图像题：s-t图像**
   例：甲乙两物体同时同地同方向运动，它们的s-t图像如图所示，甲的图线斜率大于乙，则（ ）
   A. 甲的速度大于乙 B. 甲的速度小于乙 C. 甲乙速度相等 D. 无法判断
   答案：A（s-t图像中斜率表示速度）

4. **计算题：平均速度**
   例：小明前一半路程以4m/s的速度行走，后一半路程以6m/s的速度行走，求全程的平均速度。
   答案：设总路程为$2s$，则$t_1 = \dfrac{s}{4}$，$t_2 = \dfrac{s}{6}$，$v_{\text{平}} = \dfrac{2s}{\dfrac{s}{4} + \dfrac{s}{6}} = \dfrac{2s}{\dfrac{5s}{12}} = 4.8\text{m/s}$

【解题思路】
1. **速度公式应用**：$v = \dfrac{s}{t}$，变形为$s = vt$和$t = \dfrac{s}{v}$，注意对应同一物体同一段路程
2. **平均速度计算**：必须用总路程除以总时间，不是速度的平均值
3. **单位换算**：m/s换算成km/h乘以3.6，km/h换算成m/s除以3.6
4. **图像分析**：s-t图像斜率表示速度；v-t图像与时间轴围成的面积表示路程
5. **比值问题**：当路程相同时，速度与时间成反比；当时间相同时，速度与路程成正比
6. **易错警示**：平均速度必须指明是哪段路程或哪段时间的平均速度

#### 2-4 平均速度的测量

【知识点】
- 实验原理：$v = \dfrac{s}{t}$
- 实验器材：斜面、小车、刻度尺、停表、金属片
- 实验步骤：$①$将斜面一端垫高，另一端放金属片；$②$让小车从斜面顶端滑下，用停表测出小车到达金属片的时间t；$③$用刻度尺测出斜面长度s；$④$计算平均速度
- 测量下半段路程的平均速度：先测出全程时间$t_1$和上半段路程时间$t_2$，则下半段时间$t_3 = t_1 - t_2$
- 金属片的作用：便于测量时间和确定小车运动终点
- 斜面坡度不宜过大：坡度过大，小车下滑太快，时间不易测量
- 斜面坡度不宜过小：坡度过小，小车可能无法滑下
- 小车必须从同一位置由静止释放：保证每次实验条件相同
- 实验结论：小车沿斜面下滑的速度越来越快，做加速运动
- 易错点：计时开始和结束要与小车运动同步；下半段路程的时间不能直接测量，要用总时间减去上半段时间

【标准考点】
1. 实验原理和器材（高频）
2. 实验步骤和操作要点（高频）
3. 平均速度的计算（高频）
4. 实验误差分析（中频）
5. 实验结论的得出（中频）

【常见题型】
1. **实验题：测量平均速度**
   例：在"测量平均速度"的实验中，小明让小车从斜面顶端A处由静止开始下滑，测得小车到达B处的时间为2s，到达C处的时间为3s，AB段路程为0.6m，BC段路程为0.9m。求：
   （1）AB段的平均速度；（2）BC段的平均速度；（3）AC段的平均速度。
   答案：（1）$v_{AB} = \dfrac{0.6\text{m}}{2\text{s}} = 0.3\text{m/s}$；（2）$v_{BC} = \dfrac{0.9\text{m}}{3\text{s} - 2\text{s}} = 0.9\text{m/s}$；（3）$v_{AC} = \dfrac{0.6\text{m} + 0.9\text{m}}{3\text{s}} = 0.5\text{m/s}$

2. **填空题：实验操作**
   例：在测量平均速度的实验中，斜面坡度不宜过大，原因是 ___ 。
   答案：坡度过大，小车下滑太快，时间不易测量，误差较大

3. **选择题：实验分析**
   例：在测量小车沿斜面下滑的平均速度时，如果小车过了起点才开始计时，则测得的平均速度（ ）
   A. 偏大 B. 偏小 C. 不变 D. 无法判断
   答案：A（时间测量值偏小，根据$v = \dfrac{s}{t}$，速度偏大）

4. **实验题：误差分析**
   例：实验中如果斜面坡度太大，会导致什么结果？如何改进？
   答案：斜面坡度太大，小车下滑太快，时间测量误差大；改进方法：减小斜面坡度

【解题思路】
1. **实验原理**：$v = \dfrac{s}{t}$，用刻度尺测路程，用停表测时间
2. **分段计算**：上半段、下半段、全程要分别计算，注意对应关系
3. **时间测量**：下半段时间 = 全程时间 - 上半段时间，不能直接测量
4. **误差分析**：时间测量偏大则速度偏小，时间测量偏小则速度偏大
5. **实验改进**：坡度适中，多次测量求平均值，同步计时

### 第3章 声现象

#### 3-1 声音的产生与传播

【知识点】
- 声音的产生：声音是由物体的振动产生的，振动停止，发声也停止
- 声源：正在发声的物体叫做声源
- 声音的传播：声音的传播需要介质，真空不能传声
- 介质：能够传播声音的物质叫做介质，包括固体、液体、气体
- 声音以波的形式传播，叫做声波
- 声速：声音传播的速度，与介质的种类和温度有关
- 一般情况下，$v_{\text{固}} > v_{\text{液}} > v_{\text{气}}$
- 15℃时空气中的声速是340m/s
- 回声：声音在传播过程中遇到障碍物被反射回来的现象
- 听到回声的条件：回声到达人耳比原声晚0.1s以上，即障碍物距离至少17m
- 人耳听声的过程：声波→外耳道→鼓膜振动→听小骨→耳蜗→听觉神经→大脑
- 骨传导：声音通过头骨、颌骨传到听觉神经，引起听觉
- 易错点：振动停止，发声停止，但声音不一定立即消失（还在传播中）

【标准考点】
1. 声音产生的条件（高频）
2. 声音传播需要介质（高频）
3. 声速的影响因素（高频）
4. 回声的计算（中频）
5. 骨传导的应用（低频）

【常见题型】
1. **选择题：声音产生**
   例：下列关于声音产生的说法中，正确的是（ ）
   A. 只要物体振动就一定能听到声音 B. 声音是由物体振动产生的 C. 不振动的物体也能发声 D. 以上说法都不对
   答案：B

2. **填空题：声速**
   例：声音在15℃的空气中传播速度是 ___ m/s，一般情况下，声音在液体中的传播速度 ___ （选填"大于""小于"或"等于"）在气体中的传播速度。
   答案：340；大于

3. **计算题：回声**
   例：一个人面对高山喊一声，4s后听到回声，求人与山的距离。（声音在空气中的速度为340m/s）
   答案：$s = vt = 340\text{m/s} \times 4\text{s} = 1360\text{m}$，人与山的距离$d = \dfrac{s}{2} = \dfrac{1360\text{m}}{2} = 680\text{m}$

   例：为什么月球上的宇航员不能直接对话，而要用无线电？
   答案：月球上没有空气，是真空，真空不能传声，所以不能直接对话，要用电磁波（无线电）传递信息。

【解题思路】
1. **声音产生条件**：物体振动产生声音，振动停止发声停止
2. **声音传播条件**：需要介质，真空不能传声
3. **声速比较**：固体>液体>气体，与温度有关
4. **回声计算**：声音来回传播，距离是路程的一半，$d = \dfrac{vt}{2}$
5. **易错警示**：听到声音的条件：$①$有声源振动；$②$有介质传播；$③$频率在20Hz~20000Hz之间；$④$响度足够大

#### 3-2 声音的特性

【知识点】
- 音调：声音的高低，由发声体振动的频率决定
- 频率：物体每秒振动的次数，单位是赫兹（Hz）
- 频率越高，音调越高；频率越低，音调越低
- 超声波：频率高于20000Hz的声波
- 次声波：频率低于20Hz的声波
- 人耳能听到的声音频率范围：20Hz~20000Hz
- 响度：声音的强弱（大小），由发声体的振幅决定
- 振幅：物体振动的幅度
- 振幅越大，响度越大
- 响度还与距离声源的远近有关，距离越远，响度越小
- 音色：声音的特色，由发声体的材料和结构决定
- 不同发声体的音色不同，可以通过音色辨别发声体
- 易错点：音调和响度容易混淆；音色与振幅无关

1. 音调、响度、音色的区别（高频）
2. 影响音调的因素（高频）
3. 影响响度的因素（高频）
4. 超声波和次声波（中频）
5. 音色的应用（中频）

【解题思路】

4. **音色应用**：辨别不同发声体，如不同人、不同乐器

#### 3-3 声的利用

【知识点】
- 声音可以传递信息：如说话交流、B超、回声定位等
- 声音可以传递能量：如超声波清洗、超声波碎石等
- 回声定位：蝙蝠利用超声波回声定位确定目标位置
- 声呐：利用声波探测海底深度、鱼群位置等
- B超：利用超声波获得人体内部信息
- 超声波清洗：利用超声波传递能量清洗精密机械
- 超声波碎石：利用超声波传递能量击碎人体内的结石
- 次声波的应用：预测地震、台风、监测核爆炸等
- 次声波的危害：能量大的次声波对人体有害
- 易错点：传递信息和传递能量的区别

#### 3-4 噪声的危害和控制

【知识点】
- 噪声：从物理学角度，发声体做无规则振动时发出的声音；从环保角度，妨碍人们正常休息、学习和工作的声音
- 噪声的等级：用分贝（dB）表示
- 0dB是人刚能听到的最微弱的声音
- 30~40dB是较为理想的安静环境
- 为了保护听力，声音不能超过90dB
- 为了保证工作和学习，声音不能超过70dB
- 为了保证休息和睡眠，声音不能超过50dB
- 控制噪声的途径：$①$在声源处减弱；$②$在传播过程中减弱；$③$在人耳处减弱
- 在声源处减弱：如给摩托车安装消声器
- 在传播过程中减弱：如道路两旁植树、安装隔音板
- 在人耳处减弱：如戴耳塞、耳罩
- 易错点：噪声不都是有害的，有时也可以利用

【标准考点】

2. 噪声的等级和危害（高频）

   A. 声源处 B. 传播过程中 C. 人耳处

   A. 课堂上老师的讲课声 B. 音乐会上优美的钢琴声 C. 深夜学习时隔壁的电视声 D. 公园里鸟儿的叫声

### 第4章 光现象

#### 4-1 光的直线传播

【知识点】
- 光源：能够发光的物体叫做光源
- 光源的分类：$①$天然光源：太阳、萤火虫、水母等；$②$人造光源：电灯、蜡烛、火把等
- 光的直线传播：光在同种均匀介质中沿直线传播
- 光线：用一条带箭头的直线表示光的传播路径和方向
- 光的直线传播现象：影子的形成、小孔成像、日食月食、激光准直、排队看齐
- 小孔成像的特点：倒立的实像，像的大小与物距和像距有关
- 光速：光在真空中的传播速度$c = 3 \times 10^8\text{m/s}$
- 光在空气中的速度略小于真空中的速度，近似等于$c$
- 光在水中的速度约为真空中的$3/4$，在玻璃中约为真空中的$2/3$
- 光年：光在一年内传播的距离，是天文学上的长度单位
- 易错点：小孔成像是实像，平面镜成像是虚像；光线是假想的模型，实际不存在

#### 4-2 光的反射

【知识点】
- 光的反射：光从一种介质射向另一种介质表面时，一部分光被反射回原来介质的现象
- 反射定律：$①$反射光线、入射光线和法线在同一平面内；$②$反射光线和入射光线分居法线两侧；$③$反射角等于入射角
- 法线：过入射点垂直于反射面的直线
- 入射角：入射光线与法线的夹角
- 反射角：反射光线与法线的夹角
- 镜面反射：平行光射到光滑表面，反射光仍是平行光
- 漫反射：平行光射到粗糙表面，反射光射向各个方向
- 镜面反射和漫反射都遵循光的反射定律
- 反射现象中光路可逆
- 易错点：反射角等于入射角，不能说入射角等于反射角；入射角增大，反射角也增大

【标准考点】
1. 光的反射定律（高频）

3. 镜面反射和漫反射的区别（高频）

5. 光路可逆的应用（低频）

【常见题型】

   答案：C

4. **镜面vs漫反射**：光滑表面镜面反射，粗糙表面漫反射，都遵循反射定律
5. **易错警示**：入射角是入射光线与法线的夹角，不是与反射面的夹角

#### 4-3 平面镜成像

【知识点】
- 平面镜成像特点：$①$像和物大小相等；$②$像和物到镜面的距离相等；$③$像和物的连线与镜面垂直；$④$平面镜成的是虚像
- 平面镜成像原理：光的反射
- 虚像：由反射光线的反向延长线相交形成的像，不能用光屏承接
- 实像：由实际光线会聚形成的像，可以用光屏承接
- 平面镜成像的应用：$①$成像（如穿衣镜）；$②$改变光路（如潜望镜）
- 平面镜成像实验：用玻璃板代替平面镜，便于确定像的位置；用两支相同的蜡烛，便于比较像与物的大小关系
- 易错点：平面镜成像大小与物体到镜面的距离无关；像的大小只与物体大小有关

#### 4-4 光的折射

【知识点】
- 光的折射：光从一种介质斜射入另一种介质时，传播方向发生偏折的现象
- 折射规律：$①$折射光线、入射光线和法线在同一平面内；$②$折射光线和入射光线分居法线两侧；$③$光从空气斜射入水或玻璃中时，折射角小于入射角；$④$光从水或玻璃斜射入空气中时，折射角大于入射角；$⑤$光垂直入射时，传播方向不变
- 折射现象中光路可逆
- 生活中的折射现象：$①$水中物体看起来变浅；$②$筷子在水中看起来弯折；$③$海市蜃楼；$④$池水看起来变浅
- 易错点：折射角是折射光线与法线的夹角，不是与界面的夹角；光从空气进入其他介质，折射角小于入射角

#### 4-5 光的色散

【知识点】
- 光的色散：太阳光通过三棱镜后被分解成红、橙、黄、绿、蓝、靛、紫七种色光的现象
- 白光是由各种色光混合而成的复色光
- 色光的三原色：红、绿、蓝，三种色光按不同比例混合可以产生各种颜色的光
- 颜料的三原色：品红、黄、青
- 透明体的颜色：由它透过的色光决定，如红色玻璃只透过红光
- 不透明体的颜色：由它反射的色光决定，如红色物体反射红光，吸收其他色光
- 白色物体反射所有色光，黑色物体吸收所有色光
- 红外线：在红光之外，具有热效应，可用于遥控、夜视仪等
- 紫外线：在紫光之外，能使荧光物质发光，可用于验钞、杀菌等
- 易错点：透明体的颜色由透过光决定，不透明体的颜色由反射光决定

【标准考点】
1. 光的色散现象（高频）

3. 物体颜色的判断（高频）

5. 复色光和单色光的区别（低频）

### 第5章 透镜及其应用

#### 5-1 透镜

【知识点】
- 透镜：由透明物质制成的、至少有一个表面是球面的一部分的光学元件
- 凸透镜：中间厚、边缘薄的透镜，对光有会聚作用
- 凹透镜：中间薄、边缘厚的透镜，对光有发散作用
- 主光轴：通过两个球面球心的直线
- 光心：透镜主光轴上的特殊点，通过光心的光传播方向不变
- 焦点：凸透镜能使跟主光轴平行的光会聚在主光轴上的一点，用F表示
- 焦距：焦点到光心的距离，用f表示
- 凸透镜有两个实焦点，凹透镜有两个虚焦点
- 凸透镜的三条特殊光线：$①$平行于主光轴的光经凸透镜后过焦点；$②$过焦点的光经凸透镜后平行于主光轴；$③$过光心的光传播方向不变
- 凹透镜的三条特殊光线：$①$平行于主光轴的光经凹透镜后发散，反向延长线过虚焦点；$②$射向虚焦点的光经凹透镜后平行于主光轴；$③$过光心的光传播方向不变
- 易错点：凸透镜对光有会聚作用，但不一定会聚成一点；凹透镜对光有发散作用

【标准考点】
1. 凸透镜和凹透镜的辨别（高频）
2. 凸透镜对光的会聚作用（高频）
3. 凹透镜对光的发散作用（高频）
4. 焦点和焦距的概念（中频）
5. 特殊光线的画法（中频）

【常见题型】
1. **选择题：透镜辨别**
   例：下列关于透镜的说法中，正确的是（ ）
   A. 凸透镜对光有会聚作用，所以通过凸透镜的光一定会聚在焦点上 B. 凹透镜对光有发散作用 C. 凸透镜只有一个焦点 D. 通过光心的光传播方向会改变
   答案：B

2. **填空题：透镜特点**
   例：凸透镜中间 ___ 边缘 ___ ，对光有 ___ 作用。
   答案：厚；薄；会聚

3. **作图题：特殊光线**
   例：画出平行于主光轴的光经凸透镜后的折射光线。
   答案：折射光线过焦点

4. **选择题：焦距**
   例：关于凸透镜的焦点，下列说法正确的是（ ）
   A. 凸透镜只有一个焦点 B. 焦点到光心的距离叫焦距 C. 焦点在透镜内部 D. 平行光经凸透镜后一定过焦点
   答案：B

【解题思路】
1. **透镜辨别**：中间厚边缘薄是凸透镜，中间薄边缘厚是凹透镜
2. **会聚与发散**：凸透镜使光靠近主光轴，凹透镜使光远离主光轴
3. **三条特殊光线**：平行过焦点、过焦点平行、过光心不变
4. **易错警示**：凸透镜的会聚作用是指折射光比入射光更靠近主光轴

#### 5-2 生活中的透镜

【知识点】
- 照相机原理：物距大于2倍焦距（$u > 2f$），成倒立、缩小的实像
- 照相机结构：镜头相当于凸透镜，胶片相当于光屏
- 投影仪原理：物距在1倍焦距和2倍焦距之间（$f < u < 2f$），成倒立、放大的实像
- 投影仪结构：镜头相当于凸透镜，屏幕相当于光屏，平面镜改变光路
- 放大镜原理：物距小于1倍焦距（$u < f$），成正立、放大的虚像
- 实像：由实际光线会聚而成，可以用光屏承接，也可以用眼睛直接观察
- 虚像：由实际光线的反向延长线会聚而成，不能用光屏承接，只能用眼睛观察
- 照相机使用时，物体离镜头越远，像离镜头越近，像越小
- 投影仪使用时，投影片离镜头越近，屏幕离镜头越远，像越大
- 易错点：照相机和投影仪成的是实像，放大镜成的是虚像

#### 5-3 凸透镜成像的规律

【知识点】
- 凸透镜成像规律：
  - 当$u > 2f$时，成倒立、缩小的实像，像距$f < v < 2f$（照相机）
  - 当$u = 2f$时，成倒立、等大的实像，像距$v = 2f$
  - 当$f < u < 2f$时，成倒立、放大的实像，像距$v > 2f$（投影仪）
  - 当$u = f$时，不成像（平行光出射）
  - 当$u < f$时，成正立、放大的虚像，像与物同侧（放大镜）
- 实像都是倒立的，虚像都是正立的
- 物距减小时，像距增大，像变大
- 一倍焦距分虚实，二倍焦距分大小
- 凸透镜成像实验：蜡烛、凸透镜、光屏依次放在光具座上，调整三者中心在同一高度
- 易错点：虚像不能用光屏承接；物距等于焦距时不成像

#### 5-4 眼睛和眼镜

- 易错点：近视眼戴凹透镜，远视眼戴凸透镜；近视眼看近处清楚，远视眼看远处清楚

#### 5-5 显微镜和望远镜

- 望远镜的作用：物镜使远处的物体在焦点附近成实像，目镜相当于放大镜把这个像放大
- 视角：物体对眼睛的光心所张的角，视角越大，看到的物体越大
- 易错点：显微镜的物镜焦距短，目镜焦距长；望远镜的物镜焦距长，目镜焦距短

#### 6-1 质量

【知识点】
- 质量：物体所含物质的多少叫做质量，用字母m表示
- 质量的国际单位是千克（kg），常用单位还有吨（t）、克（g）、毫克（mg）
- 单位换算：$1\text{t} = 10^3\text{kg}$，$1\text{kg} = 10^3\text{g}$，$1\text{g} = 10^3\text{mg}$
- 质量是物体本身的一种属性，不随物体的形状、状态、位置、温度而改变
- 天平的使用方法：$①$放：将天平放在水平台面上；$②$移：将游码移到标尺左端的零刻度线处；$③$调：调节平衡螺母，使指针指在分度盘中央；$④$称：左盘放物体，右盘放砝码，用镊子向右盘中加减砝码，并调节游码在标尺上的位置，直到横梁恢复平衡；$⑤$读：右盘中砝码的总质量加上游码在标尺上所对的刻度值，就等于被测物体的质量；$⑥$收：测量完毕，把砝码放回盒中，游码归零
- 使用天平的注意事项：$①$被测物体的质量不能超过天平的量程；$②$用镊子加减砝码，不能用手接触砝码；$③$潮湿的物体和化学药品不能直接放到天平的托盘中
- 易错点：质量是物体的属性，不随位置改变；天平读数时，物体质量=砝码质量+游码示数

#### 6-2 密度

【知识点】
- 密度：某种物质组成的物体的质量与它的体积之比叫做这种物质的密度，用字母$ρ$表示
- 密度公式：$ρ = \dfrac{m}{V}$
- 变形公式：$m = ρV$，$V = \dfrac{m}{ρ}$
- 密度的国际单位是千克每立方米（kg/m³），常用单位还有克每立方厘米（g/cm³）
- 单位换算：$1\text{g/cm}^3 = 10^3\text{kg/m}^3$
- 水的密度：$ρ_{\text{水}} = 1.0 \times 10^3\text{kg/m}^3 = 1.0\text{g/cm}^3$
- 密度的物理意义：表示单位体积的某种物质的质量
- 密度是物质的一种特性，不同物质的密度一般不同
- 同种物质的密度与质量和体积无关，只与物质的种类、状态、温度有关
- 易错点：密度是物质的特性，与质量体积无关；不能说密度与质量成正比，与体积成反比

#### 6-3 测量物质的密度

【知识点】
- 实验原理：$ρ = \dfrac{m}{V}$
- 测量固体密度的步骤：$①$用天平测出固体的质量m；$②$在量筒中倒入适量的水，读出水的体积$V_1$；$③$用细线拴住固体，将其浸没在量筒的水中，读出水面到达的刻度$V_2$；$④$计算固体的体积$V = V_2 - V_1$；$⑤$计算密度$ρ = \dfrac{m}{V}$
- 测量液体密度的步骤：$①$用天平测出烧杯和液体的总质量$m_1$；$②$将烧杯中的部分液体倒入量筒中，读出量筒中液体的体积V；$③$用天平测出烧杯和剩余液体的总质量$m_2$；$④$计算量筒中液体的质量$m = m_1 - m_2$；$⑤$计算密度$ρ = \dfrac{m}{V}$
- 量筒的使用方法：$①$量筒要放在水平台面上；$②$读数时视线要与凹液面底部（或凸液面顶部）相平
- 易错点：测量液体密度时，不能先测空烧杯质量，再倒入液体测总质量，因为烧杯壁会残留液体，导致体积测量偏小

【标准考点】
1. 固体密度的测量（高频）
2. 液体密度的测量（高频）
3. 量筒的使用方法（中频）
4. 实验误差分析（中频）
5. 实验步骤的设计（中频）

【常见题型】
1. **实验题：固体密度测量**
   例：小明测量一块石块的密度，测得石块的质量为52g，量筒中水的体积为40mL，放入石块后水的体积为60mL，求石块的密度。
   答案：$V = 60\text{mL} - 40\text{mL} = 20\text{mL} = 20\text{cm}^3$，$ρ = \dfrac{m}{V} = \dfrac{52\text{g}}{20\text{cm}^3} = 2.6\text{g/cm}^3$

2. **实验题：液体密度测量**
   例：小红测量某液体的密度，测得烧杯和液体的总质量为80g，将部分液体倒入量筒后，量筒中液体的体积为40mL，烧杯和剩余液体的总质量为44g，求液体的密度。
   答案：$m = 80\text{g} - 44\text{g} = 36\text{g}$，$V = 40\text{mL} = 40\text{cm}^3$，$ρ = \dfrac{m}{V} = \dfrac{36\text{g}}{40\text{cm}^3} = 0.9\text{g/cm}^3$

3. **选择题：误差分析**
   例：在测量液体密度的实验中，如果先测空烧杯质量，再倒入液体测总质量，最后将液体全部倒入量筒测体积，则测得的密度（ ）
   A. 偏大 B. 偏小 C. 不变 D. 无法判断
   答案：A（烧杯壁残留液体，导致体积测量值偏小，密度偏大）

4. **填空题：量筒读数**
   例：用量筒测量液体体积时，视线要与 ___ 相平。
   答案：凹液面底部（或凸液面顶部）

【解题思路】
1. **固体密度测量**：先测质量，再用量筒测体积（排水法）
2. **液体密度测量**：先测总质量，倒出部分测体积，再测剩余质量
3. **量筒读数**：视线与凹液面底部相平
4. **误差分析**：看质量和体积的测量是否有偏差
5. **易错警示**：液体密度测量时，不能先测空烧杯质量，因为烧杯壁会残留液体

#### 6-4 密度的应用

【知识点】
- 利用密度鉴别物质：通过测量物体的密度，与密度表对照，可以鉴别物质的种类
- 利用密度求质量：对于不便直接称量的物体，可以先测出体积，查密度表，用$m = ρV$计算质量
- 利用密度求体积：对于形状不规则或不便于直接测量体积的物体，可以先测出质量，查密度表，用$V = \dfrac{m}{ρ}$计算体积
- 判断物体是空心还是实心：$①$比较密度：$ρ_{\text{物}} < ρ_{\text{实}}$，则是空心；$②$比较质量：$m_{\text{物}} < m_{\text{实}}$，则是空心；$③$比较体积：$V_{\text{物}} > V_{\text{实}}$，则是空心
- 密度在生活中的应用：$①$选种：饱满的种子密度大，干瘪的种子密度小；$②$鉴别真伪：如鉴别金银首饰；$③$材料选择：如飞机材料要密度小
- 易错点：判断空心实心时，要注意比较的对象

【标准考点】
1. 利用密度鉴别物质（高频）
2. 利用密度求质量和体积（高频）
3. 判断空心实心（中频）
4. 密度在生活中的应用（中频）

【常见题型】
1. **计算题：鉴别物质**
   例：一个金属块的质量是54g，体积是20cm³，求这个金属块的密度，并判断它是什么金属。
   答案：$ρ = \dfrac{m}{V} = \dfrac{54\text{g}}{20\text{cm}^3} = 2.7\text{g/cm}^3$，查密度表可知该金属是铝

2. **计算题：空心实心判断**
   例：一个铁球的质量是158g，体积是30cm³，判断这个铁球是空心还是实心的。（$ρ_{\text{铁}} = 7.9\text{g/cm}^3$）
   答案：$V_{\text{实}} = \dfrac{m}{ρ} = \dfrac{158\text{g}}{7.9\text{g/cm}^3} = 20\text{cm}^3 < 30\text{cm}^3$，所以是空心的

3. **计算题：求质量**
   例：一个铜球的体积是$10\text{cm}^3$，求这个铜球的质量。（$ρ_{\text{铜}} = 8.9\text{g/cm}^3$）
   答案：$m = ρV = 8.9\text{g/cm}^3 \times 10\text{cm}^3 = 89\text{g}$

4. **简答题：密度应用**
   例：为什么飞机制造要选用密度小的材料？
   答案：飞机需要减轻自身重量，在体积一定的情况下，密度越小，质量越小，有利于飞行。

【解题思路】
1. **鉴别物质**：测密度，查密度表对照
2. **求质量**：$m = ρV$，先查密度，再测体积
3. **求体积**：$V = \dfrac{m}{ρ}$，先测质量，再查密度
4. **空心实心判断**：比较密度、质量或体积
5. **易错警示**：判断空心实心时，要注意比较的对象和单位

### 第7章 运动和力

#### 7-1 力

【知识点】
- 力：物体对物体的作用叫做力，用字母F表示
- 力的单位：牛顿，简称牛，符号是N
- 力产生的条件：$①$必须有两个或两个以上的物体；$②$物体间必须有相互作用（可以不接触）
- 力的作用效果：$①$力可以改变物体的运动状态（速度的大小或方向发生变化）；$②$力可以改变物体的形状（使物体发生形变）
- 力的三要素：力的大小、方向、作用点
- 力的示意图：用一根带箭头的线段表示力，线段的起点或终点表示力的作用点，箭头表示力的方向，线段的长度表示力的大小
- 物体间力的作用是相互的，一个物体对另一个物体施力的同时，也受到另一个物体对它的作用力
- 相互作用力的特点：大小相等、方向相反、作用在同一直线上、作用在两个不同的物体上
- 易错点：力不能脱离物体而存在；不接触的物体间也可以有力的作用

2. 力的作用效果（高频）

【常见题型】

   例：关于力，下列说法正确的是（ ）
   A. 力可以脱离物体而存在 B. 不接触的物体间没有力的作用 C. 力是物体对物体的作用 D. 只有一个物体也能产生力
   答案：C

2. **选择题：力的作用效果**
   例：下列现象中，力的作用效果与其他三个不同的是（ ）
   A. 用力拉弓，弓变弯 B. 用力蹬车，车加速前进 C. 用力压弹簧，弹簧缩短 D. 用力拉橡皮筋，橡皮筋变长
   答案：B（B是改变运动状态，其他是改变形状）

3. **作图题：力的示意图**
   例：画出放在水平桌面上的书本受到的支持力的示意图。
   答案：从书本的重心向上画一个带箭头的线段，标注F或N

4. **简答题：力的相互性**
   例：为什么游泳时向后划水，人会向前进？
   答案：人向后划水时，给水一个向后的力，由于物体间力的作用是相互的，水也给人一个向前的力，所以人向前进。

【解题思路】
1. **力的判断**：看是否有施力物体和受力物体
2. **作用效果**：改变形状或改变运动状态
3. **力的示意图**：确定作用点、方向、大小，画带箭头的线段
4. **相互作用力**：大小相等、方向相反、作用在不同物体上
5. **易错警示**：力不能脱离物体存在；不接触的物体间也可以有力的作用（如磁力、重力）

#### 7-2 弹力

【知识点】
- 弹性：物体受力发生形变，不受力时又恢复到原来形状的性质
- 塑性：物体受力发生形变，不受力时不能恢复到原来形状的性质
- 弹力：物体由于发生弹性形变而产生的力
- 弹力产生的条件：$①$物体发生弹性形变；$②$物体相互接触
- 弹力的方向：与物体形变的方向相反，如压力、支持力、拉力都属于弹力
- 弹簧测力计的原理：在弹性限度内，弹簧的伸长量与受到的拉力成正比
- 弹簧测力计的使用方法：$①$观察量程和分度值；$②$检查指针是否指在零刻度线，不在则调零；$③$测量时，要使弹簧测力计的轴线方向与力的方向一致；$④$读数时，视线要与刻度盘垂直
- 易错点：弹力是接触力，不接触的物体间没有弹力；弹簧的伸长量不等于弹簧的长度

【标准考点】

   答案：C（重力不属于弹力）

   答案：D

【解题思路】

5. **易错警示**：伸长量≠长度；超过弹性限度，弹簧不能恢复

#### 7-3 重力

【知识点】
- 重力：由于地球的吸引而使物体受到的力，用字母G表示
- 重力的施力物体是地球
- 重力的大小：$G = mg$，其中$g = 9.8\text{N/kg}$（粗略计算时取$g = 10\text{N/kg}$）
- $g$的物理意义：质量为1kg的物体受到的重力为9.8N
- 重力的方向：竖直向下（不是垂直向下）
- 重力的作用点：重心
- 质地均匀、外形规则的物体的重心在它的几何中心上
- 物体的重心不一定在物体上，如圆环的重心在圆心
- 提高稳度的方法：$①$增大支撑面；$②$降低重心
- 易错点：重力方向是竖直向下，不是垂直向下；质量与重力的区别

【标准考点】

2. 重力公式的应用（高频）
3. 重力的方向（高频）

5. 质量与重力的区别（中频）

【常见题型】
1. **计算题：重力计算**
   例：一个物体的质量是5kg，求它受到的重力。（$g = 10\text{N/kg}$）
   答案：$G = mg = 5\text{kg} \times 10\text{N/kg} = 50\text{N}$

   答案：B

   答案：C

   例：建筑工人在砌墙时，常常用重垂线来检查墙壁是否竖直，这是为什么？

2. **重力方向**：竖直向下，可用于重垂线

4. **质量vs重力**：质量是物体属性，重力随位置变化
5. **易错警示**：重力方向是竖直向下，不是垂直向下

#### 7-4 牛顿第一定律

【知识点】
- 牛顿第一定律：一切物体在没有受到力的作用时，总保持静止状态或匀速直线运动状态
- 牛顿第一定律也叫惯性定律
- 牛顿第一定律是在大量经验事实的基础上，通过进一步推理而概括出来的，不能用实验直接证明
- 惯性：一切物体都有保持原来运动状态不变的性质，这种性质叫做惯性
- 一切物体在任何情况下都有惯性
- 惯性的大小只与物体的质量有关，质量越大，惯性越大
- 惯性不是力，不能说"受到惯性""惯性力"，应该说"具有惯性""由于惯性"
- 易错点：惯性是物体的属性，不是力；惯性大小只与质量有关，与速度无关

   答案：D

【解题思路】

2. **惯性判断**：一切物体在任何情况下都有惯性
3. **惯性大小**：只与质量有关，与速度、受力情况无关
4. **惯性解释现象**：$①$明确研究对象原来的运动状态；$②$分析哪部分受力改变运动状态；$③$哪部分由于惯性保持原来状态
5. **易错警示**：惯性不是力，不能说"受到惯性"

#### 7-5 二力平衡

【知识点】
- 平衡状态：物体保持静止或匀速直线运动状态
- 二力平衡：物体在两个力的作用下保持平衡状态
- 二力平衡的条件：$①$作用在同一物体上；$②$大小相等；$③$方向相反；$④$作用在同一直线上（同体、等大、反向、共线）
- 二力平衡的应用：$①$根据已知力求另一个力；$②$判断物体的运动状态
- 相互作用力与平衡力的区别：$①$相互作用力作用在两个不同的物体上；$②$平衡力作用在同一个物体上
- 物体受平衡力作用时，运动状态不变（静止或匀速直线运动）
- 物体受非平衡力作用时，运动状态改变
- 易错点：平衡力作用在同一物体上，相互作用力作用在不同物体上

   答案：B（A是相互作用力，B是平衡力）

5. **简答题：力与运动**
   例：为什么物体受到平衡力作用时，运动状态不变？
   答案：平衡力的合力为零，相当于不受力，根据牛顿第一定律，物体保持静止或匀速直线运动状态。

【解题思路】

2. **平衡状态**：静止或匀速直线运动
3. **应用**：已知一个力求另一个力，方向相反大小相等
4. **区分平衡力与相互作用力**：看是否作用在同一物体上
5. **易错警示**：平衡力作用在同一物体，相互作用力作用在不同物体

#### 7-6 摩擦力

【知识点】
- 摩擦力：两个相互接触的物体，当它们做相对运动或有相对运动趋势时，在接触面上会产生一种阻碍相对运动的力
- 摩擦力的分类：$①$静摩擦力：物体有相对运动趋势但保持静止时产生的摩擦力；$②$滑动摩擦力：一个物体在另一个物体表面滑动时产生的摩擦力；$③$滚动摩擦力：一个物体在另一个物体表面滚动时产生的摩擦力
- 滑动摩擦力的大小：$①$与压力大小有关：压力越大，滑动摩擦力越大；$②$与接触面的粗糙程度有关：接触面越粗糙，滑动摩擦力越大
- 滑动摩擦力的方向：与物体相对运动的方向相反
- 增大摩擦的方法：$①$增大压力；$②$增大接触面的粗糙程度；$③$变滚动为滑动
- 减小摩擦的方法：$①$减小压力；$②$减小接触面的粗糙程度；$③$变滑动为滚动；$④$使接触面分离（加润滑油、气垫、磁悬浮）
- 摩擦力的测量：用弹簧测力计水平拉动物体做匀速直线运动，根据二力平衡，拉力等于摩擦力
- 易错点：摩擦力不一定阻碍物体运动，有时也促进运动；滚动摩擦远小于滑动摩擦

### 第8章 压强和浮力

#### 8-1 压强

【知识点】
- 压力：垂直作用在物体表面上的力，方向垂直于受力面
- 压力的作用效果与压力的大小和受力面积有关
- 压强：物体所受压力的大小与受力面积之比叫做压强，用字母p表示
- 压强公式：$p = \dfrac{F}{S}$
- 压强的国际单位是帕斯卡（Pa），$1\text{Pa} = 1\text{N/m}^2$
- 增大压强的方法：$①$增大压力；$②$减小受力面积；$③$同时增大压力和减小受力面积
- 减小压强的方法：$①$减小压力；$②$增大受力面积；$③$同时减小压力和增大受力面积
- 生活中的应用：菜刀磨得锋利（减小受力面积增大压强）、书包带宽（增大受力面积减小压强）
- 易错点：压力不一定等于重力；受力面积是实际接触面积

   答案：C（只有在水平面上且无其他力时，压力才等于重力）

   答案：$\dfrac{p_甲}{p_乙} = \dfrac{F_甲/S_甲}{F_乙/S_乙} = \dfrac{m_甲 g / S_甲}{m_乙 g / S_乙} = \dfrac{m_甲}{m_乙} \times \dfrac{S_乙}{S_甲} = \dfrac{2}{1} \times \dfrac{2}{1} = 4:1$

3. **增大减小压强**：看压力和受力面积的变化
4. **比值问题**：代入公式，化简求解
5. **易错警示**：压力不一定等于重力；受力面积是实际接触面积，不是物体底面积

#### 8-2 液体的压强

【知识点】
- 液体压强的特点：$①$液体对容器底和侧壁都有压强；$②$液体内部向各个方向都有压强；$③$同种液体在同一深度，各个方向的压强相等；$④$同种液体，深度越深，压强越大；$⑤$在不同液体的同一深度，液体密度越大，压强越大
- 液体压强公式：$p = ρgh$，其中$ρ$为液体密度（kg/m³），$g = 9.8\text{N/kg}$，$h$为液体深度（m）
- 深度h：从液面到研究点的竖直距离
- 连通器：上端开口、下端连通的容器
- 连通器的原理：连通器里装同种液体，在液体不流动时，各容器中的液面高度总是相同的
- 连通器的应用：茶壶、锅炉水位计、船闸、乳牛自动喂水器
- 液体压强的计算：先求压强$p = ρgh$，再求压力$F = pS$
- 易错点：液体压强只与液体密度和深度有关，与容器形状无关；h是深度不是高度

#### 8-3 大气压强

【知识点】
- 大气压强：大气对浸在它里面的物体的压强叫做大气压强，简称大气压
- 大气压产生的原因：空气受重力作用，且具有流动性
- 大气压的存在：马德堡半球实验、吸盘、吸管吸饮料、针筒吸药液等
- 大气压的测量：托里拆利实验
- 标准大气压：$p_0 = 1.013 \times 10^5\text{Pa}$，相当于760mm高水银柱产生的压强
- 大气压的变化：$①$随高度增加而减小；$②$与天气、季节有关
- 沸点与气压的关系：气压增大，沸点升高；气压减小，沸点降低
- 易错点：托里拆利实验中，玻璃管倾斜、粗细、上提下压都不影响水银柱高度

#### 8-4 流体压强与流速的关系

【知识点】

- 流体压强与流速的关系：在气体和液体中，流速越大的位置压强越小

- 易错点：流速大压强小，不是流速大压力大

#### 8-5 浮力

【知识点】
- 浮力：浸在液体（或气体）中的物体受到液体（或气体）向上托的力叫做浮力，用$F_{\text{浮}}$表示
- 浮力的方向：竖直向上
- 浮力产生的原因：液体对物体向上和向下的压力差
- 阿基米德原理：浸在液体中的物体受到向上的浮力，浮力的大小等于它排开的液体所受的重力
- 阿基米德原理公式：$F_{\text{浮}} = G_{\text{排}} = ρ_{\text{液}}gV_{\text{排}}$
- 物体的浮沉条件：
  - 上浮：$F_{\text{浮}} > G$，$ρ_{\text{液}} > ρ_{\text{物}}$
  - 悬浮：$F_{\text{浮}} = G$，$ρ_{\text{液}} = ρ_{\text{物}}$
  - 下沉：$F_{\text{浮}} < G$，$ρ_{\text{液}} < ρ_{\text{物}}$
  - 漂浮：$F_{\text{浮}} = G$，$V_{\text{排}} < V_{\text{物}}$
- 浮力的应用：$①$轮船：用"空心"的办法增大浮力；$②$潜水艇：通过改变自身重力实现浮沉；$③$气球和飞艇：充入密度小于空气的气体
- 易错点：浮力大小只与液体密度和排开液体的体积有关，与物体形状、深度无关

   例：一个体积为$100\text{cm}^3$的铁块浸没在水中，求它受到的浮力。（$ρ_{\text{水}} = 1.0 \times 10^3\text{kg/m}^3$，$g = 10\text{N/kg}$）
   答案：$V_{\text{排}} = V_{\text{物}} = 100\text{cm}^3 = 10^{-4}\text{m}^3$，$F_{\text{浮}} = ρ_{\text{液}}gV_{\text{排}} = 1.0 \times 10^3 \times 10 \times 10^{-4} = 1\text{N}$

   答案：A

3. **计算题：浮力计算**
   例：一个重为10N的物体浸没在水中，受到的浮力是8N，求物体的密度。（$ρ_{\text{水}} = 1.0 \times 10^3\text{kg/m}^3$，$g = 10\text{N/kg}$）
   答案：$F_{\text{浮}} = ρ_{\text{水}}gV_{\text{排}}$，$V_{\text{排}} = \dfrac{F_{\text{浮}}}{ρ_{\text{水}}g} = \dfrac{8}{1.0 \times 10^3 \times 10} = 8 \times 10^{-4}\text{m}^3$，$V_{\text{物}} = V_{\text{排}} = 8 \times 10^{-4}\text{m}^3$，$m = \dfrac{G}{g} = \dfrac{10}{10} = 1\text{kg}$，$ρ_{\text{物}} = \dfrac{m}{V} = \dfrac{1}{8 \times 10^{-4}} = 1.25 \times 10^3\text{kg/m}^3$

4. **简答题：浮力应用**
   例：潜水艇是如何实现上浮和下潜的？
   答案：潜水艇通过改变自身重力来实现浮沉。向水舱充水时，重力增大，重力大于浮力，下潜；排出水时，重力减小，重力小于浮力，上浮。

【解题思路】
1. **阿基米德原理**：$F_{\text{浮}} = ρ_{\text{液}}gV_{\text{排}}$，$V_{\text{排}}$是排开液体的体积
2. **浮沉条件**：比较浮力与重力，或比较液体密度与物体密度
3. **漂浮和悬浮**：漂浮时$F_{\text{浮}} = G$，$V_{\text{排}} < V_{\text{物}}$；悬浮时$F_{\text{浮}} = G$，$V_{\text{排}} = V_{\text{物}}$
4. **浮力应用**：轮船增大浮力，潜水艇改变重力，气球充轻气体
5. **易错警示**：浮力大小只与$ρ_{\text{液}}$和$V_{\text{排}}$有关，与深度、形状无关

### 第9章 机械和功

#### 9-1 杠杆

【知识点】
- 杠杆：在力的作用下能绕着固定点转动的硬棒
- 杠杆的五要素：$①$支点（O）：杠杆绕着转动的固定点；$②$动力（$F_1$）：使杠杆转动的力；$③$阻力（$F_2$）：阻碍杠杆转动的力；$④$动力臂（$l_1$）：从支点到动力作用线的距离；$⑤$阻力臂（$l_2$）：从支点到阻力作用线的距离
- 杠杆的平衡条件：动力×动力臂 = 阻力×阻力臂，即$F_1l_1 = F_2l_2$
- 杠杆的分类：
  - 省力杠杆：$l_1 > l_2$，$F_1 < F_2$，省力但费距离，如撬棒、扳手
  - 费力杠杆：$l_1 < l_2$，$F_1 > F_2$，费力但省距离，如筷子、钓鱼竿
  - 等臂杠杆：$l_1 = l_2$，$F_1 = F_2$，不省力也不费力，如天平
- 易错点：力臂是从支点到力的作用线的距离，不是支点到力的作用点的距离

2. 杠杆的平衡条件（高频）
3. 杠杆的分类（高频）
4. 力臂的画法（中频）
5. 杠杆平衡条件的应用（中频）

【常见题型】
1. **选择题：杠杆分类**

   A. 筷子 B. 钓鱼竿 C. 扳手 D. 镊子
   答案：C

2. **作图题：力臂画法**
   例：画出图中杠杆的动力臂和阻力臂。
   答案：从支点向力的作用线作垂线，垂线段的长度就是力臂

3. **计算题：杠杆平衡条件**
   例：一个杠杆的动力臂是阻力臂的2倍，阻力是100N，求动力。
   答案：$F_1l_1 = F_2l_2$，$F_1 \times 2l_2 = 100 \times l_2$，$F_1 = 50\text{N}$

4. **填空题：杠杆平衡**
   例：杠杆的平衡条件是 ___ 。
   答案：动力×动力臂 = 阻力×阻力臂（$F_1l_1 = F_2l_2$）

5. **简答题：杠杆应用**
   例：为什么使用省力杠杆可以省力，但要费距离？
   答案：根据$F_1l_1 = F_2l_2$，省力杠杆$l_1 > l_2$，所以$F_1 < F_2$，但动力移动的距离大于阻力移动的距离。

【解题思路】
1. **杠杆五要素**：支点、动力、阻力、动力臂、阻力臂
2. **平衡条件**：$F_1l_1 = F_2l_2$
3. **杠杆分类**：比较动力臂和阻力臂的大小
4. **力臂画法**：从支点向力的作用线作垂线
5. **易错警示**：力臂是支点到力的作用线的距离，不是到力的作用点的距离

#### 9-2 滑轮

【知识点】
- 定滑轮：轴固定不动的滑轮
- 定滑轮的特点：不省力，但可以改变力的方向，实质是等臂杠杆
- 动滑轮：轴随物体一起运动的滑轮
- 动滑轮的特点：省一半力，但不能改变力的方向，实质是动力臂为阻力臂2倍的杠杆
- 滑轮组：定滑轮和动滑轮组合在一起
- 滑轮组的特点：既可以省力，又可以改变力的方向
- 滑轮组的省力情况：$F = \dfrac{G}{n}$（不计摩擦和动滑轮重），$s = nh$，其中n是承担物重的绳子段数
- n的判断方法：数直接与动滑轮相连的绳子段数
- 易错点：动滑轮省一半力是指不计摩擦和动滑轮重的情况

5. **易错警示**：动滑轮省一半力是在不计摩擦和动滑轮重的情况下

#### 9-3 功

【知识点】
- 功的概念：如果一个力作用在物体上，物体在这个力的方向上移动了一段距离，就说这个力对物体做了功
- 做功的两个必要因素：$①$作用在物体上的力；$②$物体在这个力的方向上移动的距离
- 不做功的三种情况：$①$有力无距离（如推而未动）；$②$有距离无力（如物体由于惯性运动）；$③$力和距离垂直（如提水桶水平移动）
- 功的公式：$W = Fs$
- 功的单位：焦耳（J），$1\text{J} = 1\text{N} \cdot \text{m}$
- 功的原理：使用任何机械都不省功
- 易错点：做功必须满足两个必要因素；力和距离要对应

   答案：A

   答案：使用机械时，虽然可以省力或省距离，但不能既省力又省距离，所以使用任何机械都不省功。

4. **功的原理**：使用任何机械都不省功
5. **易错警示**：提水桶水平移动，提力不做功（力和距离垂直）

#### 9-4 功率

【知识点】
- 功率的概念：功与做功所用时间之比叫做功率，用字母P表示
- 功率的物理意义：表示做功快慢的物理量
- 功率的公式：$P = \dfrac{W}{t}$
- 功率的变形公式：$P = Fv$（当物体做匀速直线运动时）
- 功率的单位：瓦特（W），$1\text{W} = 1\text{J/s}$，常用单位还有千瓦（kW），$1\text{kW} = 10^3\text{W}$
- 功率大表示做功快，但不一定做功多
- 易错点：功率大不一定做功多，还要看时间；功率小不一定做功少

【常见题型】

   例：小明用50N的水平推力推着重100N的箱子在水平地面上前进了10m，用了20s，求小明对箱子做功的功率。
   答案：$W = Fs = 50\text{N} \times 10\text{m} = 500\text{J}$，$P = \dfrac{W}{t} = \dfrac{500\text{J}}{20\text{s}} = 25\text{W}$

   答案：C

   答案：瓦特（W）；$10^3$

   例：一辆汽车在平直公路上匀速行驶，受到的牵引力是2000N，速度是20m/s，求汽车牵引力的功率。
   答案：$P = Fv = 2000\text{N} \times 20\text{m/s} = 40000\text{W} = 40\text{kW}$

5. **简答题：功率与做功**

2. **功率物理意义**：表示做功快慢，不是做功多少
3. **$P = Fv$**：当物体匀速运动时，功率等于力乘以速度
4. **单位换算**：$1\text{kW} = 10^3\text{W}$
5. **易错警示**：功率大不一定做功多，还要看时间

#### 9-5 机械效率

【知识点】
- 有用功：对人们有用的功，用$W_{\text{有}}$表示
- 额外功：对人们无用但又不得不做的功，用$W_{\text{额}}$表示
- 总功：有用功与额外功之和，用$W_{\text{总}}$表示，$W_{\text{总}} = W_{\text{有}} + W_{\text{额}}$
- 机械效率：有用功与总功的比值，用$η$表示
- 机械效率公式：$η = \dfrac{W_{\text{有}}}{W_{\text{总}}} \times 100\%$
- 机械效率总是小于1（因为有用功总小于总功）
- 提高机械效率的方法：$①$增大有用功；$②$减小额外功（如减小摩擦、减小机械自重）
- 滑轮组的机械效率：$η = \dfrac{W_{\text{有}}}{W_{\text{总}}} = \dfrac{Gh}{Fs} = \dfrac{Gh}{Fnh} = \dfrac{G}{nF}$
- 斜面的机械效率：$η = \dfrac{W_{\text{有}}}{W_{\text{总}}} = \dfrac{Gh}{Fs}$
- 易错点：机械效率与功率无关；机械效率高不一定省力

【标准考点】

   例：用滑轮组提升重为400N的物体，物体上升2m，拉力为250N，绳子自由端移动4m，求滑轮组的机械效率。
   答案：$W_{\text{有}} = Gh = 400\text{N} \times 2\text{m} = 800\text{J}$，$W_{\text{总}} = Fs = 250\text{N} \times 4\text{m} = 1000\text{J}$，$η = \dfrac{W_{\text{有}}}{W_{\text{总}}} = \dfrac{800\text{J}}{1000\text{J}} = 80\%$

   答案：D

   例：机械效率的公式是 ___ ，机械效率总是 ___ 1（选填"大于""等于"或"小于"）。
   答案：$η = \dfrac{W_{\text{有}}}{W_{\text{总}}} \times 100\%$；小于

4. **简答题：提高机械效率**
   例：如何提高滑轮组的机械效率？
   答案：$①$增大物重（增大有用功）；$②$减小动滑轮重（减小额外功）；$③$减小摩擦（减小额外功）。

   例：用沿斜面向上的拉力将重为100N的物体从斜面底端匀速拉到顶端，斜面高2m，长5m，拉力为50N，求斜面的机械效率。
   答案：$W_{\text{有}} = Gh = 100\text{N} \times 2\text{m} = 200\text{J}$，$W_{\text{总}} = Fs = 50\text{N} \times 5\text{m} = 250\text{J}$，$η = \dfrac{W_{\text{有}}}{W_{\text{总}}} = \dfrac{200\text{J}}{250\text{J}} = 80\%$

【解题思路】

4. **提高机械效率**：增大有用功，减小额外功
5. **易错警示**：机械效率与功率无关；机械效率高不一定省力

### 第10章 机械能、内能及其转化

#### 10-1 机械能

【知识点】
- 能量：物体能够对外做功，表示这个物体具有能量
- 动能：物体由于运动而具有的能
- 影响动能的因素：质量和速度，质量越大，速度越大，动能越大
- 势能：重力势能和弹性势能
- 重力势能：物体由于被举高而具有的能
- 影响重力势能的因素：质量和高度，质量越大，高度越高，重力势能越大
- 弹性势能：物体由于发生弹性形变而具有的能
- 影响弹性势能的因素：弹性形变的大小
- 机械能：动能和势能的总和
- 动能和势能的转化：动能可以转化为势能，势能也可以转化为动能
- 机械能守恒：如果只有动能和势能相互转化，机械能的总和保持不变
- 易错点：动能和势能可以相互转化，但机械能可能不守恒（有摩擦时）

   答案：重力势；动

4. **简答题：能量转化**

   答案：从最高点到最低点，高度降低，速度增大，重力势能转化为动能。

2. **重力势能判断**：看物体是否被举高，质量和高度
3. **弹性势能判断**：看物体是否发生弹性形变
4. **能量转化**：动能→势能（速度减小，高度增加）；势能→动能（高度降低，速度增大）
5. **易错警示**：机械能守恒的条件是只有动能和势能相互转化，没有摩擦

#### 10-2 内能

【知识点】
- 内能：物体内部所有分子热运动的动能与分子势能的总和
- 一切物体在任何情况下都具有内能
- 影响内能的因素：温度、质量、状态
- 温度越高，分子运动越剧烈，内能越大
- 改变内能的两种方式：做功和热传递
- 做功改变内能：对物体做功，物体内能增加；物体对外做功，物体内能减少
- 热传递改变内能：热量从高温物体传递到低温物体
- 热传递的条件：存在温度差
- 热传递的方向：从高温物体传到低温物体，或从物体的高温部分传到低温部分
- 热量：在热传递过程中，传递内能的多少叫做热量
- 温度、内能、热量的区别：温度是状态量，内能是状态量，热量是过程量
- 易错点：不能说"含有热量"或"具有热量"；温度高的物体内能不一定大（还要看质量）

3. 做功改变内能的实例（高频）

5. 温度、内能、热量的区别（中频）

   A. 0℃的物体没有内能 B. 温度高的物体内能一定大 C. 物体温度升高，内能一定增加 D. 运动的物体一定比静止的物体内能大
   答案：C

   例：下列事例中，通过做功改变物体内能的是（ ）

   答案：C

【解题思路】
1. **内能判断**：一切物体都有内能，温度越高内能越大
2. **改变内能方式**：做功（机械能↔内能）和热传递（内能转移）
3. **做功实例**：摩擦生热、压缩气体、钻木取火是做功；晒太阳、热水袋是热传递
4. **热传递**：条件是温度差，方向是高温→低温
5. **易错警示**：热量是过程量，不能说"含有"；温度升高内能增加，但内能增加不一定温度升高（如熔化过程）

#### 10-3 比热容

【知识点】
- 比热容：一定质量的某种物质，在温度升高时吸收的热量与它的质量和升高的温度乘积之比
- 比热容用符号c表示
- 比热容的单位：焦每千克摄氏度，符号J/(kg·℃)
- 水的比热容：$c_{水}=4.2\times10^3$ J/(kg·℃)
- 比热容是物质的一种特性，不同物质的比热容一般不同
- 比热容与物质的种类和状态有关，与质量、温度变化、吸收热量无关
- 水的比热容较大的应用：调节气温、作冷却剂、取暖
- 热量计算公式：$Q=cm\Delta t$
  - 吸热公式：$Q_{吸}=cm(t-t_0)$
  - 放热公式：$Q_{放}=cm(t_0-t)$
- 热平衡方程：$Q_{吸}=Q_{放}$（不计热量损失）
- 易错点：比热容是物质特性，与质量、温度变化无关；计算时注意温度变化量$\Delta t$

【标准考点】
1. 比热容的概念和物理意义（高频）
2. 比热容是物质特性的理解（高频）
3. 水的比热容较大的应用（中频）
4. 热量计算公式的应用（高频）
5. 热平衡方程的应用（中频）

【常见题型】
1. **选择题：比热容概念**
   例：关于比热容，下列说法正确的是（ ）
   A. 物体的质量越大，比热容越大 B. 物体吸收的热量越多，比热容越大 C. 物体的温度变化越大，比热容越大 D. 比热容是物质的一种特性，与质量、温度变化、吸收热量无关
   答案：D

2. **计算题：热量计算**
   例：质量为2kg的水，温度从20℃升高到70℃，求水吸收的热量。$[c_{水}=4.2\times10^3$ J/(kg·℃)]
   答案：$Q_{吸}=cm(t-t_0)=4.2\times10^3\times2\times(70-20)=4.2\times10^5$ J

3. **简答题：水的比热容应用**
   例：为什么沿海地区昼夜温差比内陆地区小？
   答案：水的比热容比砂石大，相同质量的水和砂石吸收或放出相同热量时，水的温度变化小。沿海地区水多，所以昼夜温差小。

4. **计算题：热平衡**
   例：将质量为1kg、温度为80℃的铁块放入质量为2kg、温度为20℃的水中，不计热量损失，求最终温度。$[c_{铁}=0.46\times10^3$ J/(kg·℃)，$c_{水}=4.2\times10^3$ J/(kg·℃)]
   答案：$Q_{放}=Q_{吸}$，$c_{铁}m_{铁}(t_0-t)=c_{水}m_{水}(t-t_0')$，$0.46\times10^3\times1\times(80-t)=4.2\times10^3\times2\times(t-20)$，解得$t\approx22.4$℃

5. **选择题：比热容特性**
   例：下列情况中，比热容发生变化的是（ ）
   A. 水结成冰 B. 将铁块切成两半 C. 把铁块加热 D. 把铁块从地球带到月球
   答案：A（状态改变，比热容改变）

【解题思路】
1. **比热容理解**：是物质特性，只与物质种类和状态有关
2. **公式应用**：$Q=cm\Delta t$，注意$\Delta t$是温度变化量
3. **吸放热判断**：温度升高吸热，温度降低放热
4. **热平衡**：$Q_{吸}=Q_{放}$，列方程求解
5. **易错警示**：比热容与质量、温度变化、热量无关；计算时单位要统一

#### 10-4 热机

【知识点】
- 热机：利用内能做功的机械
- 热机的分类：蒸汽机、内燃机、汽轮机、喷气发动机等
- 内燃机：燃料在汽缸内燃烧的热机
- 内燃机的分类：汽油机和柴油机
- 内燃机的工作冲程：吸气冲程、压缩冲程、做功冲程、排气冲程
- 一个工作循环：活塞往复两次，曲轴转动两周，完成四个冲程，对外做功一次
- 压缩冲程：机械能转化为内能
- 做功冲程：内能转化为机械能
- 汽油机和柴油机的区别：
  - 汽油机：汽缸顶部有火花塞，点燃式，效率较低
  - 柴油机：汽缸顶部有喷油嘴，压燃式，效率较高
- 热机的效率：用来做有用功的能量与燃料完全燃烧放出的能量之比
- 提高热机效率的方法：使燃料充分燃烧、减少热量损失、减少摩擦
- 易错点：一个工作循环只有做功冲程对外做功，其他三个冲程靠飞轮惯性完成

#### 10-5 燃料的利用及其对环境的影响

【知识点】
- 燃料的热值：某种燃料完全燃烧放出的热量与其质量之比，用q表示
- 热值的单位：焦每千克，符号J/kg（气体燃料用J/m³）
- 燃料完全燃烧放热公式：$Q_{放}=mq$（固体、液体）或$Q_{放}=Vq$（气体）
- 热值是燃料的一种特性，不同燃料的热值一般不同
- 燃料的利用效率（炉子的效率）：有效利用的热量与燃料完全燃烧放出的热量之比
- $η=\dfrac{Q_{有效}}{Q_{放}}\times100\%$
- 提高燃料利用率的方法：使燃料充分燃烧、减少热量损失
- 燃料燃烧对环境的影响：
  - 产生二氧化碳：温室效应
  - 产生二氧化硫、氮氧化物：酸雨
  - 产生粉尘：空气污染
- 新能源的开发和利用：太阳能、风能、地热能、核能等
- 易错点：热值是燃料特性，与质量、燃烧情况无关；完全燃烧才能用$Q=mq$计算

【标准考点】
1. 热值的概念和物理意义（高频）
2. 燃料燃烧放热计算（高频）
3. 燃料利用效率的计算（中频）
4. 燃料燃烧对环境的影响（低频）
5. 新能源的了解（低频）

【常见题型】
1. **选择题：热值概念**
   例：关于燃料的热值，下列说法正确的是（ ）
   A. 燃料的质量越大，热值越大 B. 燃料燃烧越充分，热值越大 C. 热值是燃料的特性，与质量、燃烧情况无关 D. 不同燃料的热值一定不同
   答案：C

2. **计算题：放热计算**
   例：完全燃烧2kg的酒精，能放出多少热量？$[q_{酒精}=3.0\times10^7$ J/kg]
   答案：$Q_{放}=mq=2\times3.0\times10^7=6.0\times10^7$ J

3. **计算题：效率计算**
   例：某锅炉完全燃烧5kg的煤，将200kg的水从20℃加热到70℃，求锅炉的效率。$[q_{煤}=3.4\times10^7$ J/kg，$c_{水}=4.2\times10^3$ J/(kg·℃)]
   答案：$Q_{放}=mq=5\times3.4\times10^7=1.7\times10^8$ J，$Q_{吸}=cm\Delta t=4.2\times10^3\times200\times(70-20)=4.2\times10^7$ J，$η=\dfrac{Q_{吸}}{Q_{放}}\times100\%=\dfrac{4.2\times10^7}{1.7\times10^8}\times100\%\approx24.7\%$

4. **简答题：环境保护**
   例：燃料燃烧对环境有哪些影响？如何减少污染？
   答案：影响：产生二氧化碳导致温室效应，产生二氧化硫和氮氧化物导致酸雨，产生粉尘污染空气。减少污染：使用清洁能源、改进燃烧技术、安装净化设备。

5. **填空题：新能源**
   例：常见的清洁能源有 ___ 、 ___ 、 ___ 等。
   答案：太阳能；风能；地热能（答案不唯一）

【解题思路】
1. **热值理解**：是燃料特性，只与燃料种类有关
2. **放热计算**：固体液体用$Q=mq$，气体用$Q=Vq$
3. **效率计算**：$η=\dfrac{Q_{有效}}{Q_{放}}$，注意区分有用热量和总热量
4. **环境保护**：识别污染物，提出改进措施
5. **易错警示**：必须是完全燃烧才能用$Q=mq$；热值与质量无关

### 第11章 简单电路

#### 11-1 简单电现象

【知识点】
- 摩擦起电：用摩擦的方法使物体带电
- 摩擦起电的本质：电子的转移，不是创造了电荷
- 两种电荷：正电荷（丝绸摩擦过的玻璃棒带的电荷）和负电荷（毛皮摩擦过的橡胶棒带的电荷）
- 电荷间的相互作用：同种电荷相互排斥，异种电荷相互吸引
- 验电器：检验物体是否带电的仪器，原理是同种电荷相互排斥
- 电荷量：电荷的多少，用Q表示，单位是库仑（C）
- 元电荷：最小的电荷量，$e=1.6\times10^{-19}$ C
- 导体：容易导电的物体，如金属、人体、大地、酸碱盐溶液
- 绝缘体：不容易导电的物体，如橡胶、塑料、陶瓷、玻璃
- 易错点：摩擦起电是电子转移，不是创造电荷；带电体吸引轻小物体，不一定是异种电荷

【标准考点】
1. 摩擦起电的本质（高频）
2. 两种电荷及其相互作用（高频）
3. 验电器的原理（中频）
4. 导体和绝缘体的区分（中频）
5. 带电体的性质（中频）

【常见题型】
1. **选择题：摩擦起电**
   例：用丝绸摩擦玻璃棒后，玻璃棒带正电，这是因为（ ）
   A. 玻璃棒得到了电子 B. 玻璃棒失去了电子 C. 丝绸得到了质子 D. 玻璃棒得到了质子
   答案：B

2. **选择题：电荷相互作用**
   例：甲乙丙三个轻质小球，甲吸引乙，乙排斥丙，已知丙带正电，则（ ）
   A. 甲一定带负电 B. 甲可能带负电，也可能不带电 C. 乙一定带正电 D. 乙可能带正电，也可能不带电
   答案：B（乙排斥丙，乙带正电；甲吸引乙，甲可能带负电也可能不带电）

3. **填空题：验电器**
   例：验电器的原理是 ___ 。
   答案：同种电荷相互排斥

4. **选择题：导体绝缘体**
   例：下列物体中，都属于导体的是（ ）
   A. 铜、橡胶 B. 人体、大地 C. 塑料、玻璃 D. 陶瓷、盐水
   答案：B

5. **简答题：带电体性质**
   例：用塑料梳子梳干燥的头发时，头发会随梳子飘起来，为什么？
   答案：梳子与头发摩擦后带电，带电体能吸引轻小物体，所以头发会随梳子飘起来。

【解题思路】
1. **摩擦起电本质**：电子转移，得电子带负电，失电子带正电
2. **电荷相互作用**：同种排斥，异种吸引；注意带电体也能吸引不带电的轻小物体
3. **验电器**：利用同种电荷排斥原理
4. **导体绝缘体**：看是否有大量自由移动的电荷
5. **易错警示**：吸引≠异种电荷，也可能是带电体吸引轻小物体

#### 11-2 认识电路

【知识点】
- 电路的组成：电源、用电器、开关、导线
  - 电源：提供电能的装置（如电池、发电机）
  - 用电器：消耗电能的装置（如灯泡、电动机）
  - 开关：控制电路通断的装置
  - 导线：连接电路各元件，输送电能
- 电路的状态：
  - 通路：处处连通的电路，用电器正常工作
  - 断路（开路）：某处断开的电路，用电器不工作
  - 短路：电源两极直接用导线连接（电源短路）或用电器两端直接用导线连接（用电器短路）
- 电源短路的危害：电流过大，可能烧坏电源，甚至引起火灾
- 电路图：用规定的符号表示电路连接的图
- 常见电路元件符号：电池、开关、灯泡、电阻、电流表、电压表等
- 画电路图的要求：
  - 使用规定的元件符号
  - 元件分布均匀，不要画在拐角处
  - 电路图最好画成长方形，导线横平竖直
  - 简洁、整齐、美观
- 易错点：电源短路和用电器短路的区别；画电路图时元件符号要规范

【标准考点】
1. 电路的组成（高频）
2. 电路三种状态的判断（高频）
3. 短路的危害（中频）
4. 电路图的画法（高频）
5. 根据实物图画电路图或根据电路图连接实物图（高频）

【常见题型】
1. **选择题：电路组成**
   例：一个完整的电路必须包括（ ）
   A. 电源、开关、导线 B. 电源、用电器、导线 C. 电源、用电器、开关、导线 D. 用电器、开关、导线
   答案：C

2. **选择题：电路状态**

3. **简答题：短路危害**

   答案：电源短路时，电路中电流很大，会烧坏电源，甚至引起火灾。

4. **作图题：画电路图**

5. **连接题：根据电路图连接实物**

【解题思路】
1. **电路组成识别**：必须有电源、用电器、开关、导线四个部分
2. **电路状态判断**：看电流是否能从电源正极经过用电器回到负极
3. **短路判断**：看电流是否不经过用电器直接回到电源负极

5. **连接实物**：按照电路图从电源正极开始，依次连接各元件

#### 11-3 不同物质的导电性能

【知识点】
- 导体：容易导电的物体
  - 常见导体：金属、人体、大地、石墨、酸碱盐的水溶液
  - 导体容易导电的原因：内部有大量自由移动的电荷（自由电子或离子）
- 绝缘体：不容易导电的物体
  - 常见绝缘体：橡胶、塑料、陶瓷、玻璃、干木头、油
  - 绝缘体不容易导电的原因：内部几乎没有自由移动的电荷
- 导体和绝缘体之间没有绝对的界限，在一定条件下可以相互转化
  - 例如：干木头是绝缘体，湿木头是导体；常温下的玻璃是绝缘体，红炽状态的玻璃是导体
- 半导体：导电性能介于导体和绝缘体之间的物质
  - 常见半导体材料：硅、锗
  - 半导体的应用：二极管、三极管、集成电路
  - 半导体特性：单向导电性（二极管）
- 超导体：某些物质在温度降到足够低时，电阻变为零
  - 超导体的应用：输电导线、电动机线圈、磁悬浮列车
  - 超导体不能用于电热器（因为不产生热量）
- 易错点：导体和绝缘体可以相互转化；超导体不能用于电热器

【标准考点】
1. 导体和绝缘体的区分（高频）
2. 导体容易导电的原因（中频）
3. 导体和绝缘体的转化（中频）
4. 半导体的特性和应用（低频）
5. 超导体的特性和应用（低频）

【常见题型】
1. **选择题：导体绝缘体**
   例：下列各组物质中，都属于导体的是（ ）
   A. 铜、橡胶 B. 人体、大地 C. 塑料、玻璃 D. 陶瓷、盐水
   答案：B

2. **选择题：导体导电原因**
   例：金属导体容易导电，是因为金属内部有（ ）
   A. 大量自由电子 B. 大量质子 C. 大量中子 D. 大量原子核
   答案：A

3. **选择题：导体绝缘体转化**
   例：下列说法正确的是（ ）
   A. 导体和绝缘体之间没有绝对的界限 B. 绝缘体永远不能导电 C. 导体和绝缘体不能转化 D. 以上说法都不对
   答案：A

4. **填空题：半导体**
   例：半导体二极管具有 ___ 特性，只允许电流从一个方向通过。
   答案：单向导电

5. **选择题：超导体应用**
   例：超导体不能用于制作（ ）
   A. 输电导线 B. 电动机线圈 C. 电热器的发热体 D. 电磁铁线圈
   答案：C（超导体电阻为零，不产生热量）

【解题思路】
1. **导体绝缘体判断**：看是否容易导电，记住常见例子
2. **导电原因**：导体有大量自由电荷（金属是自由电子，溶液是离子）
3. **转化条件**：温度、湿度等条件改变时可能转化
4. **半导体特性**：单向导电性，用于电子元件
5. **超导体特点**：电阻为零，不能用于需要发热的电器

#### 11-4 电流及其测量

【知识点】
- 电流的形成：电荷的定向移动形成电流
- 电流的方向：规定正电荷定向移动的方向为电流方向
- 在电源外部，电流从电源正极流向负极
- 在电源内部，电流从电源负极流向正极
- 金属导体中电流的方向与自由电子定向移动的方向相反
- 电流的符号：I
- 电流的单位：安培（A），常用单位还有毫安（mA）、微安（μA）
  - $1\text{A}=1000\text{mA}$，$1\text{mA}=1000\text{μA}$
- 常见电流值：
  - 计算器中的电流：约100μA
  - 手机充电电流：约1A
  - 家用冰箱的电流：约1A
  - 雷电电流：可达2×10⁵A
- 电流表的使用方法：
  - 电流表必须串联在电路中
  - 电流必须从正接线柱流入，从负接线柱流出
  - 被测电流不能超过电流表的量程
  - 不允许将电流表直接连到电源两极（会造成短路）
- 电流表的读数：
  - 先看量程（0-0.6A或0-3A）
  - 再看分度值（0.02A或0.1A）
  - 最后读出示数
- 串联电路的电流规律：串联电路中各处电流相等，$I=I_1=I_2=\cdots=I_n$
- 并联电路的电流规律：并联电路中干路电流等于各支路电流之和，$I=I_1+I_2+\cdots+I_n$
- 易错点：电流表必须串联，不能并联；正负接线柱不能接反

【标准考点】
1. 电流的形成和方向（高频）
2. 电流单位的换算（中频）
3. 电流表的使用方法（高频）
4. 电流表的读数（高频）
5. 串并联电路的电流规律（高频）

【常见题型】
1. **选择题：电流方向**
   例：关于电流的方向，下列说法正确的是（ ）
   A. 正电荷移动的方向就是电流方向 B. 负电荷移动的方向就是电流方向 C. 规定正电荷定向移动的方向为电流方向 D. 电流方向总是从电源负极到正极
   答案：C

2. **填空题：单位换算**
   例：0.5A= ___ mA= ___ μA
   答案：500；5×10⁵

3. **选择题：电流表使用**
   例：使用电流表时，下列做法错误的是（ ）
   A. 电流表串联在电路中 B. 电流从正接线柱流入 C. 电流表可以直接连到电源两极 D. 被测电流不能超过量程
   答案：C

4. **读图题：电流表读数**
   例：如图所示，电流表使用的量程是0-0.6A，指针指在第15个小格，则电流为 ___ A。
   答案：0.30A（分度值0.02A，15×0.02=0.30）

5. **计算题：串并联电路电流**
   例：如图所示，在串联电路中，电流表A₁的示数为0.3A，则电流表A₂的示数为 ___ A。
   答案：0.3A（串联电路各处电流相等）

6. **计算题：并联电路电流**
   例：如图所示，在并联电路中，电流表A₁的示数为0.2A，电流表A₂的示数为0.3A，则干路电流表A的示数为 ___ A。
   答案：0.5A（并联电路干路电流等于各支路电流之和）

【解题思路】
1. **电流方向判断**：正电荷定向移动方向，电源外部从正极到负极
2. **单位换算**：A→mA→μA，每级进率1000
3. **电流表使用**：串联、正进负出、不超量程、不能直接接电源
4. **电流表读数**：先看量程，再看分度值，最后读数
5. **串并联电流规律**：串联相等，并联干路等于支路之和

#### 11-5 电压及其测量

【知识点】
- 电压的作用：电压是形成电流的原因，电源是提供电压的装置
- 电压的符号：U
- 电压的单位：伏特（V），常用单位还有千伏（kV）、毫伏（mV）
  - $1\text{kV}=1000\text{V}$，$1\text{V}=1000\text{mV}$
- 常见电压值：
  - 一节干电池：1.5V
  - 一节蓄电池：2V
  - 家庭电路电压：220V
  - 对人体安全的电压：不高于36V
- 电压表的使用方法：
  - 电压表必须并联在电路中
  - 电流必须从正接线柱流入，从负接线柱流出
  - 被测电压不能超过电压表的量程
  - 电压表可以直接连到电源两极（测量电源电压）
- 电压表的读数：
  - 先看量程（0-3V或0-15V）
  - 再看分度值（0.1V或0.5V）
  - 最后读出示数
- 串联电路的电压规律：串联电路两端的总电压等于各部分电路两端的电压之和，$U=U_1+U_2+\cdots+U_n$
- 并联电路的电压规律：并联电路中各支路两端的电压相等，$U=U_1=U_2=\cdots=U_n$
- 易错点：电压表必须并联，不能串联；正负接线柱不能接反

【标准考点】
1. 电压的作用（高频）
2. 电压单位的换算（中频）
3. 常见电压值的记忆（中频）
4. 电压表的使用方法（高频）

6. 串并联电路的电压规律（高频）

【常见题型】

   A. 电路中有电流就一定有电压 B. 电路中有电压就一定有电流 C. 电压是形成电流的原因，电路中有电压就一定有电流 D. 以上说法都不对
   答案：A

   例：220V= ___ kV= ___ mV
   答案：0.22；2.2×10⁵

   答案：1.5；220；36

4. **选择题：电压表使用**
   例：使用电压表时，下列做法正确的是（ ）
   A. 电压表串联在电路中 B. 电压表可以直接连到电源两极 C. 电流从负接线柱流入 D. 被测电压可以超过量程
   答案：B

#### 11-6 电阻

【知识点】
- 电阻的概念：导体对电流的阻碍作用叫做电阻
- 电阻的符号：R
- 电阻的单位：欧姆（Ω），常用单位还有千欧（kΩ）、兆欧（MΩ）
  - $1\text{MΩ}=1000\text{kΩ}$，$1\text{kΩ}=1000\text{Ω}$
- 电阻是导体本身的一种性质，不同导体的电阻一般不同
- 影响电阻大小的因素：
  - 材料：长度和横截面积相同时，不同材料的电阻不同
  - 长度：材料和横截面积相同时，导体越长，电阻越大
  - 横截面积：材料和长度相同时，导体横截面积越大，电阻越小
  - 温度：大多数导体的电阻随温度的升高而增大（如金属）
- 电阻与电压、电流无关：电阻是导体本身的性质，不随电压、电流的变化而变化
- 易错点：电阻是导体本身的性质，与电压电流无关；温度对电阻的影响

【标准考点】
1. 电阻的概念（高频）
2. 电阻单位的换算（中频）
3. 影响电阻大小的因素（高频）
4. 电阻是导体本身性质的理解（高频）

【常见题型】
1. **选择题：电阻概念**
   例：关于电阻，下列说法正确的是（ ）
   A. 导体中有电流时才有电阻 B. 导体两端有电压时才有电阻 C. 电阻是导体本身的一种性质，与电流电压无关 D. 以上说法都不对
   答案：C

2. **填空题：单位换算**
   例：5kΩ= ___ Ω，0.2MΩ= ___ kΩ
   答案：5000；200

3. **选择题：影响电阻因素**
   例：关于影响导体电阻大小的因素，下列说法正确的是（ ）
   A. 导体越长，电阻越大 B. 导体横截面积越大，电阻越大 C. 在材料、长度相同时，横截面积越大，电阻越小 D. 电阻与电压成正比
   答案：C

4. **实验题：探究影响电阻的因素**
   例：在"探究影响导体电阻大小的因素"实验中，要探究电阻与长度的关系，应选择 ___ 相同、 ___ 不同的两根导体进行实验。
   答案：材料、横截面积；长度

5. **选择题：电阻性质**
   例：一段导体两端的电压从3V增加到6V时，这段导体的电阻将（ ）
   A. 变大 B. 变小 C. 不变 D. 无法判断
   答案：C（电阻是导体本身的性质，与电压无关）

6. **简答题：温度对电阻的影响**
   例：为什么灯泡刚点亮时容易烧坏？
   答案：灯泡刚点亮时，灯丝温度较低，电阻较小，根据欧姆定律$I=U/R$，电流较大，容易烧坏灯丝。

【解题思路】
1. **电阻理解**：是导体本身的性质，与电压电流无关
2. **单位换算**：MΩ→kΩ→Ω，每级进率1000
3. **影响因素**：材料、长度、横截面积、温度，用控制变量法探究
4. **电阻与长度横截面积关系**：越长越大，越粗越小
5. **温度影响**：大多数金属电阻随温度升高而增大

#### 11-7 变阻器

【知识点】
- 变阻器的作用：改变接入电路中电阻的大小，从而改变电路中的电流和部分电路两端的电压
- 滑动变阻器的构造：瓷筒、线圈、滑片、接线柱、支架
- 滑动变阻器的原理：通过改变接入电路中电阻线的长度来改变电阻
- 滑动变阻器的使用方法：
  - 串联在电路中
  - 接线柱要"一上一下"连接
  - 闭合开关前，滑片应移到阻值最大处
- 滑动变阻器的作用：

#### 12-2 欧姆定律

【知识点】
- 欧姆定律的内容：导体中的电流，跟导体两端的电压成正比，跟导体的电阻成反比
- 欧姆定律的公式：$I = \dfrac{U}{R}$
  - $I$ 表示电流，单位是安培（A）
  - $U$ 表示电压，单位是伏特（V）
  - $R$ 表示电阻，单位是欧姆（Ω）
- 公式的变形：
  - $U = IR$（求电压）
  - $R = \dfrac{U}{I}$（求电阻）
- 对公式 $R = \dfrac{U}{I}$ 的理解：
  - 电阻是导体本身的一种性质，与电压、电流无关
  - 不能认为"电阻与电压成正比，与电流成反比"
  - 该公式只是提供了一种测量电阻的方法
- 欧姆定律的适用条件：
  - 适用于纯电阻电路（电能全部转化为内能）
  - 适用于同一导体或同一段电路（I、U、R要对应同一对象）
  - 适用于稳恒电流（电流不随时间变化）
- 应用欧姆定律解题的步骤：
  - 明确已知量和未知量
  - 画出电路图，标出已知量
  - 选择合适的公式进行计算
  - 注意单位统一（I用A，U用V，R用Ω）

#### 12-4 欧姆定律在串、并联电路中的应用

【知识点】
- 串联电路的等效电阻：
  - 串联电路的总电阻等于各串联电阻之和：$R = R_1 + R_2 + \cdots + R_n$
  - 串联电路的总电阻比任何一个分电阻都大
  - 串联电阻越多，总电阻越大（相当于增加了导体的长度）
  - 推导：$U = U_1 + U_2$，$IR = I_1R_1 + I_2R_2$，因为 $I = I_1 = I_2$，所以 $R = R_1 + R_2$
- 并联电路的等效电阻：
  - 并联电路的总电阻的倒数等于各并联电阻的倒数之和：$\dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2} + \cdots + \dfrac{1}{R_n}$
  - 并联电路的总电阻比任何一个分电阻都小
  - 并联电阻越多，总电阻越小（相当于增加了导体的横截面积）
  - 两个电阻并联的特殊公式：$R = \dfrac{R_1R_2}{R_1 + R_2}$
  - 推导：$I = I_1 + I_2$，$\dfrac{U}{R} = \dfrac{U_1}{R_1} + \dfrac{U_2}{R_2}$，因为 $U = U_1 = U_2$，所以 $\dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2}$
- 串联电路的分压规律：
  - 串联电路中各电阻两端的电压与电阻成正比：$\dfrac{U_1}{U_2} = \dfrac{R_1}{R_2}$
  - 电阻越大，分得的电压越大
- 并联电路的分流规律：
  - 并联电路中各支路的电流与电阻成反比：$\dfrac{I_1}{I_2} = \dfrac{R_2}{R_1}$
  - 电阻越大，分得的电流越小
- 应用欧姆定律解串、并联电路问题的步骤：
  - 画出电路图，明确已知量和未知量
  - 分析电路结构（串联还是并联）
  - 根据串、并联电路的特点列方程
  - 结合欧姆定律求解

1. **串联电路解题思路**：
   - 总电阻 $R = R_1 + R_2$
   - 电流处处相等 $I = I_1 = I_2$
   - 电压分配 $U = U_1 + U_2$，$\dfrac{U_1}{U_2} = \dfrac{R_1}{R_2}$
2. **并联电路解题思路**：
   - 总电阻 $\dfrac{1}{R} = \dfrac{1}{R_1} + \dfrac{1}{R_2}$
   - 各支路电压相等 $U = U_1 = U_2$
   - 电流分配 $I = I_1 + I_2$，$\dfrac{I_1}{I_2} = \dfrac{R_2}{R_1}$
3. **综合题解题技巧**：
   - 先分析电路结构（串、并联）
   - 画出等效电路图
   - 根据串、并联特点列方程
   - 结合欧姆定律求解
4. **易错警示**：
   - 并联总电阻比任何一个分电阻都小
   - 串联分压与电阻成正比，并联分流与电阻成反比

#### 13-1 电能 电功

【知识点】
- 电能的概念：电能是指电流通过导体时所做的功，是能量的一种形式
- 电能的单位：
  - 国际单位：焦耳（J）
  - 常用单位：千瓦时（kW·h），俗称"度"
  - 换算关系：$1\text{kW·h} = 3.6 \times 10^6\text{J}$
- 电能的测量：电能表（电度表）
  - 电能表的作用：测量用电器在一段时间内消耗的电能
  - 电能表的参数：
    - "220V"：表示这个电能表应该在220V的电路中使用
    - "10（20）A"：表示这个电能表的标定电流为10A，额定最大电流为20A
    - "50Hz"：表示这个电能表在50Hz的交流电路中使用
    - "600revs/(kW·h)"或"600imp/(kW·h)"：表示接在这个电能表上的用电器，每消耗1kW·h的电能，电能表的转盘转过600转（或指示灯闪烁600次）
  - 电能表的读数：最后一位是小数位，单位是kW·h
  - 用电能表测量电功率：$P = \dfrac{W}{t} = \dfrac{n/N}{t}$（n为转数，N为每千瓦时的转数，t为时间）
- 电功的概念：电流所做的功叫做电功，用W表示
- 电功的实质：电流做功的过程就是电能转化为其他形式能的过程
- 电功的公式：
  - 基本公式：$W = UIt$（适用于所有电路）
  - 推导公式：$W = I^2Rt = \dfrac{U^2}{R}t$（仅适用于纯电阻电路）
  - 其中：W表示电功（J），U表示电压（V），I表示电流（A），t表示时间（s）
- 电功与电能的关系：电流做了多少功，就有多少电能转化为其他形式的能，即 $W = E_{\text{电}}$

#### 13-2 电功率

【知识点】
- 电功率的概念：电流在单位时间内所做的功叫做电功率，用P表示
- 电功率的物理意义：表示电流做功的快慢
- 电功率的单位：
  - 国际单位：瓦特（W），简称瓦
  - 常用单位：千瓦（kW）
  - 换算关系：$1\text{kW} = 10^3\text{W}$
- 电功率的公式：
  - 定义式：$P = \dfrac{W}{t}$（适用于所有情况）
  - 计算式：$P = UI$（适用于所有电路）
  - 推导式：$P = I^2R = \dfrac{U^2}{R}$（仅适用于纯电阻电路）
  - 其中：P表示电功率（W），U表示电压（V），I表示电流（A），R表示电阻（Ω）
- 额定电压：用电器正常工作时的电压，用$U_{\text{额}}$表示
- 额定功率：用电器在额定电压下工作时的功率，用$P_{\text{额}}$表示
- 实际电压：用电器实际工作时的电压，用$U_{\text{实}}$表示
- 实际功率：用电器在实际电压下工作时的功率，用$P_{\text{实}}$表示
- 额定功率与实际功率的关系：
  - 当$U_{\text{实}} = U_{\text{额}}$时，$P_{\text{实}} = P_{\text{额}}$，用电器正常工作
  - 当$U_{\text{实}} > U_{\text{额}}$时，$P_{\text{实}} > P_{\text{额}}$，用电器可能烧坏
  - 当$U_{\text{实}} < U_{\text{额}}$时，$P_{\text{实}} < P_{\text{额}}$，用电器不能正常工作
- 用电器的电阻不变时：$\dfrac{P_{\text{实}}}{P_{\text{额}}} = \left(\dfrac{U_{\text{实}}}{U_{\text{额}}}\right)^2$
- 灯泡的亮度取决于实际功率，实际功率越大，灯泡越亮
- 铭牌的含义：如"220V 100W"表示额定电压为220V，额定功率为100W

5. **易错警示**：电功率大不代表做功多，还要考虑时间

#### 13-3 测量小灯泡的电功率

【知识点】
- 实验原理：$P = UI$（用电压表测出小灯泡两端的电压U，用电流表测出通过小灯泡的电流I，根据公式$P = UI$计算出电功率）
- 实验方法：伏安法（与伏安法测电阻类似，但目的不同）
- 实验器材：电源、开关、导线、小灯泡、电压表、电流表、滑动变阻器
- 实验电路图：
  - 小灯泡与电流表串联（测通过小灯泡的电流）
  - 电压表并联在小灯泡两端（测小灯泡两端的电压）
  - 滑动变阻器与小灯泡串联（保护电路、改变小灯泡两端的电压）
- 实验步骤：
  - $①$ 按照电路图连接实物电路，连接时开关要断开
  - $②$ 滑动变阻器滑片移到阻值最大处（保护电路）
  - $③$ 闭合开关，调节滑动变阻器，使小灯泡两端电压等于额定电压，读出此时的电流表示数，计算额定功率
  - $④$ 调节滑动变阻器，使小灯泡两端电压略高于额定电压（约1.2倍），读出电流表示数，计算实际功率
  - $⑤$ 调节滑动变阻器，使小灯泡两端电压略低于额定电压，读出电流表示数，计算实际功率
- 滑动变阻器的作用：
  - 保护电路（闭合开关前滑片在阻值最大处）
  - 改变小灯泡两端的电压和通过的电流，实现多次测量
- 实验注意事项：
  - 电流表、电压表的量程要选择合适（根据小灯泡的额定电压和额定功率估算）
  - 小灯泡两端电压不要超过额定电压太多，以免烧坏小灯泡
  - 多次测量的目的：不是求平均值减小误差，而是测量不同电压下的电功率，找出规律
- 实验结论：
  - 当$U_{\text{实}} = U_{\text{额}}$时，$P_{\text{实}} = P_{\text{额}}$，小灯泡正常发光
  - 当$U_{\text{实}} > U_{\text{额}}$时，$P_{\text{实}} > P_{\text{额}}$，小灯泡较亮（可能烧坏）
  - 当$U_{\text{实}} < U_{\text{额}}$时，$P_{\text{实}} < P_{\text{额}}$，小灯泡较暗
- 与伏安法测电阻的区别：
  - 测电阻：多次测量求平均值减小误差
  - 测电功率：多次测量找规律（不同电压下的功率不同）

#### 13-4 焦耳定律

【知识点】
- 电流的热效应：电流通过导体时，电能转化为内能，这种现象叫做电流的热效应
- 焦耳定律的内容：电流通过导体产生的热量跟电流的二次方成正比，跟导体的电阻成正比，跟通电时间成正比
- 焦耳定律的公式：$Q = I^2Rt$
  - $Q$ 表示热量，单位是焦耳（J）
  - $I$ 表示电流，单位是安培（A）
  - $R$ 表示电阻，单位是欧姆（Ω）
  - $t$ 表示通电时间，单位是秒（s）
- 焦耳定律的推导：
  - 对于纯电阻电路（电能全部转化为内能）：$Q = W = UIt = I^2Rt = \dfrac{U^2}{R}t$
  - 对于非纯电阻电路（如电动机，电能只有一部分转化为内能）：$Q < W$，只能用 $Q = I^2Rt$ 计算热量
- 电功与电热的关系：
  - 纯电阻电路：$W = Q$，即 $UIt = I^2Rt$，$U = IR$（欧姆定律成立）
  - 非纯电阻电路：$W > Q$，即 $UIt > I^2Rt$，$U > IR$（欧姆定律不成立）
    - 例：电动机工作时，$W_{\text{电}} = W_{\text{机械}} + Q$，$UIt = W_{\text{机械}} + I^2Rt$
- 电热的利用：
  - 电热器：利用电流的热效应工作的用电器（如电炉、电饭锅、电热水器、电熨斗等）
  - 电热器的发热体：电阻大、熔点高的电阻丝（如镍铬合金丝）
  - 电热器的优点：清洁卫生、无污染、热效率高、方便控制和调节温度
- 电热的防止：
  - 电视机、电脑等用电器工作时会产生电热，需要散热
  - 防止电热危害的方法：安装散热窗、散热风扇、散热片等
- 焦耳定律的实验探究：
  - 实验方法：控制变量法、转换法（通过温度计示数变化或液柱高度差来反映产生热量的多少）
  - 探究电热与电流的关系：控制电阻和通电时间不变，改变电流
  - 探究电热与电阻的关系：控制电流和通电时间不变，改变电阻（串联不同阻值的电阻）
  - 探究电热与通电时间的关系：控制电流和电阻不变，改变通电时间

1. 焦耳定律的内容和公式（高频）
2. 焦耳定律的简单计算（高频）
3. 纯电阻电路与非纯电阻电路的区别（高频）
4. 探究焦耳定律的实验（高频）
5. 电热的利用和防止（中频）
6. 电热器发热体的特点（中频）
7. 电功与电热的综合计算（高频）

【常见题型】
1. **选择题：电流的热效应**
   例：下列用电器中，利用电流的热效应工作的是（ ）
   A. 电风扇 B. 电视机 C. 电饭锅 D. 电脑
   答案：C

2. **填空题：焦耳定律的计算**
   例：一个电阻为$100\Omega$的导体，通过它的电流为$2\text{A}$，通电$5\text{min}$，产生的热量是 ___ J。
   答案：$Q = I^2Rt = (2\text{A})^2 \times 100\Omega \times 300\text{s} = 1.2 \times 10^5\text{J}$

3. **计算题：电功与电热的综合计算**
   例：一台电动机，线圈电阻为$2\Omega$，接在$220\text{V}$的电路中正常工作，通过线圈的电流为$5\text{A}$。求：
   （1）电动机正常工作时的总功率；
   （2）电动机线圈在$1\text{min}$内产生的热量；
   （3）电动机正常工作时的效率。
   答案：
   （1）$P_{\text{总}} = UI = 220\text{V} \times 5\text{A} = 1100\text{W}$
   （2）$Q = I^2Rt = (5\text{A})^2 \times 2\Omega \times 60\text{s} = 3000\text{J}$
   （3）$P_{\text{热}} = I^2R = (5\text{A})^2 \times 2\Omega = 50\text{W}$
   $P_{\text{机械}} = P_{\text{总}} - P_{\text{热}} = 1100\text{W} - 50\text{W} = 1050\text{W}$
   $\eta = \dfrac{P_{\text{机械}}}{P_{\text{总}}} = \dfrac{1050\text{W}}{1100\text{W}} \approx 95.5\%$

4. **实验题：探究焦耳定律**
   例：在"探究电流通过导体产生的热量与哪些因素有关"的实验中：
   （1）实验中如何比较电流通过导体产生的热量？
   （2）探究电热与电阻的关系时，应如何设计实验？
   答案：（1）通过温度计示数的变化（或U形管中液柱的高度差）来反映产生热量的多少（转换法）；（2）将两个阻值不同的电阻串联在电路中（控制电流和通电时间相同），比较它们产生的热量

5. **简答题：电热的利用和防止**
   例：电炉的发热体用电阻大、熔点高的材料制成，为什么？
   答案：根据 $Q = I^2Rt$，在电流和通电时间相同时，电阻越大产生的热量越多，所以发热体要用电阻大的材料；同时发热体工作时温度很高，所以要用熔点高的材料，防止熔化。

【解题思路】
1. **焦耳定律计算**：
   - 核心公式：$Q = I^2Rt$（适用于所有电路）
   - 纯电阻电路可推导：$Q = W = UIt = \dfrac{U^2}{R}t$
   - 非纯电阻电路只能用 $Q = I^2Rt$
2. **纯电阻与非纯电阻的判断**：
   - 纯电阻：电能全部转化为内能（如电炉、电饭锅）
   - 非纯电阻：电能部分转化为内能（如电动机、充电器）
3. **电动机的能量关系**：
   - $W_{\text{电}} = W_{\text{机械}} + Q$
   - $UIt = W_{\text{机械}} + I^2Rt$
   - 效率 $\eta = \dfrac{W_{\text{机械}}}{W_{\text{电}}} = \dfrac{UIt - I^2Rt}{UIt}$
4. **探究实验要点**：
   - 控制变量法：控制其他因素不变，只改变一个因素
   - 转换法：通过温度变化或液柱高度差反映热量
   - 串联控制电流相同（探究Q与R的关系）
5. **易错警示**：
   - 非纯电阻电路不能用 $Q = \dfrac{U^2}{R}t$ 计算热量
   - 电热器发热体要电阻大（产生热量多），不是电阻小

#### 14-1 家庭电路

【知识点】
- 家庭电路的组成：
  - 进户线：火线和零线（火线与零线之间的电压是220V）
  - 电能表：测量用户消耗的电能
  - 总开关（闸刀开关）：控制整个电路的通断，便于检修
  - 保险装置（保险丝或空气开关）：当电流过大时自动切断电路，起保护作用
  - 用电器和插座：各用电器之间并联，插座与用电器并联
- 家庭电路的连接规则：
  - 各用电器之间并联
  - 开关与所控制的用电器串联
  - 开关要接在火线和用电器之间
  - 螺丝口灯泡的螺旋接零线，灯座顶端的金属片接火线
- 火线和零线：
  - 火线（端线）：用试电笔接触时，氖管发光
  - 零线：在户外已经接地，用试电笔接触时，氖管不发光
  - 火线和零线之间的电压是220V
- 试电笔的使用：
  - 作用：辨别火线和零线
  - 使用方法：手接触笔尾金属体，笔尖接触被测导线
  - 现象：接触火线时氖管发光，接触零线时氖管不发光
  - 注意：手不能接触笔尖金属体
- 三孔插座和三线插头：
  - 三孔插座的接线：左零右火上接地（左N右L上E）
  - 三线插头：与用电器外壳相连的插脚接在接地线上
  - 作用：当用电器外壳带电时，电流通过接地线流入大地，避免触电事故
- 漏电保护器：
  - 作用：当发生漏电（电流经人体或其他路径流入大地）时，迅速切断电路
  - 工作原理：检测火线和零线中的电流是否相等，不相等时说明有漏电，立即切断电路
  - 与保险丝的区别：保险丝在电流过大时熔断，漏电保护器在漏电时切断电路

#### 14-2 家庭电路中电流过大的原因

【知识点】
- 家庭电路中电流过大的两个原因：
  - 短路：火线和零线直接连通（不经过用电器）
    - 短路时电路中的电阻很小，根据 $I = \dfrac{U}{R}$，电流会很大
    - 短路的原因：电线绝缘皮破损、用电器内部绝缘损坏、改装电路时误操作等
    - 短路的危害：电流过大，导线发热严重，可能引起火灾
  - 过载（用电器总功率过大）：同时使用的用电器总功率超过电路允许的最大功率
    - 根据 $P = UI$，家庭电路电压 $U = 220\text{V}$ 不变，总功率 $P$ 越大，干路电流 $I$ 越大
    - 过载的原因：同时使用多个大功率用电器（如空调、电热水器、电磁炉等）
    - 过载的危害：电流过大，导线发热，可能引起火灾
- 保险丝的作用：
  - 保险丝的材料：电阻率大、熔点低的铅锑合金
  - 保险丝的原理：当电流过大时，保险丝由于温度升高而熔断，自动切断电路，起保护作用
  - 保险丝的选择：保险丝的额定电流应等于或稍大于电路正常工作时的最大电流
  - 保险丝的安装：串联在家庭电路的干路中（火线上）
  - 注意事项：
    - 不能用铜丝、铁丝等代替保险丝（它们的熔点高，电流过大时不会熔断，起不到保护作用）
    - 更换保险丝时要先查明原因，排除故障后再更换
- 空气开关（断路器）：
  - 作用：当电路中电流过大时，自动切断电路（俗称"跳闸"）
  - 优点：切断故障电路后可以重新闭合，不需要更换
  - 空气开关兼有保险丝和总开关的作用
- 家庭电路的安全措施：
  - 保险装置（保险丝或空气开关）
  - 漏电保护器
  - 接地保护（三孔插座）

1. 家庭电路中电流过大的原因（高频）
2. 短路的危害和判断（高频）
3. 过载的计算和判断（高频）
4. 保险丝的材料和特点（中频）
5. 保险丝的选择原则（中频）
6. 不能用铜丝、铁丝代替保险丝的原因（高频）
7. 空气开关的作用（中频）

【常见题型】
1. **选择题：电流过大的原因**
   例：家庭电路中电流过大的原因可能是（ ）
   A. 短路 B. 过载 C. 断路 D. 短路或过载
   答案：D

2. **计算题：过载判断**
   例：某家庭电路中装有"220V 10A"的空气开关，家中已有用电器：100W的电视机、300W的洗衣机、200W的电脑、800W的电饭锅。如果再接入一个1500W的空调，空气开关会"跳闸"吗？
   答案：总功率 $P = 100\text{W} + 300\text{W} + 200\text{W} + 800\text{W} + 1500\text{W} = 2900\text{W}$
   总电流 $I = \dfrac{P}{U} = \dfrac{2900\text{W}}{220\text{V}} \approx 13.2\text{A} > 10\text{A}$
   所以空气开关会"跳闸"

3. **简答题：保险丝的材料**
   例：为什么保险丝要用电阻率大、熔点低的铅锑合金制成？
   答案：根据 $Q = I^2Rt$，当电流过大时，电阻率大意味着电阻大，产生的热量多，温度升高快；熔点低意味着在较低温度下就能熔断，及时切断电路，起到保护作用。

4. **选择题：保险丝的选择**
   例：关于保险丝，下列说法正确的是（ ）
   A. 保险丝的额定电流越大越好 B. 保险丝的额定电流越小越好
   C. 保险丝的额定电流应等于或稍大于电路正常工作时的最大电流
   D. 可以用铜丝代替保险丝
   答案：C

5. **简答题：不能用铜丝代替保险丝**
   例：为什么不能用铜丝、铁丝代替保险丝？
   答案：铜丝、铁丝的熔点高，当电路中电流过大时，它们不会熔断，起不到保护电路的作用，容易造成火灾。

【解题思路】
1. **判断电流过大的原因**：
   - 短路：火线和零线直接连通，电阻极小，电流极大
   - 过载：用电器总功率过大，$I = \dfrac{P}{U}$，电流超过电路允许值
2. **过载计算**：
   - 先求总功率：$P_{\text{总}} = P_1 + P_2 + \cdots + P_n$
   - 再求总电流：$I = \dfrac{P_{\text{总}}}{U}$（家庭电路 $U = 220\text{V}$）
   - 比较：若 $I > I_{\text{允许}}$，则过载
3. **保险丝的选择**：
   - 额定电流 = 或稍大于电路正常工作时的最大电流
   - 不能选太大（起不到保护作用）
   - 不能选太小（正常工作时也会熔断）
4. **保险丝的特点**：
   - 材料：电阻率大、熔点低
   - 原理：$Q = I^2Rt$，电流过大时产生热量多，温度升高快，达到熔点时熔断
5. **易错警示**：
   - 不能用铜丝、铁丝代替保险丝
   - 更换保险丝前要先排除故障
   - 空气开关"跳闸"后，要先查明原因再重新闭合

#### 14-3 安全用电

【知识点】
- 触电的概念：一定强度的电流通过人体时，会造成人体受伤甚至死亡，这种现象叫做触电
- 触电的条件：
  - 人体成为电路的一部分（接触带电体并形成通路）
  - 通过人体的电流超过安全限度
- 人体的安全电压：不高于36V的电压（在干燥环境中）
- 触电的类型：
  - 单线触电：站在地上的人接触到火线，电流从火线经人体流入大地
  - 双线触电：人同时接触到火线和零线，电流从火线经人体流入零线
  - 高压电弧触电：靠近高压带电体时，空气被击穿形成电弧，电流通过人体
  - 跨步电压触电：高压线落在地上，地面上不同位置有电压差，人走过时两脚之间有电压，电流从一只脚流入，另一只脚流出
- 触电的危害：
  - 触电事故的严重程度取决于电流的大小、通电时间的长短、电流通过人体的路径
  - 通过人体的电流超过30mA时，就有生命危险
  - 电流通过心脏、大脑等重要器官时，危险性更大
- 安全用电的原则：
  - 不接触低压带电体（不靠近低压带电体）
  - 不靠近高压带电体
  - 更换灯泡、搬动电器前应断开电源开关
  - 不弄湿用电器，不损坏绝缘层
  - 保险装置、插座、导线、家用电器等达到使用寿命应及时更换
- 触电急救：
  - 发现有人触电时，不能直接用手去拉触电者（否则自己也会触电）
  - 应首先切断电源（断开开关或用干燥的木棒、竹竿等绝缘体将电线挑开）
  - 然后对触电者进行急救（人工呼吸等）
  - 情况严重时，应立即拨打急救电话
- 安全用电常识：
  - 不用湿手触摸开关、插座和用电器
  - 不在电线上晾衣服
  - 不损坏用电器的绝缘层
  - 有金属外壳的用电器要接地（使用三孔插座）
  - 户外不靠近高压带电体，不攀爬变压器

2. 人体的安全电压（高频）
3. 触电的类型（中频）
4. 安全用电的原则（高频）
5. 触电急救方法（中频）
6. 安全用电常识（高频）

【常见题型】
1. **选择题：安全电压**
   例：对人体安全的电压是（ ）
   A. 不高于36V B. 不高于220V C. 不高于110V D. 不高于12V
   答案：A

2. **选择题：触电类型**

   A. 单线触电 B. 双线触电 C. 高压电弧触电 D. 跨步电压触电
   答案：A

   - 核心：不接触低压带电体，不靠近高压带电体

   - 安全电压是不高于36V，不是等于36V

   - 高压带电体不能靠近，更不能接触

### 第15章 电与磁

#### 15-1 磁现象 磁场

【知识点】
- 磁现象：
  - 磁性：物体能够吸引铁、钴、镍等物质的性质叫做磁性
  - 磁体：具有磁性的物体叫做磁体
  - 磁极：磁体上磁性最强的部分叫做磁极
    - 南极（S极）：指南的那个磁极
    - 北极（N极）：指北的那个磁极
  - 磁极间的相互作用规律：同名磁极相互排斥，异名磁极相互吸引
  - 磁化：一些物体在磁体或电流的作用下会获得磁性，这种现象叫做磁化
    - 软磁材料：容易被磁化，也容易退磁（如铁）
    - 硬磁材料：容易被磁化，也不容易退磁（如钢）
- 磁场：
  - 磁场的概念：磁体周围存在一种看不见、摸不着的物质，能够使磁针偏转，这种物质叫做磁场
  - 磁场的基本性质：对放入其中的磁体产生磁力的作用
  - 磁场的方向：在磁场中某一点，小磁针静止时北极所指的方向就是该点的磁场方向
  - 磁体周围的磁场方向：从N极出发，回到S极（外部）；从S极到N极（内部）
- 磁感线：
  - 磁感线的概念：为了形象地描述磁场，用一些带箭头的曲线来表示磁场的分布情况，这些曲线叫做磁感线
  - 磁感线的特点：
    - 磁感线是假想的曲线，实际并不存在
    - 磁感线从磁体的N极出发，回到S极（外部）
    - 磁感线越密的地方，磁场越强；越疏的地方，磁场越弱
    - 磁感线不会相交
    - 磁感线是立体的曲线，不是平面的
  - 常见磁体的磁感线分布：
    - 条形磁体：两端密，中间疏
    - 蹄形磁体：两极之间较密
    - 同名磁极：相互排斥，磁感线不相连
    - 异名磁极：相互吸引，磁感线相连
- 地磁场：
  - 地球本身是一个巨大的磁体，周围存在磁场，叫做地磁场
  - 地磁场的N极在地理的南极附近，S极在地理的北极附近
  - 指南针（司南）就是利用地磁场来指示方向的
  - 磁偏角：地理的两极与地磁场的两极并不完全重合，它们之间的偏差叫做磁偏角

【标准考点】
1. 磁性和磁体的概念（高频）
2. 磁极间的相互作用规律（高频）
3. 磁场的概念和基本性质（高频）
4. 磁场方向的判断（高频）
5. 磁感线的特点和画法（高频）
6. 地磁场的特点（中频）
7. 磁化现象（中频）

【常见题型】
1. **选择题：磁极间的相互作用**
   例：两根完全相同的条形磁体，将它们的N极靠近，会发生的现象是（ ）
   A. 相互吸引 B. 相互排斥 C. 没有作用 D. 先吸引后排斥
   答案：B

2. **填空题：磁场方向**
   例：在磁场中某一点，小磁针静止时 ___ 所指的方向就是该点的磁场方向。磁体周围的磁感线都是从 ___ 极出发，回到 ___ 极。
   答案：北极（N极）；N；S

3. **选择题：磁感线的特点**
   例：关于磁感线，下列说法正确的是（ ）

   C. 磁感线越密的地方，磁场越强 D. 磁感线可以相交
   答案：C

4. **简答题：地磁场**
   例：指南针为什么能够指示方向？
   答案：地球本身是一个巨大的磁体，周围存在地磁场。地磁场的N极在地理的南极附近，S极在地理的北极附近。指南针是一个小磁体，在地磁场的作用下，它的N极指向地磁场的S极（地理的北极附近），S极指向地磁场的N极（地理的南极附近），从而指示方向。

5. **选择题：磁化**
   例：下列材料中，容易被磁化且也容易退磁的是（ ）
   A. 钢 B. 铁 C. 铜 D. 铝
   答案：B

【解题思路】
1. **磁极间相互作用**：同名磁极相互排斥，异名磁极相互吸引
2. **磁场方向的判断**：
   - 小磁针静止时N极所指的方向
   - 磁感线的切线方向
   - 磁体外部：从N极到S极
3. **磁感线的画法**：
   - 从N极出发，回到S极
   - 磁极附近密，中间疏
   - 不相交、不中断
   - 立体分布
4. **地磁场要点**：
   - 地磁N极在地理南极附近
   - 地磁S极在地理北极附近
   - 存在磁偏角
5. **易错警示**：
   - 磁感线是假想的，实际不存在
   - 磁场方向是小磁针N极受力方向，不是S极
   - 磁体内部磁场方向从S到N，外部从N到S

#### 15-2 电生磁

【知识点】
- 电流的磁效应（奥斯特实验）：
  - 奥斯特实验：1820年，丹麦物理学家奥斯特发现，通电导线周围存在磁场
  - 电流的磁效应：通电导体周围存在与电流方向有关的磁场，这种现象叫做电流的磁效应
  - 实验现象：
    - 导线通电时，小磁针发生偏转（说明通电导线周围存在磁场）
    - 改变电流方向，小磁针偏转方向改变（说明磁场方向与电流方向有关）
  - 实验结论：通电导体周围存在磁场；磁场方向与电流方向有关
  - 注意事项：实验时导线要沿南北方向放置（与小磁针平行），效果更明显
- 通电螺线管的磁场：
  - 通电螺线管外部的磁场与条形磁体的磁场相似
  - 通电螺线管两端的极性跟螺线管中电流的方向有关
  - 安培定则（右手螺旋定则）：
    - 用右手握住螺线管，让四指指向螺线管中电流的方向
    - 则大拇指所指的那端就是通电螺线管的N极
  - 通电螺线管磁场的强弱与以下因素有关：
    - 电流的大小：电流越大，磁场越强
    - 线圈的匝数：匝数越多，磁场越强
    - 是否插入铁芯：插入铁芯后磁场大大增强
- 电磁铁：
  - 构造：内部插入铁芯的通电螺线管
  - 工作原理：电流的磁效应
  - 特点：
    - 通电时有磁性，断电时无磁性
    - 电流越大，磁性越强
    - 线圈匝数越多，磁性越强
    - 磁极极性可以通过改变电流方向来改变

1. 奥斯特实验的结论（高频）
2. 电流的磁效应（高频）
3. 通电螺线管的磁场特点（高频）
4. 安培定则的应用（高频）
5. 影响通电螺线管磁场强弱的因素（中频）
6. 电磁铁的特点和应用（中频）

【常见题型】
1. **选择题：奥斯特实验**
   例：关于奥斯特实验，下列说法正确的是（ ）
   A. 说明通电导线周围存在磁场 B. 说明磁场可以产生电流
   C. 说明磁场对电流有力的作用 D. 说明电磁感应现象
   答案：A

   例：用右手握住螺线管，让四指指向螺线管中电流的方向，则大拇指所指的那端就是通电螺线管的 ___ 极。
   答案：N

   例：如图所示，通电螺线管的左端是（ ）
   （图中电流方向已知）
   A. N极 B. S极 C. 无法判断 D. 可能是N极也可能是S极
   答案：根据安培定则判断（具体看电流方向）

4. **简答题：电磁铁的特点**
   例：电磁铁与永磁体相比有哪些优点？
   答案：$①$电磁铁磁性的有无可以由通断电来控制；$②$电磁铁磁性的强弱可以由电流大小和线圈匝数来调节；$③$电磁铁的磁极极性可以由电流方向来改变。

5. **实验题：探究通电螺线管的磁场**
   例：在探究"通电螺线管外部磁场的方向"实验中：

   答案：（1）用小磁针判断，小磁针静止时N极所指的方向即为该点的磁场方向，从而判断螺线管的N、S极；（2）改变电流方向可以改变磁极极性

【解题思路】
1. **奥斯特实验要点**：
   - 结论：通电导体周围存在磁场（电→磁）
   - 磁场方向与电流方向有关
   - 这是第一个揭示电与磁有联系的实验

   - 右手握住螺线管
   - 四指指向电流方向
   - 大拇指指向N极
   - 注意：电流从螺线管的哪端流入，哪端流出
3. **通电螺线管磁场**：
   - 外部磁场类似条形磁体
   - 磁场强弱：电流大小、线圈匝数、有无铁芯
   - 极性：由电流方向决定
4. **电磁铁的优点**：
   - 磁性可控（通断控制有无）
   - 强弱可调（改变电流或匝数）
   - 极性可变（改变电流方向）
5. **易错警示**：
   - 安培定则中四指指向电流方向，不是磁场方向
   - 通电螺线管内部磁场方向从S到N
   - 改变电流大小只能改变磁场强弱，不能改变极性

#### 15-3 电磁铁 电磁继电器

【知识点】
- 电磁铁：
  - 构造：内部插入铁芯的通电螺线管
  - 工作原理：电流的磁效应（通电时铁芯被磁化，磁场大大增强）
  - 影响电磁铁磁性强弱的因素：
    - 电流的大小：电流越大，磁性越强
    - 线圈的匝数：匝数越多，磁性越强
    - 有无铁芯：插入铁芯后磁性大大增强
  - 电磁铁的优点：
    - 磁性的有无可以由通断电来控制
    - 磁性的强弱可以由电流大小和线圈匝数来调节
    - 磁极极性可以由电流方向来改变
  - 电磁铁的应用：电磁起重机、电磁选矿机、电铃、磁悬浮列车等
- 电磁继电器：
  - 构造：电磁铁、衔铁、弹簧、触点（动触点和静触点）
  - 实质：利用电磁铁来控制工作电路的一种开关
  - 工作原理：
    - 控制电路通电→电磁铁有磁性→吸引衔铁→动触点与静触点接触→工作电路接通
    - 控制电路断电→电磁铁无磁性→弹簧将衔铁拉回→动触点与静触点分离→工作电路断开
  - 电磁继电器的作用：
    - 用低电压、弱电流控制高电压、强电流
    - 实现远距离控制和自动控制
  - 电磁继电器的应用：电话、电铃、自动控制系统等

【标准考点】
1. 电磁铁的构造和工作原理（高频）
2. 影响电磁铁磁性强弱的因素（高频）
3. 电磁铁的优点（中频）

5. 电磁继电器的作用（中频）
6. 探究电磁铁磁性强弱的实验（高频）

   A. 改变电流的大小 B. 改变线圈的匝数
   C. 改变电流的方向 D. 插入或拔出铁芯
   答案：C（改变电流方向只能改变磁极极性，不能改变磁性强弱）

2. **实验题：探究电磁铁的磁性强弱**
   例：在"探究电磁铁的磁性强弱与哪些因素有关"的实验中：
   （1）如何判断电磁铁磁性的强弱？
   （2）探究磁性强弱与电流的关系时，应如何操作？

   答案：电磁铁；低；弱；高；强

   例：电磁继电器在电路中起什么作用？
   答案：电磁继电器可以用低电压、弱电流的控制电路来控制高电压、强电流的工作电路，实现远距离控制和自动控制，保障操作安全。

   例：下列设备中，没有利用电磁铁的是（ ）
   A. 电磁起重机 B. 电铃 C. 指南针 D. 电磁继电器
   答案：C（指南针利用的是地磁场，不是电磁铁）

【解题思路】
1. **电磁铁磁性强弱的判断**：
   - 转换法：通过吸引大头针的数目来判断
   - 影响因素：电流大小、线圈匝数、有无铁芯
2. **探究实验设计**：
   - 控制变量法：探究一个因素时，控制其他因素不变
   - 改变电流：用滑动变阻器调节
   - 改变匝数：换用不同匝数的线圈
3. **电磁继电器工作原理**：
   - 控制电路→电磁铁→衔铁→触点→工作电路
   - 低电压控制高电压（安全）
4. **电磁铁 vs 永磁体**：
   - 电磁铁：磁性可控，强弱可调，极性可变
   - 永磁体：磁性固定，不可调节
5. **易错警示**：
   - 改变电流方向只能改变极性，不能改变强弱
   - 电磁继电器中控制电路和工作电路是独立的

#### 15-4 电动机

【知识点】
- 磁场对通电导体的作用：
  - 实验现象：通电导体在磁场中会受到力的作用
  - 力的方向与以下因素有关：
    - 电流的方向：改变电流方向，力的方向改变
    - 磁场的方向：改变磁场方向，力的方向改变
    - 同时改变电流方向和磁场方向，力的方向不变
  - 力的大小与以下因素有关：
    - 电流的大小：电流越大，力越大
    - 磁场的强弱：磁场越强，力越大
  - 能量转化：电能转化为机械能

#### 15-5 磁生电

【知识点】
- 电磁感应现象（法拉第实验）：

  - 产生感应电流的条件：
    - 电路必须是闭合的
    - 导体必须是闭合电路的一部分

    - 导体运动的方向：改变导体运动方向，感应电流方向改变
    - 磁场的方向：改变磁场方向，感应电流方向改变
    - 同时改变导体运动方向和磁场方向，感应电流方向不变
  - 感应电流的大小与以下因素有关：
    - 导体切割磁感线的速度：速度越快，电流越大
    - 磁场的强弱：磁场越强，电流越大
    - 切割磁感线的导体长度：长度越长，电流越大
  - 能量转化：机械能转化为电能
- 发电机的工作原理：
  - 原理：电磁感应现象
  - 构造：磁铁（定子）、线圈（转子）、滑环、电刷
  - 工作过程：
    - 线圈在磁场中转动，切割磁感线
    - 产生感应电流
    - 通过滑环和电刷将电流引出
  - 交流发电机产生的是交流电
    - 交流电：电流方向周期性变化的电流
    - 我国交流电的频率是50Hz，周期是0.02s
    - 每个周期电流方向改变2次
  - 发电机的能量转化：机械能转化为电能
- 发电机与电动机的区别：
  - 发电机：电磁感应原理，机械能→电能
  - 电动机：磁场对通电导体的作用，电能→机械能
- 发电机的应用：火力发电、水力发电、风力发电等

#### 16-1 探索微观世界的历程

  - 原子核是由质子和中子组成的

  - 卢瑟福的核式结构模型：原子中心有一个很小的原子核，电子绕核运动
  - 玻尔的原子模型：电子在特定的轨道上绕核运动

  - 分子直径的数量级：$10^{-10}\text{m}$
  - 原子核直径的数量级：$10^{-15}\text{m}$
  - 电子的质量很小，约为质子质量的$\dfrac{1}{1836}$

  - 质子和中子是由更小的粒子——夸克组成的
  - 夸克是目前已知的最小粒子

#### 16-3 能源：危机与希望

【知识点】
- 能源的概念：能够提供能量的物质资源叫做能源
- 能源的分类：
  - 按来源分类：
    - 一次能源：直接从自然界获得的能源（如煤、石油、天然气、太阳能、风能、水能、地热能、核能等）
    - 二次能源：无法从自然界直接获得，必须通过一次能源的消耗才能得到的能源（如电能、汽油、柴油、煤气等）
  - 按可否再生分类：
    - 可再生能源：可以在自然界里源源不断地得到的能源（如太阳能、风能、水能、地热能、生物质能等）
    - 不可再生能源：越用越少，不可能在短期内从自然界得到补充的能源（如煤、石油、天然气、核能等）
  - 按使用情况分类：
    - 常规能源：已经大规模生产和广泛利用的能源（如煤、石油、天然气、水能）
    - 新能源：近年来才开始利用或正在开发研究的能源（如太阳能、核能、地热能、海洋能、氢能等）
- 化石能源：
  - 化石能源包括：煤、石油、天然气
  - 化石能源是不可再生能源
  - 化石能源燃烧会产生二氧化碳，造成温室效应
  - 化石能源的储量有限，面临枯竭
- 核能：
  - 核能：原子核发生分裂或聚合时释放的能量
  - 裂变：质量较大的原子核分裂成两个或多个质量较小的原子核，释放出巨大的能量
    - 应用：核电站、原子弹
    - 核电站的原理：利用可控核裂变反应释放能量发电
    - 核能的优点：能量密度大、不产生温室气体
    - 核能的问题：核废料处理困难、存在核泄漏风险
  - 聚变：质量较小的原子核结合成质量较大的原子核，释放出更大的能量
    - 应用：氢弹、太阳内部的能量来源
    - 聚变的优势：原料丰富（氘、氚）、产物无污染、能量更大
    - 聚变的问题：目前还不能实现可控核聚变
- 太阳能：
  - 太阳能的来源：太阳内部发生核聚变释放的能量
  - 太阳能的利用方式：
    - 光热转换：如太阳能热水器
    - 光电转换：如太阳能电池
  - 太阳能的优点：清洁、无污染、取之不尽用之不竭
  - 太阳能的缺点：受天气影响大、能量密度低、成本高
- 其他新能源：
  - 风能：利用风力发电，清洁无污染，但受风力影响不稳定
  - 水能：利用水力发电，清洁可再生，但受地理条件限制
  - 地热能：利用地球内部的热能，清洁可再生，但受地理条件限制
  - 海洋能：利用潮汐、波浪等发电，能量丰富但技术难度大
  - 生物质能：利用植物、动物粪便等生物质资源，可再生
  - 氢能：燃烧产物是水，无污染，热值高，但制取和储存困难
- 能源与可持续发展：
  - 能源消耗带来的问题：温室效应、酸雨、臭氧层破坏、雾霾等
  - 可持续发展的含义：既满足当代人的需求，又不损害后代人满足其需求的能力
  - 解决能源问题的措施：
    - 提高能源利用率
    - 开发新能源
    - 节约能源
    - 保护环境

【常见题型】
1. **选择题：能源分类**
   例：下列能源中，属于可再生能源的是（ ）
   A. 煤 B. 石油 C. 太阳能 D. 天然气
   答案：C

2. **填空题：能源分类**
   例：电能属于 ___ 次能源，太阳能属于 ___ 次能源。
   答案：二；一

3. **选择题：核能**
   例：关于核能，下列说法正确的是（ ）
   A. 核电站利用的是核聚变 B. 原子弹利用的是核裂变
   C. 太阳内部发生的是核裂变 D. 核能是可再生能源
   答案：B

4. **简答题：太阳能的优点**
   例：太阳能有哪些优点？
   答案：$①$清洁无污染；$②$取之不尽用之不竭；$③$分布广泛，获取方便；$④$安全，不会发生爆炸泄漏等事故。

5. **简答题：能源与可持续发展**
   例：为了解决能源危机，我们应该采取哪些措施？
   答案：$①$提高能源利用率；$②$开发新能源（如太阳能、风能、核能等）；$③$节约能源；$④$保护环境，减少污染。

6. **选择题：新能源**
   例：下列能源中，不属于新能源的是（ ）
   A. 太阳能 B. 核能 C. 煤 D. 地热能
   答案：C

【解题思路】
1. **能源分类的判断**：
   - 一次能源 vs 二次能源：是否直接从自然界获得
   - 可再生 vs 不可再生：能否在短期内从自然界得到补充
   - 常规能源 vs 新能源：是否已经大规模利用
2. **核能的区分**：
   - 裂变：重核分裂（核电站、原子弹）
   - 聚变：轻核结合（太阳、氢弹）
   - 目前核电站只能利用裂变，聚变还不能控制
3. **太阳能的利用**：
   - 光热转换：太阳能→内能（热水器）
   - 光电转换：太阳能→电能（电池）
4. **新能源的优缺点**：
   - 优点：清洁、可再生、无污染
   - 缺点：受自然条件限制、技术不成熟、成本高
5. **可持续发展**：
   - 节约能源
   - 提高利用率
   - 开发新能源
   - 保护环境
6. **易错警示**：
   - 电能是二次能源，不是一次能源
   - 核能是不可再生能源（核燃料有限）
   - 太阳能是可再生能源
   - 水能是可再生能源，但不是新能源（常规能源）
