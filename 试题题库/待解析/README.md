## 三、标准工作流

> 两个阶段必须分开：**先格式化 → 用户审核通过 → 再拆题解析**。解析阶段不得回头修改源试卷 MD。

### 阶段 A：识别提取 → 格式化（产出源试卷 MD）

1. **获取题干**
   - 菁优网分享链接：走 `菁优网试卷提取格式化` 技能——浏览器打开页面 → 判定答案/解析门禁 → DOM 结构化提取 → 转换器生成中间稿 → 人工按规则复核。
   - 组卷网链接：走 `组卷网试卷提取格式化` 技能——浏览器过 JS 挑战壳打开页面 → 判定答案/解析门禁 → DOM 结构化提取 → 转换器生成中间稿 → 人工按规则复核。
   - 出卷网链接：走 `出卷网试卷提取格式化` 技能——匿名直抓页面 → 解析内嵌 `paper_detail` JSON → 判定答案/解析门禁 → 转换器生成中间稿（公式 MathML 解码为 LaTeX）→ 人工按规则复核。
   - PDF / 图片：先 OCR 成 Markdown 中间稿。
2. **落盘**：源 MD 放 `待解析/` 根目录，文件名 `{年级}-{学科}-{试卷名}-{YYYYMMDD}.md`；frontmatter 含创建时间、来源、类型、`tags: [年级+学科]`。
3. **六项格式化**（Rules 第二章 / 技能摘要）：
   - 题号 `数字、` → `数字. `；
   - 公式 `$...$`：内侧无空格、外侧留空格；连续表达式整体包裹，禁止逐字母拆开；
   - 圈数 ①②③ 逐个 `$①$` 包裹、彼此空格；
   - 选择题选项每项独占一行、空行隔开；
   - 填空线 ` ___ ` 两侧各一空格；
   - 独立数字前后空格；独立字母/变量 `$` 包裹。
4. **机械校验**：题数=配图数、0 HTML 残留、0 裸圈数、0 非法填空线、无 callout、无本地图引用。
5. **交用户审核**，通过后才进入阶段 B。

### 阶段 B：拆题解析（审核通过后执行）

1. **建卷夹、移源文件**：在 `待解析/` 下建同名试卷文件夹；把源 PDF 和源 MD **一并移入**；根目录不得残留该卷源文件。源 MD 全程不得修改。
2. **逐题拆成独立 Q 文件**：
   - 文件名 `{ID}.md`；frontmatter：`id`（与文件名一致）、`source`（双链指向源卷对应题号锚点）、`knowledge`（纯文本知识点数组，锚点与体系文件逐字一致）、`tags`（年级+学科）。
   - 正文：原题干原样保留；解析写在 `> [!question]-` callout 内，四段：**【答案】【考点】【解析】【易错点】**。
3. **图片本地化**：扫描题干网络图片，下载到卷夹（与 Q 文件同目录，**禁止子文件夹**），命名 `{题目ID}-P{序号}.扩展名`，每题从 P01 重新编号；Q 文件内引用换本地路径；源 MD 图片保持网络链接不动。
4. **几何配图**（涉及辅助线的几何题，走 geo-figure 流程，见第五节）：`{题目ID}-FIG01.svg` 同目录，callout 内【解析】末尾、【易错点】前引用 `![解题配图|600]({题目ID}-FIG01.svg)`。
5. **终检**：按 Rules 4.7 拆题验证清单（20 项）+ 5.5 配图验证清单（11 项）逐项过。
6. **归档**：整卷移入上级对应学科文件夹。

## 四、命名规则

### 4.1 题目 ID

```
{科目}-{年级}-{日期}-{当日序号}-Q{题号}
MAT-7-2-20260730-001-Q01
```

| 字段 | 说明 |
|---|---|
| 科目 | MAT 数学 / CHI 语文 / ENG 英语 / PHY 物理 / CHE 化学；单独几何专题用 `GEO` 前缀 |
| 年级 | 7-1 七上 / 7-2 七下 / 8-1 八上 / 8-2 八下 / 9-1 九上 / 9-Q 九全 |
| 日期 | `YYYYMMDD`；文件名仅有年月时补 `01` |
| 当日序号 | 当天该科目第几份，3 位 |
| 题号 | Q01 起 2 位连续编号，与源卷 `1. 2. 3.` 一一对应 |

### 4.2 图片与配图

- 原图：`{题目ID}-P01.png`（每题 P 序号独立从 01 开始）
- 解题配图：`{题目ID}-FIG01.svg`（FIG 序号与 P 序号相互独立）
- 均与 Q 文件同目录，无子文件夹；PNG 预览只留临时目录，不进知识库。

### 4.3 tags 格式

统一 `年级+学科`：`七上数学`、`八上物理`、`九全物理` 等。

## 五、几何配图工作流要点（geo-figure）

1. **先写文字解析**，明确辅助线作法与辅助点字母；
2. **临时目录解坐标**：numpy 求精确坐标，不估点；先读原卷 P 图确定方位，构图不得翻转/旋转（保持手性）；
3. **画图**：主图黑色实线 `#000` 线宽 1.8；辅助线/辅助圆紫色虚线 `#9b59b6`；区域填充浅蓝 `#d7e6f8`；关键结论线段加粗着色；直角标记、角弧克制使用；
4. **数值自校验（强制）**：Report 逐条打印等长/垂直/共线/角度关系，全部 PASS 才导图；
5. **导出 SVG** 到卷夹，Q 文件内带宽度引用；
6. **瑕疵自检（强制，数值校验查不出，必须对照 PNG 目检）**：
   - 每个直角标记/角弧的两条边都落在已画线段上，无悬空边；
   - 垂足/交点在主线延长线上时，主线延长段必须补画；
   - 原卷已有线段被标记引用时按原样式补全；
   - 方位与原卷一致：各点上下左右、关键线水平/竖直姿态、钝锐角开口朝向；
   - 标签贴近端点（偏移 0.08~0.12）、不压线段、不互相遮挡。

## 六、硬性红线（历次返工沉淀）

- **源试卷 MD 不得修改**：无 callout、图片不换本地路径；所有解析只写在独立 Q 文件。
- **无子文件夹**：图片、SVG 与 Q 文件同目录。
- **无 HTML 残留**：`<div>/<img>/<table>/<center>/<sub>/<sup>/<br>` 全部转为 Markdown。
- **门禁不编造**：答案/解析/考点在公开预览不可见时，如实标注，不推测、不编造。
- **配图必须对照原图复核**：交付前逐张对照 P01 清单——各点在边上的位置与分段比例、所有连线（含内部三角形边、高、中线、辅助线）是否齐全、方位/手性不得翻转旋转；不能只靠数值自校验通过就出图。
- **解析中出现的每个垂足/辅助点**（"过 X 作 XY⊥…于 Z"）必须在图上有：Z 点、辅助虚线、直角标记三件套。
- **知识点锚点**：`knowledge` 为纯文本，无 `[[...]]`、无加粗；与体系文件 `#### ` 标题逐字一致。
