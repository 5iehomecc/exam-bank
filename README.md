# 试卷题库（v2.7.1）

本地只读的初中试卷习题库。数据来自 `D:\【Knowledge Notes】\12-试卷解析` 下已拆分的独立试题 md，
**不改动、不移动任何源文件**。

整个应用跑在 **Windows 自带的 PowerShell 5.1** 上，**不需要安装 Python，也不需要任何第三方依赖**：
索引构建和本地服务都是 PowerShell 脚本。

## 怎么用

1. **双击 `启动题库.bat`**（只有这一个 bat，启动和停止都在里面）。
   - 第一次打开：弹框让你选「装试题的那一层」文件夹（名字随意），选完自动记住并直接打开网页；
   - 以后打开：先问一句 `上次的题库：D:\…\12-试卷解析　[回车/Y 打开 · N 换一个]`，
     **5 秒不操作就自动用上次的**，等于还是一键；
   - 上次的路径找不到题了（库被挪走/改名）：不静默打开，直接转成弹框重新选；
   - 选到的文件夹里没有拆好的试题（`*-Q*.md`）：**不会自动继续**，只接受按 `R` 重新选或按 `Q` 退出，
     不合格的路径不会写进 config；
   - 换过题库后会自动重建索引（比对索引里记录的来源路径），不会出现「路径是新的、题目是旧的」。
2. 打开后会自动建索引、起服务、开浏览器；页面头部有一枚 `题库路径 <绝对路径>`，点一下可复制。
3. 浏览器地址：`http://127.0.0.1:8787`（8787 被占用时自动顺延到 8788、8789…，
   顺延时以命令行窗口里打印的地址为准）。
4. **关掉浏览器里的题库页面，服务会在 8 秒后自动退出**，命令行窗口也会自己消失。
   只有一套脚本，不需要再单独点停止。
   （兜底：300 秒无心跳自动退出；按 Ctrl+C 也能立即结束。）

命令行等价写法（PowerShell 里执行）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\serve.ps1
```

常用参数（**命令行优先于 config.json**）：

| 参数 | 作用 |
|---|---|
| `-Port 8790` | 指定起始端口 |
| `-NoOpen` | 不自动打开浏览器 |
| `-Rebuild` | 强制重建索引 |
| `-IdleExit 0` | 关闭「无心跳自动退出」兜底 |
| `-NoPrompt` | 跳过「用上次的题库吗」这一问，直接用 config |
| `-NoPick` | 禁止弹选择框（脚本/自动化场合），路径不可用时直接退出 |
| `-Version` | 只打印版本号 |
| `-Vault` / `-Sub` | 临时指定题库根与试卷解析子目录（给了就不交互、也不写 config） |

## 换题库 / 分享给别人

**文件夹名字可以随便起**，不需要叫「试卷解析」。程序判断标准是「这一层里有没有拆好的 `*-Q*.md`」，
所以 `12-试卷解析`、`我的数学题库`、`题库` 都能用。换题库的办法：

| 方式 | 怎么做 | 适合谁 |
|---|---|---|
| 启动时换（最简单） | 双击 `启动题库.bat`，在提示处按 **N**，就会弹框重新选 | 换库、库搬了位置 |
| 手填配置 | 改 `config.json`：`vault` 填库根目录，`sub` 填那个文件夹名（原名） | 想批量搭多份环境 |
| 自动探测 | 没有 config 时：读 `%APPDATA%\obsidian\obsidian.json` 里登记的库，<br>先找名字带「试卷解析」的子目录，找不到再找「里面有 `*-Q*.md`」的子目录，<br>找到就问一句「用它吗」 | 分享给别人的第一落点 |

说明几点：

- 选中文件夹后程序会自动拆成 `vault`（父目录）+ `sub`（文件夹原名）写进 config，
  页面头部会显示这个绝对路径，点一下可复制，方便确认到底读的是哪个库。
- `vault` 也支持手填**相对路径**（相对本程序目录），例如程序放在库内 `12-试卷解析\试卷题库` 时写
  `"vault": "..\.."`，整个库搬到哪里都不用改。
- 选了取消：已有可用配置就沿用上次的（只提示一句，不再追问）；第一次用且没配置则提示无法启动并退出。
- `port` / `idleExit`：起始端口、无心跳多少秒后自动退出，可省略（默认 8787 / 300）。
- 手改 config 写错（指向没有 `*-Q*.md` 的文件夹）时，启动会直接拒绝并让你重新选，不会带着空库跑。
- 给别人用：整个文件夹发过去或推到 GitHub，对方解压后双击 `启动题库.bat`，第一次会自己弹框让选题库层；
  自己的 `config.json` 不要提交（`.gitignore` 已忽略），里面是私人路径。

## 文件说明

| 文件 | 作用 |
|---|---|
| `VERSION` | 版本号唯一来源，页面徽标、索引 meta、启动横幅都读它 |
| `CHANGELOG.md` | 版本变更记录 |
| `LICENSE` | MIT 许可 |
| `.gitattributes` | 换行约定：`.bat` 强制 CRLF（保证 clone 下来能直接双击）、前端与 JSON 用 LF |
| `config.json` | **题库路径配置**（vault / sub / port / idleExit），换库或分享时只改这里 |
| `config.example.json` | 配置模板，给别人的参考；不发自己的 `config.json` 就不会带上私人路径 |
| `.gitignore` | 忽略 `config.json`、`questions.json`（前者含私人路径，后者是可再生的索引） |
| `启动题库.bat` | 唯一的入口 bat：启动服务；首次/换库时在里面选题库文件夹，关页面自动停 |
| `serve.ps1` | 本地只读服务：启动引导（选择题库文件夹、确认上次路径）、页面、`/api/questions`、`/api/meta`（版本/库名/路径）、`/api/ping`（心跳）、`/vault/`（只开放题库那一层）、`/assets/` |
| `lib.ps1` | 索引核心逻辑 + 配置读写 + 文件夹选择框：扫描试题 md 的 frontmatter，推导年级/学科/题型，解析知识点体系文件，生成 `questions.json` |
| `build-index.ps1` | 只建索引的命令行入口（同样读 `config.json`） |
| `index.html` | 单页前端（三栏） |
| `questions.json` | 索引产物，可随时重建，不需要手工编辑 |
| `assets/` | `marked.min.js` + `tex-svg.js`，公式与 Markdown 本地离线渲染 |
| `旧版-python（已停用）/` | 早先的 `index.py` / `serve.py`，仅留档，脚本不再调用 |

## 界面能做什么

- **左栏**：学科、年级、上/下册、题型、试卷来源、知识点树。
  知识点树按「学科 → 教材册次 → 章 → 知识点」四级展开，后面数字是题量；
  知识点体系文件里没有的条目会落在「未归入知识点体系 / 待归类」，不会丢。
- **左栏收起**：头部左上角的 ◧ 按钮（或 `Ctrl+B`）可收起筛选栏。收起后中栏让位给右栏，
  题目预览与配图明显变宽（1680 窗口实测 710px → 957px，1920 窗口约 826px → 1100px），
  状态会记住，适合专注看一道题。再点一次（或再按 `Ctrl+B`）恢复。
- **中栏**：题目卡片。搜索命中的关键词会高亮，卡片左侧 ★ 可收藏到选题夹。
- **右栏**：完整题干、配图、解析。解析默认折叠，点一下展开，也可一键全展开。
- **选题夹**：「只看收藏」筛出收藏题，「导出 MD」把这批题连同解析导出成一份 Markdown。
- **色彩方案**：头部右侧的配色按钮，可在「青瓷 / 纸墨 / 纯白」之间切换（默认青瓷），选择会记在本机浏览器里；
  想直接指定可用 `?theme=celadon|paper|white`。
- **题库路径**：头部徽标旁边常驻一枚 `题库路径 D:\…\12-试卷解析`，显示本次实际读取的绝对路径（收起左栏也在），
  点一下可复制，方便确认「我到底打开的是哪个库」。

## 数据更新

新增/修改试题 md 后，重新双击 `启动题库.bat` 即可——`serve.ps1` 发现 `questions.json`
比最新的 md 旧会自动重建（约 7 秒）。也可单独执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build-index.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\build-index.ps1 -Version
```

## 技术备注

- 服务用 `System.Net.Sockets.TcpListener` 手写 HTTP/1.1（短连接，`Connection: close`），
  避开 `HttpListener` 需要 URLACL 授权的问题；只监听 `127.0.0.1`。
- 端口顺延用「直接 `Start()` 试绑」：绑不上就换下一个，绑上就是你的。
  不用「先探测再绑定」（Windows 上两者之间仍可能被别的进程抢走）。
- **`/vault/` 只开放题库那一层**（`config.json` 里的 `sub` 目录），且只放行
  `.md` 与图片 / `.pdf`；其它路径 403，其它类型 403。页面只会读这一层里的试题与配图，
  库里的私人笔记、`.obsidian/` 配置不会因为这个服务被读到。
- 题型判定只看「第一个 `> [!question]` 之前的题干」，不看解析里有没有 `A.`，也不截断题干
  （长题干里的填空下划线必须算进去）。
- `lib.ps1` / `build-index.ps1` / `serve.ps1` 都以 **UTF-8 带 BOM** 保存——Windows PowerShell 5.1
  读无 BOM 的 `.ps1` 会把中文当 ANSI 解码。`questions.json` 必须无 BOM，否则前端 `JSON.parse` 会崩。

## 版本号怎么改

只改 `VERSION` 文件一行，然后重启即可：页面徽标、`/api/meta`、启动横幅、`serve.ps1 -Version`、
`build-index.ps1 -Version` 都会跟着变。同时在 `CHANGELOG.md` 记一条。
